# Chemistry 2e — Chapter 17: Electrochemistry

> Source: https://openstax.org/books/chemistry-2e/pages/17-introduction

This chapter continues the exploration of reduction-oxidation (redox) reactions. These reactions involve changes in oxidation states and electron transfers between reactants. Around 1800, chemists began investigating ways to facilitate electron transfer through external circuits rather than through direct contact of reactants. Over two centuries, electrochemistry has become a field yielding insights into redox chemistry fundamentals while enabling practical technologies, from industrial metallurgical processes to rechargeable batteries powering electric vehicles.

## 17.1 Review of Redox Chemistry

### Learning Objectives
- Describe defining traits of redox chemistry
- Identify the oxidant and reductant of a redox reaction
- Balance chemical equations for redox reactions using the half-reaction method

### Oxidation Numbers
A redox reaction is one that entails changes in oxidation number (or oxidation state) for one or more of the elements involved.

Key rules for assigning oxidation numbers:
1. The oxidation number of an atom in an element is equal to zero.
2. For an atom in a compound, the oxidation number is equal to the charge the atom would have in the compound if the compound were ionic.
3. The sum of oxidation numbers for all atoms in a molecule is equal to the charge on the molecule.

Examples:
- Ionic: NaCl → Na = +1, Cl = −1; CaF₂ → Ca = +2, F = −1
- Covalent: H₂O → O = −2, H = +1; CCl₄ → C = +4, Cl = −1
- NO₃⁻ → N = +5, O = −2; check: (1)(+5) + (3)(−2) = +5 − 6 = −1 ✓

### Balancing Redox Equations

Simple example (by inspection), decomposition of molten sodium chloride:
- Unbalanced: NaCl(l) → Na(l) + Cl₂(g)
- Balanced: 2NaCl(l) → 2Na(l) + Cl₂(g)
- Changes: Na: +1 → 0 (reduction); Cl: −1 → 0 (oxidation)

Half-reaction method for aqueous redox reactions (eight steps):
1. Write skeletal equations for the oxidation and reduction half-reactions.
2. Balance each half-reaction for all elements except H and O.
3. Balance each half-reaction for O by adding H₂O.
4. Balance each half-reaction for H by adding H⁺.
5. Balance each half-reaction for charge by adding electrons.
6. If necessary, multiply one or both half-reactions so electrons consumed = electrons produced.
7. Add the two half-reactions and simplify.
8. If the reaction occurs in basic medium, add OH⁻ to neutralize H⁺ (equal numbers on both sides) and simplify.

### Example 17.1 — Acidic Solution
Copper + nitric acid → aqueous Cu²⁺ + nitrogen monoxide gas.
- Skeletal: Cu(s) → Cu²⁺(aq); HNO₃(aq) → NO(g)
- Balance O with H₂O (reduction): HNO₃(aq) → NO(g) + 2H₂O(l)
- Balance H with H⁺: 3H⁺(aq) + HNO₃(aq) → NO(g) + 2H₂O(l)
- Balance charge with e⁻:
  - Oxidation: Cu(s) → Cu²⁺(aq) + 2e⁻
  - Reduction: 3e⁻ + 3H⁺(aq) + HNO₃(aq) → NO(g) + 2H₂O(l)
- Equalize electrons (oxidation ×3, reduction ×2), add and cancel 6e⁻:

**3Cu(s) + 6H⁺(aq) + 2HNO₃(aq) → 3Cu²⁺(aq) + 2NO(g) + 4H₂O(l)**

Check your learning (concentrated nitric acid → NO₂):
Cu(s) + 2H⁺(aq) + 2HNO₃(aq) → Cu²⁺(aq) + 2NO₂(g) + 2H₂O(l)

### Example 17.2 — Basic Solution
MnO₄⁻(aq) + Cr(OH)₃(s) → MnO₂(s) + CrO₄²⁻(aq), basic.
- Oxidation: H₂O(l) + Cr(OH)₃(s) → CrO₄²⁻(aq) + 5H⁺(aq) + 3e⁻
- Reduction: 3e⁻ + 4H⁺(aq) + MnO₄⁻(aq) → MnO₂(s) + 2H₂O(l)
- Add, simplify: Cr(OH)₃(s) + MnO₄⁻(aq) → CrO₄²⁻(aq) + H⁺(aq) + MnO₂(s) + H₂O(l)
- Neutralize H⁺ with OH⁻ (H⁺ + OH⁻ = H₂O):

**Cr(OH)₃(s) + MnO₄⁻(aq) → CrO₄²⁻(aq) + MnO₂(s) + 2H₂O(l)**

Check your learning (permanganate + bromide, basic):
H₂O(l) + 2MnO₄⁻(aq) + Br⁻(aq) → 2MnO₂(s) + BrO₃⁻(aq) + 2OH⁻(aq)

## 17.2 Galvanic Cells

### Learning Objectives
- Describe the function of a galvanic cell and its components
- Use cell notation to symbolize the composition and construction of galvanic cells

### Spontaneous Redox Reactions
A copper wire in silver nitrate solution shows spontaneous electron transfer: solution turns blue (Cu²⁺ forms) and gray silver deposits on the wire.
- Overall: Cu(s) + 2Ag⁺(aq) → Cu²⁺(aq) + 2Ag(s)
- Oxidation: Cu(s) → Cu²⁺(aq) + 2e⁻
- Reduction: 2Ag⁺(aq) + 2e⁻ → 2Ag(s)

### Electrochemical and Galvanic Cells
**Electrochemical cells** contain all reactants and products of a redox system while preventing physical contact between them; electron transfer occurs through an external circuit. **Galvanic cells** (or **voltaic cells**) are electrochemical cells in which a spontaneous redox reaction takes place.

### Components
- **Half-cells:** each contains a redox conjugate pair ("couple") of a single reactant; two half-cells are separated but connected.
- **Electrodes:** solid conductors where redox occurs. **Anode** = electrode at which oxidation occurs; **cathode** = electrode where reduction occurs.
- **Salt bridge:** a tube of inert electrolyte solution connecting the two half-cell solutions; maintains charge balance by allowing compensatory flow of inert ions.
- **External circuit:** connects the electrodes, allowing electron flow from anode to cathode.

Copper-silver cell (Figure 17.3): left half-cell Cu(0)/Cu(II) (Cu foil in 1 M Cu(NO₃)₂); right half-cell Ag(I)/Ag(0) (Ag foil in 1 M AgNO₃); salt bridge with NaNO₃. NO₃⁻ flows into the anode half-cell (balances rising Cu²⁺); Na⁺ flows into the cathode half-cell (compensates falling Ag⁺).

### Cell Notation (Cell Schematic)
Guidelines:
1. Chemical formulas or element symbols represent relevant components.
2. Vertical parallel lines (│) represent interfaces between component phases; commas separate components in the same phase; a double line (║) represents the salt bridge.
3. The schematic begins with the anode (left), proceeds through phases/interfaces, ending with the cathode (right).

- Copper-silver cell: Cu(s)│1 M Cu(NO₃)₂(aq)║1 M AgNO₃(aq)│Ag(s)
- Magnesium-iron(III) cell, net reaction Mg(s) + 2Fe³⁺(aq) → Mg²⁺(aq) + 2Fe²⁺(aq):
  - Oxidation: Mg(s) → Mg²⁺(aq) + 2e⁻; Reduction: 2Fe³⁺(aq) + 2e⁻ → 2Fe²⁺(aq)
  - Schematic: Mg(s)│0.1 M MgCl₂(aq)║0.2 M FeCl₃(aq), 0.3 M FeCl₂(aq)│Pt(s)

**Inert vs active electrodes:** when neither member of a redox couple can serve as an electrode (both are solute species), platinum (Pt) serves as an **inert electrode**. **Active electrodes** are made from a member of the redox couple (e.g., the Mg anode above).

### Example 17.3 — Writing Galvanic Cell Schematics
Cr wire in 1 M CrCl₃ (anode) connected to Cu wire in 1 M CuCl₂ (cathode):
- Schematic: Cr(s)│1 M CrCl₃(aq)║1 M CuCl₂(aq)│Cu(s)
- Anode: Cr(s) → Cr³⁺(aq) + 3e⁻; Cathode: Cu²⁺(aq) + 2e⁻ → Cu(s)
- Equalized: 2Cr(s) → 2Cr³⁺(aq) + 6e⁻; 3Cu²⁺(aq) + 6e⁻ → 3Cu(s)
- Overall: 2Cr(s) + 3Cu²⁺(aq) → 2Cr³⁺(aq) + 3Cu(s)

Check your learning (net Sn⁴⁺(aq) + Zn(s) → Sn²⁺(aq) + Zn²⁺(aq)):
Zn(s)│Zn²⁺(aq)║Sn⁴⁺(aq), Sn²⁺(aq)│Pt(s)

## 17.3 Electrode and Cell Potentials

### Learning Objectives
- Describe and relate the electrode potential and cell potential
- Interpret electrode/cell potentials in terms of oxidant and reductant strength
- Calculate cell potentials and predict redox spontaneity using standard electrode potentials

### Potential as a Measurable Property
"Potential" quantifies relative redox activity and equals energy per unit charge transferred, measured in volts (V = J/C). It reflects the driving force for electron transfer.

A single half-cell's potential cannot be measured independently; only the **difference** between two half-cells can be measured, yielding **cell potentials**.

### Cell Potential
$$E_\text{cell} = E_\text{cathode} - E_\text{anode}$$

Under standard-state conditions (1 M concentrations, 1 bar pressures, 298 K):
$$E^\circ_\text{cell} = E^\circ_\text{cathode} - E^\circ_\text{anode}$$

### Standard Hydrogen Electrode (SHE)
A reference half-cell assigned exactly 0 V, based on:
$$2H^+(aq) + 2e^- \rightarrow H_2(g)$$
A typical SHE has an inert platinum electrode in 1 M aqueous H⁺ with H₂ gas at 1 bar, at 298 K.

### Electrode Potential
The **electrode potential (E_X)** for half-cell X is the potential measured for a cell with X as cathode and SHE as anode:
$$E_\text{cell} = E_X - E_\text{SHE}, \quad E_\text{SHE} = 0\text{ V} \Rightarrow E_\text{cell} = E_X$$
Under standard-state conditions, this is the **standard electrode potential (E°_X)**, also called the **standard reduction potential**.

### Interpreting Electrode Potentials
The stronger oxidant has the greater standard electrode potential. Since potentials are defined for reduction, a larger E° = greater driving force for reduction = stronger oxidizing agent. Negative E° means the species is a weaker oxidant than aqueous H⁺. Table 17.1 lists standard reduction potentials in descending order (strongest oxidant / most positive at top).

### Predicting Spontaneity
E°_cell is positive when E°_cathode > E°_anode. A redox reaction whose oxidant appears above the reductant in the table is predicted spontaneous. Spontaneous → positive E°_cell; nonspontaneous → negative E°_cell. Reversing a reaction reverses the sign of E°_cell.

Selected standard reduction potentials (25 °C):

| Half-Reaction | E° (V) |
|---|---|
| F₂(g) + 2e⁻ → 2F⁻(aq) | +2.866 |
| Cu²⁺(aq) + 2e⁻ → Cu(s) | +0.34 |
| 2H⁺(aq) + 2e⁻ → H₂(g) | 0.00 |
| Pb²⁺(aq) + 2e⁻ → Pb(s) | −0.1262 |
| Zn²⁺(aq) + 2e⁻ → Zn(s) | −0.7618 |

(Full listing in Appendix L.)

### Example 17.4 — Calculating Standard Cell Potentials
Cu anode, Ag cathode; Cu(s) + 2Ag⁺(aq) → Cu²⁺(aq) + 2Ag(s):
$$E^\circ_\text{cell} = E^\circ_\text{Ag} - E^\circ_\text{Cu} = 0.7996 - 0.34 = +0.46\text{ V}$$
Check your learning (Pb cathode instead of Ag): E°_cell = −0.47 V.

Note: standard electrode potentials are intensive — they are *not* multiplied by stoichiometric coefficients when computing E°_cell (the Ag half-reaction is doubled, but E°_Ag is used as listed).

### Example 17.5 — Predicting Redox Spontaneity
Cr(s) + Fe²⁺(aq) → Cr³⁺(aq) + Fe(s):
$$E^\circ_\text{cell} = E^\circ_\text{Fe(II)} - E^\circ_\text{Cr} = -0.447 - (-0.744) = +0.297\text{ V (spontaneous)}$$
Check your learning:
- I₂(s) + 2Br⁻(aq) → 2I⁻(aq) + Br₂(l): E°_cell = −0.5518 V (nonspontaneous)
- Br₂(l) + 2I⁻(aq) → 2Br⁻(aq) + I₂(s): E°_cell = +0.5518 V (spontaneous)

## 17.4 Potential, Free Energy, and Equilibrium

### Learning Objectives
- Explain relationships between potential, free energy change, and equilibrium constants
- Perform calculations involving cell potentials, free energy changes, and equilibrium
- Use the Nernst equation to determine cell potentials under nonstandard conditions

### E° and ΔG°
The standard free energy change ΔG° is the maximum work obtainable; for a galvanic cell this is electrical work:
$$\Delta G^\circ = w_\text{max} = w_\text{elec} = -nFE^\circ_\text{cell}$$
where n = moles of electrons transferred, F = **Faraday's constant = 96,485 C/mol**, E°_cell = standard cell potential. Spontaneous reactions: positive E°_cell and negative ΔG°.

### E° and K
$$\Delta G^\circ = -RT \ln K = -nFE^\circ_\text{cell}$$
$$E^\circ_\text{cell} = \frac{RT}{nF}\ln K$$
Large positive E°_cell ⇒ reaction proceeds nearly to completion (products dominate at equilibrium).

| K | ΔG° | E°_cell | Status |
|---|---|---|---|
| > 1 | < 0 | > 0 | Spontaneous (std); products abundant |
| < 1 | > 0 | < 0 | Non-spontaneous (std); reactants abundant |
| = 1 | = 0 | = 0 | At equilibrium (std) |

### Example 17.6 — K, E°_cell, and ΔG°
2Ag⁺(aq) + Fe(s) ⇌ 2Ag(s) + Fe²⁺(aq):
- Anode: Fe(s) → Fe²⁺(aq) + 2e⁻ (E° = −0.447 V); Cathode: 2[Ag⁺ + e⁻ → Ag] (E° = 0.7996 V)
- E°_cell = 0.7996 − (−0.447) = +1.247 V; n = 2
- K = 10^(n·E°_cell / 0.0592 V) = 10^(2·1.247/0.0592) = 10^42.128 = **1.3 × 10⁴²**
- ΔG° = −nFE°_cell = −2 × 96,485 × 1.247 J/mol = **−240.6 kJ/mol**

Check your learning (Sn(s) + 2Cu²⁺(aq) ⇌ Sn²⁺(aq) + 2Cu⁺(aq)):
n = 2; E°_cell = +0.291 V; ΔG° = −56.2 kJ/mol; K = 6.8 × 10⁹.

### The Nernst Equation (Nonstandard Conditions)
$$\Delta G = \Delta G^\circ + RT \ln Q \Rightarrow -nFE_\text{cell} = -nFE^\circ_\text{cell} + RT \ln Q$$
$$E_\text{cell} = E^\circ_\text{cell} - \frac{RT}{nF}\ln Q$$
At 298 K (25 °C), using base-10 log:
$$E_\text{cell} = E^\circ_\text{cell} - \frac{0.0592\text{ V}}{n}\log Q$$
Cell potential depends on n, T, and reaction composition (Q).

### Example 17.7 — Nonstandard Conditions
Co(s) + Fe²⁺(aq, 1.94 M) → Co²⁺(aq, 0.15 M) + Fe(s):
- Anode: Co (E° = −0.28 V); Cathode: Fe²⁺/Fe (E° = −0.447 V); E°_cell = −0.447 − (−0.28) = −0.17 V
- Q = [Co²⁺]/[Fe²⁺] = 0.15/1.94 = 0.077
- E_cell = −0.17 − (0.0592/2)log(0.077) = −0.17 + 0.033 = **−0.14 V** (still nonspontaneous)

Check your learning (Al│Al³⁺(0.15 M)║Cu²⁺(0.025 M)│Cu): n = 6; Q = 1440; E_cell = +1.97 V (spontaneous).

### Concentration Cells
A **concentration cell** connects two nearly identical half-cells (same half-reaction and electrode) differing only in concentration of one redox species; E°_cell = 0 and the potential depends solely on the concentration difference.

### Example 17.8 — Concentration Cell
Zn(s)│Zn²⁺(0.10 M)║Zn²⁺(0.50 M)│Zn(s):
- Overall: Zn²⁺(0.50 M) → Zn²⁺(0.10 M); E°_cell = 0.000 V
- E_cell = 0.000 − (0.0592/2)log(0.10/0.50) = **+0.021 V** (spontaneous)
- Higher-concentration ion is reduced (cathode); lower-concentration side is oxidized (anode), equalizing concentrations.

Check your learning (at equilibrium): E_cell = 0.000 V; [Zn²⁺]_cathode = [Zn²⁺]_anode = 0.30 M.

## 17.5 Batteries and Fuel Cells

### Learning Objectives
- Classify batteries as primary or secondary
- List the components and reactions for common batteries and fuel cells

### Definitions
A **battery** is a galvanic cell specially designed and constructed as a source of electrical power for a specific application. **Primary cells** cannot be recharged (single-use). **Secondary cells** use conveniently reversible reactions that allow recharging by an external power source. A **fuel cell** is a galvanic cell that uses traditional combustive fuels (most often hydrogen or methane) continuously fed in along with an oxidant.

### Dry Cell (Zinc-Carbon)
Zinc can (anode), graphite rod (cathode), paste of MnO₂/ZnCl₂/NH₄Cl/water.
- Anode: Zn(s) → Zn²⁺(aq) + 2e⁻
- Reduction: 2MnO₂(s) + 2NH₄Cl(aq) + 2e⁻ → Mn₂O₃(s) + 2NH₃(aq) + H₂O(l) + 2Cl⁻
- Overall: 2MnO₂(s) + 2NH₄Cl(aq) + Zn(s) → Zn²⁺(aq) + Mn₂O₃(s) + 2NH₃(aq) + H₂O(l) + 2Cl⁻
- Cell potential ~1.5 V. Sizes D, C, AA, AAA share the same voltage; larger cells hold more reactant and transfer more charge.

### Alkaline Battery
KOH electrolyte; developed in the 1950s to improve on dry cells.
- Anode: Zn(s) + 2OH⁻(aq) → ZnO(s) + H₂O(l) + 2e⁻
- Cathode: 2MnO₂(s) + H₂O(l) + 2e⁻ → Mn₂O₃(s) + 2OH⁻(aq)
- Overall: Zn(s) + 2MnO₂(s) → ZnO(s) + Mn₂O₃(s)
- Cell potential +1.43 V; ~3–5× the energy of a similar-sized zinc-carbon cell. Prone to KOH leakage; mostly non-rechargeable (recharging risks rupture/leak).

### Nickel-Cadmium (NiCd) — Secondary
Nickel-plated cathode, cadmium-plated anode, KOH electrolyte; "jelly-roll" design.
- Anode: Cd(s) + 2OH⁻(aq) → Cd(OH)₂(s) + 2e⁻
- Cathode: NiO₂(s) + 2H₂O(l) + 2e⁻ → Ni(OH)₂(s) + 2OH⁻(aq)
- Overall: Cd(s) + NiO₂(s) + 2H₂O(l) → Cd(OH)₂(s) + Ni(OH)₂(s)
- ~1.2 V; ~1000 recharge cycles. Cadmium is toxic — never rupture/incinerate; dispose as toxic waste.

### Lithium-Ion — Secondary
- Cathode: Li₁₋ₓCoO₂ + xLi⁺ + xe⁻ ⇌ LiCoO₂
- Anode: xLiC₆ ⇌ xLi⁺ + xe⁻ + xC₆
- Overall: Li₁₋ₓCoO₂ + xLiC₆ ⇌ LiCoO₂ + xC₆
- ~3.7 V (variable stoichiometry, typically x ≤ 0.5). Popular in portable electronics: high current, light, nearly constant discharge voltage, slow self-discharge.

### Lead-Acid — Secondary
Dilute H₂SO₄ electrolyte; used in automobiles.
- Anode: Pb(s) + HSO₄⁻(aq) → PbSO₄(s) + H⁺(aq) + 2e⁻
- Cathode: PbO₂(s) + HSO₄⁻(aq) + 3H⁺(aq) + 2e⁻ → PbSO₄(s) + 2H₂O(l)
- Overall: Pb(s) + PbO₂(s) + 2H₂SO₄(aq) → 2PbSO₄(s) + 2H₂O(l)
- ~2 V per cell; six cells in series give 12 V. Inexpensive, high current (starter motors); heavy with caustic liquid; lead must be disposed of properly.

### Hydrogen Fuel Cell
Graphite electrodes with platinum-based catalysts.
- Anode: 2H₂(g) → 4H⁺(aq) + 4e⁻
- Cathode: O₂(g) + 4H⁺(aq) + 4e⁻ → 2H₂O(g)
- Overall: 2H₂(g) + O₂(g) → 2H₂O(g)
- ~1.2 V; energy efficiency typically 50–75% (vs ~20–25% for internal combustion using the same reaction). Used on extended space missions; vehicle prototypes exist but technology is relatively immature.

## 17.6 Corrosion

### Learning Objectives
- Define corrosion
- List common corrosion-prevention methods

### Definition
**Corrosion** is usually defined as the degradation of metals by a naturally occurring electrochemical process (e.g., rust on iron, tarnish on silver, blue-green patina on copper).

### Copper Patina (Statue of Liberty)
- 2Cu(s) + ½O₂(g) → Cu₂O(s) (red)
- Cu₂O(s) + ½O₂(g) → 2CuO(s) (black)
- 2CuO(s) + CO₂(g) + H₂O(l) → Cu₂CO₃(OH)₂(s) (green)
- 3CuO(s) + 2CO₂(g) + H₂O(l) → Cu₃(CO₃)₂(OH)₂(s) (blue)
- 4CuO(s) + SO₃(g) + 3H₂O(l) → Cu₄SO₄(OH)₆(s) (green)

The blue-green patina forms a protective layer via **passivation**, preventing further corrosion.

### Rust Formation
Iron rusts (O₂ + water) through galvanic cell reactions:
- Anode (oxidation): Fe(s) → Fe²⁺(aq) + 2e⁻; E° = −0.44 V
- Cathode (reduction): O₂(g) + 4H⁺(aq) + 4e⁻ → 2H₂O(l); E° = +1.23 V
- Overall: 2Fe(s) + O₂(g) + 4H⁺(aq) → 2Fe²⁺(aq) + 2H₂O(l); E°_cell = +1.67 V
- Further oxidation in humid air: 4Fe²⁺(aq) + O₂(g) + (4+2x)H₂O(l) → 2Fe₂O₃·xH₂O(s) + 8H⁺(aq)

Unlike copper patina, rust does not protect underlying iron — it flakes off, exposing fresh metal.

### Prevention
- **Paint:** blocks water/oxygen contact.
- **Alloying:** stainless steel's chromium forms a passivating oxide layer.
- **Galvanization:** zinc coating; zinc is more readily oxidized, blocks air, and provides cathodic protection if breached.
- **Cathodic protection:** the protected metal is made the cathode; a more active metal (lower reduction potential), typically zinc or magnesium, acts as a **sacrificial anode**, oxidizing in its place. The sacrificial anode needs periodic replacement.

## 17.7 Electrolysis

### Learning Objectives
- Describe electrolytic cells and their relationship to galvanic cells
- Perform stoichiometric calculations for electrolytic processes

### Definition and Contrast
**Electrolysis**: an external circuit does work on a redox system, imposing a voltage sufficient to drive an otherwise nonspontaneous reaction (in an **electrolytic cell**). Contrast with galvanic cells, where electrical work is done *by* a redox system on its surroundings via a spontaneous reaction.

### Electrolysis of Molten NaCl (Downs Cell)
Industrial production of Na metal and Cl₂ gas.
- Anode: 2Cl⁻(l) → Cl₂(g) + 2e⁻
- Cathode: Na⁺(l) + e⁻ → Na(l)
- Cell reaction: 2Na⁺(l) + 2Cl⁻(l) → 2Na(l) + Cl₂(g)
- Cell potential is negative (nonspontaneous); an applied positive potential larger in magnitude must force the reaction.

### Electrolysis of Water
Decomposed electrolytically (raise H⁺ with strong acid).
- Anode: 2H₂O(l) → O₂(g) + 4H⁺(aq) + 4e⁻; E°_anode = +1.229 V
- Cathode: 2H⁺(aq) + 2e⁻ → H₂(g); E°_cathode = 0 V
- Cell reaction: 2H₂O(l) → 2H₂(g) + O₂(g); E°_cell = −1.229 V
- Requires applied voltage > +1.229 V.

### Electrolysis of Aqueous NaCl
Competing half-reactions (water vs solute):

Possible anode reactions:
- (i) 2Cl⁻(aq) → Cl₂(g) + 2e⁻; E°_anode = +1.35827 V
- (ii) 2H₂O(l) → O₂(g) + 4H⁺(aq) + 4e⁻; E°_anode = +1.229 V

Water oxidizes at a more positive potential than chloride, yet both are typically oxidized, giving a mixture of O₂ and Cl₂.

Possible cathode reactions:
- (iii) 2H⁺(aq) + 2e⁻ → H₂(g); E°_cathode = 0 V
- (iv) 2H₂O(l) + 2e⁻ → H₂(g) + 2OH⁻(aq); E°_cathode = −0.8277 V
- (v) Na⁺(aq) + e⁻ → Na(s); E°_cathode = −2.71 V

In neutral aqueous NaCl, [H⁺] ≈ 10⁻⁷ M (far below 1 M), so water reduction occurs at the cathode.
- Net cell reaction: 2H₂O(l) + 2Cl⁻(aq) → H₂(g) + Cl₂(g) + 2OH⁻(aq); E°_cell = −2.186 V
- This is part of the **chlor-alkali process** (industrial Cl₂ and NaOH).

### Electroplating
Deposits a thin metal coating on a conducting surface. Silver-plating utensils:
- Anode: Ag(s) → Ag⁺(aq) + e⁻; Cathode: Ag⁺(aq) + e⁻ → Ag(s)
- Silver transfers from anode to cathode; quality depends on electrolyte composition, cell voltage, and current (rate).

### Quantitative Aspects (Faraday's Laws / Stoichiometry)
**Current** is the rate of flow of charge, in amperes (A = 1 C/s).
$$Q = It \qquad Q = nF$$
where Q = charge (C), I = current (A), t = time (s), n = moles of electrons, F = 96,485 C/mol e⁻. For a generic reduction Mⁿ⁺(aq) + ne⁻ → M(s), n moles of electrons are transferred per mole of M.

### Example 17.9 — Current to Moles of Electrons
10.23 A for exactly 1 hr through an AgNO₃ cell:
$$n = \frac{Q}{F} = \frac{10.23 \times 3600}{96{,}485} = \frac{36{,}830\text{ C}}{96{,}485} = 0.3817\text{ mol e}^-$$
Cathode: Ag⁺ + e⁻ → Ag (1 mol e⁻ → 1 mol Ag, M = 107.9 g/mol):
mass Ag = 0.3817 × 107.9 = **41.19 g Ag**

Check your learning (Al³⁺ + 3e⁻ → Al; 25.0 A, 15.0 min): 0.0777 mol Al = 2.10 g Al.

### Example 17.10 — Time Required for Deposition
0.010-mm Cr layer on 3.3 m² from Cr(III) (density Cr = 7.19 g/cm³), I = 33.46 A:
