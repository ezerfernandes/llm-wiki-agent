## Summary
This task asks the programmer to write a function that takes two boolean values and outputs the result of logical "and" and "or" on both arguments, plus "not" applied to the first argument. The key insight is exercising a language's native boolean type and operators; where a language lacks a dedicated boolean type, the type most commonly used for that purpose is substituted.

## Task Requirements
- Define a function accepting two logical (boolean) values.
- Output the result of AND and OR on both arguments.
- Output the result of NOT on the first argument.
- If the language has no separate boolean type, use the type conventionally used instead.
- If the language supports additional logical operations such as XOR, list those as well.

## Language Coverage
190 languages implement this task, reflecting that boolean logic is a universal primitive present in essentially every programming language. Representative implementations include C, C++, Python, Java, Haskell, Lisp, Forth, APL, Rust, and assembly variants such as 6502 Assembly and ARM Assembly.
