## Summary
This task asks the programmer to demonstrate a language's built-in string interpolation: substituting a variable or value into placeholders within a string template. The concrete goal is to take a string template missing the word "little" (held in a variable) and produce "Mary had a little lamb". The key point is to showcase the language's native interpolation feature rather than hand-rolling a substitution routine.

## Task Requirements
- Use the language's inbuilt string interpolation to insert the value "little" (stored in a variable) into a template, yielding the output "Mary had a little lamb".
- The task is explicitly not to write a custom interpolation routine but to exercise the language's built-in capability.
- If possible, provide links to documentation on the language's string interpolation features.

## Language Coverage
134 languages implement this task, reflecting how nearly every modern language offers some form of string interpolation or templating. Representative implementations include Python, Ruby, Perl, Raku, JavaScript, C#, Kotlin, Swift, Rust, and PHP.
