## Summary
This task asks the programmer to install a signal handler so a running program reacts gracefully to an operating-system interrupt rather than dying abruptly. The program prints an incrementing integer roughly twice per second, and when it receives SIGINT (typically Ctrl-C), it stops counting, reports how many seconds it ran, and exits cleanly. The key insight is registering a custom handler that overrides the default disorderly termination behavior.

## Task Requirements
- Display an integer on each line of output at a rate of about one per half second.
- Catch the SIGINT signal (generated by the user, e.g. Ctrl-C).
- On receipt of the signal, cease outputting integers, print the number of seconds the program has run, then quit.
