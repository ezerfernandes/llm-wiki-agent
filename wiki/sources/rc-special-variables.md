## Summary
This Rosetta Code task asks the programmer to enumerate the special variables that have a predefined meaning within a given programming language. These are language-built-in identifiers (often magic or implicit) that the runtime populates or interprets automatically, rather than ordinary user-declared variables. The task is descriptive rather than algorithmic — each language entry simply lists and explains its reserved or implicit variables.

## Task Requirements
- List the special variables used within the language.
- For each, describe its predefined meaning or role within the language.

## Language Coverage
81 languages implement this task, spanning scripting languages, BASIC dialects, Lisps, and assembly. Representative entries include Perl, Raku, Python, Ruby, AWK, Tcl, UNIX Shell, Common Lisp, Haskell, and Java — languages well known for implicit globals such as Perl's `$_`/`@ARGV`, the shell's positional parameters, or a result/last-value register.
