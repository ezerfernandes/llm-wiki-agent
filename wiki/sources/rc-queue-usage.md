## Summary
This task asks the programmer to create a queue data structure and demonstrate its core operations. A queue is a FIFO (first-in, first-out) collection: elements are removed in the same order they were added, in contrast to a stack's LIFO behavior. The task focuses on exercising the queue's interface rather than on a particular internal implementation.

## Task Requirements
- Implement (or use a library) a queue supporting `push` (a.k.a. `enqueue`) to add an element.
- Support `pop` (a.k.a. `dequeue`) to remove and return the first element.
- Support `empty`, returning a truth value indicating whether the queue holds no elements.
- Demonstrate these operations in a working example.

92 languages implement this task, giving very broad coverage across imperative, functional, scripting, and assembly languages. Representative examples include C, C++, Java, Python, Haskell, Erlang, Rust, Go, Common Lisp, Forth, and AWK.
