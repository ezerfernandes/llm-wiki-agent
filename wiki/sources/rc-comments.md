## Summary
This Rosetta Code task asks the programmer to demonstrate every way a language lets you embed text in source that the compiler or interpreter ignores entirely — that is, comments. The key insight is that comment syntax is one of the most divergent features across programming languages, spanning single-line markers, multi-line block delimiters, nesting rules, and shebang lines.

## Task Requirements
- Show all ways to include text in a source file that is completely ignored by the compiler or interpreter.
- Cover the language's comment forms (e.g. single-line, block, and any nested or doc-comment variants where applicable).

## Language Coverage
330 languages implement this task, making it one of the broadest entries on the site since virtually every language has some comment mechanism. Representative implementations include C, C++, Python, Java, JavaScript, Haskell, Lisp, Perl, Ruby, Rust, and assembly variants like 6502 Assembly.
