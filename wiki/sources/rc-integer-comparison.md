## Summary
This task asks the programmer to read two integers from the user and report whether the first is less than, equal to, or greater than the second. The key constraint is that each of the three cases must be tested separately, forcing all three comparison operators (`<`, `==`, `>`) to appear in the code rather than relying on a single chained or three-way comparison.

## Task Requirements
- Obtain two integers from the user (typically via standard input).
- Display a distinct message for each relationship: first less than second, first equal to second, first greater than second.
- Test each case independently so that all three comparison operators are exercised in the code.
