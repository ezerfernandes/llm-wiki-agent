## Summary
This is the canonical "Hello, World!" task: write a program that displays the literal string "Hello world!" on a text console. It is the traditional first program a learner writes in any language, exercising the minimal path from source code to visible output. Its enduring value is as a cross-language baseline — the smallest complete program that demonstrates a language's basic syntax and output mechanism.

## Task Requirements
- Display the string "Hello world!" on a text console (standard output).
- Distinct from related variants such as Hello world/Graphical, Hello world/Line Printer, Hello world/Standard error, and Hello world/Newline omission.

## Language Coverage
632 languages implement this task — by far one of the most widely covered entries on Rosetta Code, spanning everything from mainstream languages to esoteric and assembly dialects. Representative examples include C, Python, Java, JavaScript, Rust, Go, Haskell, Lisp, COBOL, and Brainf***.
