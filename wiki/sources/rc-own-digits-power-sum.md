## Summary
An "own digits power sum" is an N-digit decimal integer equal to the sum of each of its digits raised to the power N. The classic example is 153, where 1³ + 5³ + 3³ = 153. The task is to find and display all such numbers for N = 3 through N = 8 (optionally N = 9). These are precisely the Armstrong/narcissistic numbers of a fixed length, where the exponent is tied to the digit count.

## Task Requirements
- Define an N-digit integer as an own digits power sum when it equals the sum of its individual digits each raised to the power N.
- Find and show all such numbers for N = 3 to N = 8 inclusive.
- Optionally extend to N = 9 (noted as potentially slow for interpreted languages).
