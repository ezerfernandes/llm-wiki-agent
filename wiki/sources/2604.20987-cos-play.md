## Summary
Wu, Li, Shi et al. (Univ. of Maryland + USC + Good Start Labs + MBZUAI) introduce **COS-PLAY**, a multi-agent co-evolution framework for long-horizon game play. An LLM **decision agent** retrieves an active skill from a learnable **skill bank** and executes primitive actions conditioned on both intention and skill; an **agent-managed skill pipeline** segments unlabelled rollouts, learns compact skill contracts, and continually refines the bank. Both agents are trained with **GRPO**, closing the explore-learn-reuse loop without curated human demonstrations. On six game environments, an 8B-base-model COS-PLAY beats four frontier LLM baselines by **+25.1% average reward** on single-player games while remaining competitive on multi-player social-reasoning games.

## Key Claims
- **Co-evolution motivation.** The skill bank and decision agent are tightly coupled: a bank is only useful if the decider can select+execute its skills, and the decider is only as capable as its available skills. Existing work freezes one and improves the other; COS-PLAY trains both jointly.
- **Skills as a distinct abstraction layer.** Reusable, temporally extended behavior protocols extracted from trajectories — packaged with execution guidance and applicability *contracts*. Different from one-off tool calls or prompts.
- **Two questions framed.** (Q1) Should the bank and decision agent be learned jointly? (Q2) What properties make a bank useful for decisions? COS-PLAY is one of the first frameworks coupling LLM game decision-making with an agentic skill-bank pipeline for unsupervised discovery and continual refinement in a unified co-evolution loop.
- **Why games.** Long enough episodes for multi-skill chaining, recurring subgoals across episodes, cheap rollouts. Stress-test memory, planning, real-time action under delayed reward.
- **Empirical.** 8B base model + COS-PLAY beats four frontier LLM baselines by +25.1% average reward on single-player benchmarks; competitive on social-reasoning games.
- **Method components.** Decision agent maintains an intention and active skill; switches skills as needed. Skill-bank agent does unsupervised skill discovery + contract learning + bank curation. GRPO trains both: decision agent for retrieval+execution, skill-bank agent for segmentation+contracts+curation.
