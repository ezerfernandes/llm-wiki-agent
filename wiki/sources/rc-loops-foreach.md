## Summary
This task asks the programmer to loop through a collection and print each element in order. The intent is to demonstrate a language's dedicated "for each" construct, which iterates directly over a collection's values rather than over numeric indices. Where no such construct exists, the solution should fall back to an ordinary loop that still visits elements in their natural order.

## Task Requirements
- Iterate over every element of a collection, printing each one.
- Preserve the collection's natural ordering during iteration.
- Use the language's built-in foreach loop when available; otherwise use another loop construct.

194 languages implement this task, making it one of the most broadly covered iteration tasks on the site, spanning imperative, functional, and scripting paradigms. Representative implementations include Python, C, C++, Java, JavaScript, Ruby, Haskell, Common Lisp, Go, and Rust.
