## Summary
This task asks the programmer to print a small range of non-negative integers in several number bases (such as binary, octal, and hexadecimal) using only the language's standard built-in formatting routines. The key constraint is that no user-defined conversion function may be written — the goal is to demonstrate the language's native base-output facilities rather than to reimplement base conversion.

## Task Requirements
- Print a small range of integers in several different number bases.
- Use only standard, built-in routines of the language (e.g. format specifiers or library calls).
- Do not write a custom base-conversion function (that is the separate Number base conversion task).

## Language Coverage
81 languages implement this task, reflecting how widely supported native base formatting is across both mainstream and niche languages. Representative implementations include C, C++, Python, Java, JavaScript, Ruby, Rust, Go, Haskell, and Common Lisp.
