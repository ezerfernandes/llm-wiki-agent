## Summary
Chapter 11 — the final chapter — of OpenStax [[Prealgebra]] 2e moves from solving [[LinearEquation|linear equations]] in **one** variable (Ch 8) to *visualizing* linear equations in **two** variables. It introduces the [[RectangularCoordinateSystem|rectangular (Cartesian) coordinate system]], shows that the graph of a linear equation `Ax + By = C` is a **straight line** (every point on the line is a solution and every solution is a point on the line), teaches three ways to graph such a line — plotting points, using [[Intercepts|intercepts]], and using a point plus the [[Slope|slope]] — and defines slope as rise/run with the formula `m = (y₂ − y₁)/(x₂ − x₁)`. This is the bridge from prealgebra arithmetic/equation-solving to coordinate geometry and the algebra of lines.

## Sections
- **11.1 — Use the Rectangular Coordinate System.** Defines the x-y plane built from a horizontal **x-axis** and vertical **y-axis** meeting at the **origin** `(0,0)`; the four **quadrants** numbered I–IV counterclockwise from the upper right; the **ordered pair** `(x, y)` with x-coordinate first; plotting points; reading coordinates off a graph; points on the axes have form `(a,0)` or `(0,b)`; and verifying whether an ordered pair is a **solution** of a linear equation in two variables by substitution. See [[RectangularCoordinateSystem]].
- **11.2 — Graphing Linear Equations.** A linear equation in two variables has standard form `Ax + By = C`; its graph is a line. Graph by the **point-plotting method**: build a table of (x, y) solutions, plot, and draw the line (use **three** points so an error is caught). Covers **vertical lines** `x = a` and **horizontal lines** `y = b`. See [[GraphingLinearEquations]].
- **11.3 — Graphing with Intercepts.** Defines the **x-intercept** `(a, 0)` (where y = 0) and **y-intercept** `(0, b)` (where x = 0); finds intercepts by setting the other variable to 0 and solving; graphs a line from its two intercepts plus a check point; and gives a guide for choosing a graphing method based on the equation's form. See [[Intercepts]].
- **11.4 — Understand Slope of a Line.** Defines **slope** `m` as the ratio rise/run; finds slope from a graph by counting rise and run on a right triangle and via the formula `m = (y₂ − y₁)/(x₂ − x₁)`; classifies slope as positive, negative, zero (horizontal), or undefined (vertical); and graphs a line from a point plus a slope. See [[Slope]].
- **11-key-concepts** — chapter summary of quadrant sign patterns, the point-plotting and intercept graphing procedures, intercept rules, and the slope formula.

## Key Concepts & Definitions
- **Rectangular / Cartesian coordinate system** — the plane formed by a horizontal x-axis and vertical y-axis intersecting at right angles at the **origin** `(0,0)`; also called the x-y plane or coordinate plane. ([[RectangularCoordinateSystem]])
- **Ordered pair `(x, y)`** — names a point's location; the first number is the **x-coordinate**, the second the **y-coordinate**. Order matters.
- **Quadrants** — the four regions, numbered I, II, III, IV counterclockwise from the upper right, with sign patterns I `(+,+)`, II `(−,+)`, III `(−,−)`, IV `(+,−)`. Points on an axis lie in no quadrant: x-axis points are `(a,0)`, y-axis points are `(0,b)`.
- **Linear equation in two variables** — standard form `Ax + By = C` (A, B, C constants); a first-degree equation whose graph is a **straight line**. ([[LinearEquation]], [[GraphingLinearEquations]])
- **Graph of a linear equation** — the line containing *all* of its solutions: "Every point on the line is a solution… every solution is a point on this line."
- **x-intercept** — the point `(a, 0)` where the graph crosses the x-axis; occurs when `y = 0`. **y-intercept** — the point `(0, b)` where it crosses the y-axis; occurs when `x = 0`. ([[Intercepts]])
- **Slope `m`** — the ratio of **rise** (vertical change) to **run** (horizontal change) of a line; `m = rise/run = (y₂ − y₁)/(x₂ − x₁)`. ([[Slope]])
- **Vertical line `x = a`** — slope **undefined** (run = 0, division by zero). **Horizontal line `y = b`** — slope **0** (rise = 0).

## Key Procedures / Rules
- **Plot a point** — from `(x, y)`: move along the x-axis to x, then vertically to y; mark the intersection.
- **Decide if `(x, y)` is a solution** — substitute both values into the equation; it is a solution iff the result is a true statement.
- **Graph by plotting points** — (1) find three solutions and tabulate; (2) plot and confirm they are collinear; (3) draw the line through them with arrows. Three points guard against an arithmetic error in any one.
- **Find intercepts from an equation** — let `y = 0` and solve for x → x-intercept `(x, 0)`; let `x = 0` and solve for y → y-intercept `(0, y)`.
- **Graph using intercepts** — find both intercepts, find a third check point, plot all three, draw the line.
- **Choose a method** — `x = a` / `y = b` ⇒ draw the vertical/horizontal line directly; `y = mx + b` (y isolated) ⇒ plot points with chosen x-values; `Ax + By = C` (standard form) ⇒ use intercepts.
- **Find slope from a graph** — pick two lattice points, draw the right triangle, count rise (signed vertical) over run (signed horizontal), `m = rise/run`.
- **Find slope from two points** — `m = (y₂ − y₁)/(x₂ − x₁)`; subtract coordinates in the **same order** in numerator and denominator.
- **Graph from a point and slope** — plot the point; read `m` as rise/run; count off the rise and run to a second point; draw the line.
