## Summary
This task asks the programmer to demonstrate how integer literals can be written directly in source code across as many numeric bases as the language permits, such as binary, octal, decimal, and hexadecimal. The key constraint is that the values must be parsed by the compiler or interpreter as native integer literals, not produced by calling any conversion functions or methods. It also invites showing any other literal forms the language supports, such as distinct syntaxes for different integer types.

## Task Requirements
- Show integer literals expressed in as many bases as the language allows.
- The values must be interpreted directly by the compiler/interpreter, not via function/method calls.
- Demonstrate any additional literal-expression forms, e.g. syntaxes for different integer types (sizes, signedness).

## Language Coverage
144 languages implement this task, reflecting that nearly every language has some literal notation and many support multiple radixes (commonly prefixes like `0x`, `0b`, `0o`/`0`). Representative implementations include C, C++, Java, Python, Rust, Go, Haskell, Ruby, Perl, Common Lisp, and Ada.
