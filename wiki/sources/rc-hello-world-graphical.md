## Summary
A beginner-oriented GUI task: display the string "Goodbye, World!" using some graphical user interface object — an alert dialog, a plain window, a text area, or any other on-screen widget. The point is not the text itself but exercising each language's most idiomatic path to putting characters on a graphical surface rather than a terminal.

## Task Requirements
- Display the string "Goodbye, World!" on a GUI object (alert box, plain window, text area, etc.).
- The output must go to a graphical interface, not console/text output (the related text-only variant is the separate [[Hello world/Text]] task).

## Language Coverage
208 languages implement this task, an unusually broad set spanning native toolkit bindings, scripting languages, and assembly. Representative entries include C (Win32/GTK), C++, Java (Swing), JavaScript (browser DOM/alert), Python (Tkinter), Tcl/Tk, Haskell, Go, Rust, Lua, and even AArch64 Assembly.
