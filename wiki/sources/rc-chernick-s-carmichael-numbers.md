## Summary
The task asks the programmer to compute Carmichael numbers generated by Jack Chernick's 1939 "universal form" U(n, m), a product of n factors built from a parameter m. When every factor is prime (and, for n > 4, m is a multiple of 2^(n-4)), U(n, m) is guaranteed to be a Carmichael number. The goal is to find a(n), the smallest such number with exactly n prime factors, by searching over valid m.

## Task Requirements
- Implement the form U(n, m) = (6m+1)(12m+1) * product over k=1..n-2 of (2^k * 9m + 1).
- For each n, search the smallest m (respecting the m-multiple-of-2^(n-4) constraint when n > 4) such that all n factors are prime.
- Compute a(n), the smallest Chernick's Carmichael number with n prime factors, for n = 3..9.
- Optionally find a(10). Results may be shown in factorized form. Large values require big-integer arithmetic and an efficient primality test.
