## Summary
The task asks the programmer to create and display the dragon curve, a self-similar fractal traditionally generated by repeatedly folding a strip of paper in half and unfolding each fold to a right angle. The key insight is that the same curve can be reached through several equivalent routes: recursive right/left dragon co-routines, successive segment-rewriting, an iterative turn rule derived from the bit above the lowest set bit of the step index, or a Lindenmayer (L-system) string rewrite. Output may be drawn directly or written to an image file.

## Task Requirements
- Generate the dragon curve fractal.
- Display it directly on screen or write it to an image file.
- Any of the documented construction methods (recursion, successive approximation, iterative turn rule, complex-number coordinates, or L-system) is acceptable.
