## Summary
This task asks the programmer to plot a function given as two parallel numerical arrays of x and y values, producing a graphical image of the resulting curve or scatter. The key practical point is wiring up some plotting facility — a native library, an external tool like gnuplot, or an image buffer drawn pixel by pixel — to render the data points and save or display the figure. It is framed as a subtask supporting the benchmarking of sorting-algorithm performance.

## Task Requirements
- Plot a function represented by two numerical arrays, one of x values and one of y values.
- Use the specified sample input: x = {0..9} and y = {2.7, 2.8, 31.4, 38.1, 58.0, 76.2, 100.5, 130.0, 149.3, 180.0}.
- Post the resulting image of the plotted coordinate pairs.
