## Summary
A Disarium number is an integer equal to the sum of each of its digits raised to the power of that digit's position within the number (counting from 1 on the left). For example, 135 = 1¹ + 3² + 5³ = 1 + 9 + 125. The set of Disarium numbers is finite, and the task is to enumerate the small leading members of this sequence.

## Task Requirements
- Find and display the first 18 Disarium numbers.
- Stretch goal: find and display all 20 Disarium numbers (the complete finite set).

## Language Coverage
82 languages implement this task, giving very broad coverage across paradigms — from systems and classic languages to scripting and array languages. Representative implementations include C, C++, Rust, Go, Java, Python, Haskell, Ruby, Perl, and APL.
