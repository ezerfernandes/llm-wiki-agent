## Summary
A+B is a classic "hello world" of competitive programming: read two integers A and B (each in the range -1000 to +1000) from standard input separated by whitespace, and print their sum. Its real purpose is to let contestants verify they can correctly handle input parsing and output formatting on an online judge before tackling harder problems.

## Task Requirements
- Read two integers A and B from the input stream, separated by one or more spaces.
- Both integers are constrained to the range -1000 to +1000.
- Compute and output a single integer: the sum A + B.
- Example: input `2 2` yields output `4`; input `3 2` yields output `5`.
