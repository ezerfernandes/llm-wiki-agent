## Summary
This task asks the programmer to demonstrate a `for`-loop whose increment (step) value is greater than one, rather than the default step of one. The key idea is showing how a language expresses a non-unit stride when iterating over a numeric range, which many languages handle with an explicit step clause while others require manual index arithmetic.

## Task Requirements
- Demonstrate a `for`-loop where the step value is greater than one.

## Language Coverage
196 languages implement this task, making it one of the broadest entries in the Rosetta Code loop-construct family. Representative implementations span systems and scripting languages alike, including C, C++, Rust, Go, Java, Python, Ruby, Perl, Haskell, Common Lisp, and assembly variants such as 6502 Assembly and ARM Assembly.
