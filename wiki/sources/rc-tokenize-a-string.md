## Summary
This task asks the programmer to split the string "Hello,How,Are,You,Today" on comma delimiters into an array (or list), so each element holds a single word. The resulting words are then displayed back to the user separated by periods (a trailing period is permitted). The core idea is delimiter-based splitting followed by joining with a different separator.

## Task Requirements
- Separate "Hello,How,Are,You,Today" by commas into an array or list, one word per element.
- Display the words to the user in the simplest possible way, separated by a period.
- A trailing period is acceptable to keep the solution simple.

## Language Coverage
198 languages implement this task, making it one of the most broadly covered Rosetta Code tasks since nearly every language offers built-in string splitting and joining. Representative implementations include Python, JavaScript, C, C++, Java, Ruby, Perl, Haskell, Go, and Rust.
