## Summary
This task asks the programmer to demonstrate passing one function as an argument to another function. The core idea is treating functions as ordinary values that can be handed off to other routines, the defining trait of a higher-order function. It is the minimal exercise that distinguishes languages with first-class functions from those that only support fixed call sites.

## Task Requirements
- Pass a function as an argument to another function.

## Language Coverage
160 languages implement this task, spanning functional, imperative, object-oriented, and stack-based paradigms down to assembly. Representative entries include Haskell, OCaml, Scheme, Lisp, Python, JavaScript, Ruby, C, Java, Rust, and Go.
