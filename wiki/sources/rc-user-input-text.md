## Summary
This task asks the programmer to read input from the text console: a string and the integer 75000. The key point is demonstrating each language's idiom for reading typed user input from standard input (stdin) and, where relevant, parsing/converting a textual numeric entry into an integer value. It is a basic language-learning exercise contrasted with the GUI-based companion task User input/Graphical.

## Task Requirements
- Read a string from the text console (standard input).
- Read the integer 75000 from the text console.
- Use the console/terminal as the input medium (not a graphical dialog).

## Language Coverage
167 languages implement this task, reflecting that console input is one of the most universal primitives across programming languages. Representative implementations include C, C++, Python, Java, JavaScript, Go, Rust, Haskell, Ruby, Perl, and numerous BASIC dialects.
