## Summary
This Rosetta Code task asks the programmer to demonstrate basic array syntax in their language: create an array, assign a value to it, and retrieve an element. Where the language supports it, both fixed-length (statically sized) arrays and dynamic (growable) arrays should be shown, including pushing a value onto the dynamic one. The key insight is that it surfaces the distinction between contiguous fixed-size storage and resizable list-like containers across very different language paradigms.

## Task Requirements
- Create an array.
- Assign a value to an element of the array.
- Retrieve an element from the array.
- If supported, show a fixed-length array and a dynamic array (with push/append).

## Language Coverage
261 languages implement this task, making it one of the broadest entries on Rosetta Code and spanning everything from assembly to high-level scripting. Representative examples include C, C++, Java, Python, Rust, Go, Haskell, Ruby, JavaScript, and Fortran.
