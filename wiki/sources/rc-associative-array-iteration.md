## Summary
This task asks the programmer to traverse the entries of an associative array (a dictionary or hash map structure) and print each key together with its value. It also asks for the separate idioms a language may offer to iterate over only the keys or only the values. The exercise highlights that most languages provide distinct accessors (such as key views, value views, and entry views) rather than a single iteration mechanism.

## Task Requirements
- Iterate over the key-value pairs of an associative array and print each pair.
- Show how to iterate over just the keys, if the language provides a separate way to do so.
- Show how to iterate over just the values, if the language provides a separate way to do so.

## Language Coverage
140 languages implement this task, making it a very broad survey of how mainstream and niche languages model and traverse maps. Representative implementations include Python, JavaScript, Java, C++, C#, Ruby, Go, Rust, Perl, Haskell, Clojure, and Lua.
