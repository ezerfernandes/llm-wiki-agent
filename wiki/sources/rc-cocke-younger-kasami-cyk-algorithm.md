## Summary
The task asks the programmer to implement the CYK parsing algorithm, which decides whether a given string can be generated by a context-free grammar expressed in Chomsky Normal Form. The key insight is a bottom-up dynamic-programming approach: it fills a triangular table where each cell holds the set of non-terminals that can derive a particular substring, building from single characters up to the whole string. The string is accepted if the grammar's start symbol appears in the cell spanning the entire input.

## Task Requirements
- Implement CYK for a context-free grammar in Chomsky Normal Form (rules of the form A → B C or A → a).
- Fill an n×n triangular table where T[i,j] is the set of non-terminals deriving the substring from position i to j.
- Base case: for each terminal, add every non-terminal with a production directly yielding it.
- Inductive step: for each substring length, start position, split point, and binary production, add A to T[i,j] when B derives the left part and C the right part.
- Accept the string iff the start symbol is in T[1,n].
- Apply the recognizer to the provided noun-phrase grammar (NP, Nom, AP, Det, Adv, A) which allows recursive adjective phrases like "very heavy orange".
