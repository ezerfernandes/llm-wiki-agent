## Summary
This task asks the programmer to determine the number of elements stored in an array. The canonical example is an array holding the two strings 'apple' and 'orange', whose length should be reported as 2. The key insight is that nearly every language exposes a built-in length operation (a property, function, or operator), making this a baseline exercise in array introspection across language idioms.

## Task Requirements
- Determine the number of elements contained in an array.
- Use a concrete example: an array holding the strings 'apple' and 'orange' (expected length 2).

## Language Coverage
223 languages implement this task, reflecting that querying array size is a near-universal primitive. Representative implementations span systems and scripting languages alike, including C, C++, Rust, Go, Java, Python, JavaScript, Haskell, Ruby, and Lua.
