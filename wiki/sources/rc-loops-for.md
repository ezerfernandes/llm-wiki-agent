## Summary
This task demonstrates the classic counted "for" loop, in which a control variable is set to a monotonically increasing integer for each pass over a block of code. The key exercise is nesting one for loop inside another, where the inner loop's iteration count is driven by the outer loop's control variable. The canonical output is a right triangle of asterisks (one star on the first row, growing to five on the fifth).

## Task Requirements
- Show how two for loops can be nested, one inside the other.
- Make the number of inner-loop iterations depend on the current outer-loop value.
- Print the staircase pattern of asterisks: rows of `*`, `**`, `***`, `****`, `*****`.
