## Summary
This task asks the programmer to create an associative array — a data structure that maps keys to values, also known as a dictionary, map, or hash. The point is to demonstrate the idiomatic way each language constructs such a key/value collection, ranging from native literal syntax in dynamic languages to library-backed structures in lower-level ones.

## Task Requirements
- Create an associative array (dictionary / map / hash) in the language.
- The structure should associate keys with values, the fundamental key/value mapping operation.

## Language Coverage
178 languages implement this task, making it one of the broadest entries on the site since nearly every general-purpose language offers some form of key/value collection. Representative implementations include Python, JavaScript, Ruby, Perl, C++, Java, Go, Rust, Haskell, and Lua.
