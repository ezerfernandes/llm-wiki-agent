## Summary
This task asks the programmer to demonstrate the full range of a language's facilities for working with variables. Rather than solving an algorithm, it is a survey task: each implementation should illustrate how the language declares, initializes, assigns, types, scopes, and references variables. The point is to expose the variable model of the language as a teaching reference.

## Task Requirements
- Demonstrate variable declaration.
- Demonstrate initialization.
- Demonstrate assignment.
- Demonstrate datatypes (typing of variables).
- Demonstrate scope (visibility and lifetime).
- Demonstrate referencing (aliases, pointers, references).
- Demonstrate any other variable-related facilities the language offers.

## Language Coverage
150 languages implement this task, an exceptionally broad spread reflecting that variable handling is a universal language feature. Representative entries span systems and assembly languages (C, Rust, 68000 Assembly), scripting and dynamic languages (Python, Ruby, Perl, JavaScript, Lua), functional languages (Haskell, OCaml, Clojure, F#), and many BASIC and Lisp dialects (FreeBASIC, Common Lisp, Racket).
