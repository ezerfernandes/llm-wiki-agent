## Summary
Xu, Dai & Zhang (CUHK + Zhejiang U) argue that everything the field currently calls **agentic memory** — vector stores, RAG, scratchpads, MemGPT-style paging, Reflexion's self-critiques, Voyager's skill DB — is **lookup, not memory**. Conflating them is a category error with provable consequences: a generalization ceiling on compositionally novel tasks, no expertise growth across sessions ("frozen novice problem"), and structural conversion of transient prompt injection into persistent compromise. Drawing on Complementary Learning Systems (CLS) theory from neuroscience, the paper proves a **Compositional Sample Complexity Separation** theorem (retrieval needs Ω(k²) examples, parametric needs O(d log 1/δ)) and proposes a **co-existence architecture** that pairs fast external storage with slow weight consolidation.

## Key Claims
- **Two structurally distinct paths** to changing what an LLM agent outputs: change θ (weights — generative recombination) or change C (context — bounded by L). All deployed agentic memory is C-engineering; weights are identical before and after experience.
- **Generalization Gap Theorem.** Under bounded in-context composition (Assumption 3.2, justified via Fano's inequality whenever log|H| > K log|Y|), retrieval needs Ω(k²) compositional examples while parametric fine-tuning needs only O(d) for the same target generalization — independent of context window size or retrieval quality.
- **Frozen novice problem.** No matter how much experience an agent logs, every session begins from the same pretrained weights; expertise (in the Chi et al. 1981 sense — structural reorganization, not example accumulation) cannot emerge.
- **Persistent compromise.** Stateless agent risk per session is bounded by injection probability p₀; with persistent agentic memory, P(compromised by t) = 1 − (1 − p₀)^N(t) → 1. Empirically: MINJA 98.2% injection success persisting across sessions; PoisonedRAG 90% with 5 adversarial texts in a million-entry store; InjecAgent shows memory-writing agents systematically more vulnerable.
- **Mechanistic support.** ROME / MEMIT localize knowledge to MLP weights; ParamMem shows parametric agent reflections beat external storage; SFT updates attention routers, not knowledge units (90% of SFT updates contribute nothing to knowledge per Ye et al. 2025).
- **Co-existence architecture proposal.** Episodic traces in external store (fast, temporary); skills can bridge C↔θ; rules must live in weights (slow, generalizable). The AI analog of CLS consolidation is **offline fine-tuning on distilled agent experience**.
- **Four alternatives addressed and rebutted.** Bigger context (capacity vs compositional confusion); ICL = rule extraction (ICL only activates pretrained rules, ephemeral updates); compression spectrum (supports rather than undermines the C/θ distinction); test-time adaptation (boundary case but does not change pretrained base).

## Key Quotes
> "Treating a memo as a mind."
> "Its filing cabinet grows while its capacity does not."
> "Compromising C requires only a single successful injection; injected content poisons every future session."
> "The frozen novice grows a larger filing cabinet, not a sharper mind."
