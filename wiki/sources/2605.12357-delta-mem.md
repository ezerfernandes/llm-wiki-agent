## Summary
Lei, Zhang, Li et al. ([[MindLab]] + [[nanyangtechnologicaluniversity|NTU]] + [[fudanuniversity|Fudan]] + Shanghai Jiao Tong U + [[chineseuniversityofhongkong|CUHK]] + HKUST-Guangzhou) propose **δ-mem**, a lightweight memory mechanism that augments a **frozen** full-attention Transformer backbone with a compact **online state of associative memory (OSAM)** — a fixed-size matrix $\mathbf{S}_t \in \mathbb{R}^{r \times r}$ updated via gated **delta-rule learning** as tokens stream in. Instead of retrieving text or extending context, δ-mem reads the state with a learned query, projects the readout into **low-rank query- and output-side corrections** that are added to the frozen backbone's attention computation, then writes the new key–value pair back into the state. With only an $8\times 8$ online state, δ-mem improves average score by **1.10×** over the frozen backbone and **1.15×** over the strongest non-δ-mem memory baseline; on memory-heavy benchmarks gains reach **1.31× on MemoryAgentBench** and **1.20× on LoCoMo**, while general capability (IFEval, GPQA-Diamond) is largely preserved. Three writing-granularity variants (Token / Sequence / Multi-State Write) trade off locality vs interference. Parameter overhead is **0.12%** of the backbone (4.87M trainable parameters for r=8).

## Key Claims
- **Three-paradigm taxonomy of LLM memory.** Existing memory mechanisms split into (a) **Textual Memory Mechanisms (TMMs)** — MemGPT, MemoryBank, LLMLingua-2 — that store memory as text and reinject via context; (b) **Outside-channel Memory Mechanisms (OMMs)** — Memorizing Transformers, LongMem, MLP Memory — that hold memory in a side module and fuse back via retrieval/encoding; (c) **Parametric Memory Mechanisms (PMMs)** — Prefix-Tuning, LoRA, ROME, MEMIT, Context2LoRA — that bake memory into weights or prefix/adapter parameters. Each suffers from a structural limit (context-window/retrieval-noise, integration complexity, static adaptation respectively); δ-mem positions itself as a fourth category: a **dynamically-evolving online state directly coupled with attention computation**.
- **Online State of Associative Memory (OSAM).** A matrix $\mathbf{S}_t$ stores key→value associations. Read: $\mathbf{r}_t = \mathbf{S}_{t-1}\mathbf{q}_t^m$. Write follows the **gated delta-rule**: $\mathbf{S}_t = \mathrm{Diag}(\boldsymbol{\lambda}_t)\mathbf{S}_{t-1} + \mathrm{Diag}(\boldsymbol{\beta}_t)(\mathbf{v}_t^m - \mathbf{S}_{t-1}\mathbf{k}_t^m)(\mathbf{k}_t^m)^\top$, viewable as SGD on the online regression loss $\frac{1}{2}\|\mathbf{S}\mathbf{k}_t - \mathbf{v}_t\|^2$. The forget gate $\boldsymbol{\lambda}_t$ (per-dimension) is inspired by Qwen-Next retention design (Yang et al. 2025).
- **Low-rank steering of frozen attention.** The state readout $\mathbf{r}_t$ generates two corrections $\Delta\mathbf{q}_t = \mathbf{W}_q^\Delta \mathbf{r}_t$ and $\Delta\mathbf{o}_t = \mathbf{W}_o^\Delta \mathbf{r}_t$ added to the original query and post-attention output. Critical distinction from a static LoRA: $\mathbf{W}_q^\Delta, \mathbf{W}_o^\Delta$ are fixed after training, but their input $\mathbf{r}_t$ comes from the *dynamic* state $\mathbf{S}_{t-1}$ — so the same parameters yield different steering under different histories. The backbone parameters are never updated.
- **Three writing granularities.** **Token-State Write (TSW)** updates per token (finest, noisiest); **Sequence-State Write (SSW)** averages a message segment's hidden states and updates once per message (smoother, loses sub-message detail); **Multi-State Write (MSW)** maintains $N$ parallel sub-states and concatenates their readouts (reduces interference). Strongest variant depends on backbone scale: TSW best for Qwen3-4B-Instruct (51.66 avg), MSW best for SmolLM3-3B (36.96, +10.88 over base) and on LoCoMo, SSW best for Qwen3-8B.
- **Context recovery without explicit history.** In the no-context HotpotQA setting, the online state alone recovers part of the missing multi-hop evidence: overall EM **0.08% → 6.48%**, F1 **8.27% → 15.20%**; on the Bridge subset (true multi-hop), EM **0.08% → 3.97%**, F1 **6.25% → 11.05%**. LoCoMo overall: **3.49% → 8.05%**. Evidence that the compact state retains usable historical signal even when the source context is wiped.
- **Where to inject.** Ablation: applying corrections to **both query and output branches** beats either alone (48.05 vs 47.05 for output-only, 44.51 for query-only); adding key and value branches (qkvo) is marginally better (48.05) but not worth the parameter cost. Default = qo. Layer ablation: applying to **all layers** gives best average (47.97); among partial configurations, middle 12 layers > front > back, suggesting intermediate layers are the most effective interface.
- **Efficiency.** Same GPU memory as Vanilla / Context2LoRA at 32K prompts; decoding throughput slower than Vanilla (state read+update per step) but much faster and more stable than MemGen and MLP Memory. 4.87M trainable params (0.12%) vs MemGen 46.20M (1.13%) vs MLP Memory 3,078M (76.40%).
- **Trained with standard SFT** on the shortest 2,219-sample QASPER split. Context tokens are written into the state $\mathbf{S}_C$, not replayed as backbone input; the backbone sees only query + response, with the stored state steering attention.

## Key Quotes
> "δ-mem maintains a compact and dynamically evolving memory state while steering the backbone through a pathway tightly aligned with its internal attention computation."

> "δ-mem does not simply retrieve text from memory. Instead, the current input queries the online state to extract context-relevant associative memory signals, which are then transformed into a low-rank correction to the backbone's attention components."

> "Although $\mathbf{W}_q^\Delta$ and $\mathbf{W}_o^\Delta$ are fixed after training, their input $\mathbf{r}_t$ comes from the dynamic state $\mathbf{S}_{t-1}$. Therefore, the same set of parameters can produce different steering effects under different histories."

> "Even with an extremely small 8×8 online state, the model can recover useful historical information after explicit context is removed."

## Contradictions

### Productive tension with [[2604.27707-agentic-memory-is-a-memo]] (Xu, Dai & Zhang, CUHK + Zhejiang U, 2026)
The Xu et al. paper proves a **Compositional Sample Complexity Separation**: retrieval-based "agentic memory" (vector stores, MemGPT, RAG, scratchpads) needs Ω(k²) examples for compositional generalization, while parametric fine-tuning needs only O(d log 1/δ). Their constructive proposal is **weight consolidation** (CLS-style fine-tune-on-distilled-experience) — they explicitly cede the *agentic* setting back to continual-learning weight updates.

δ-mem occupies a position the Xu et al. taxonomy doesn't cleanly cover:

| | Where memory lives | Backbone θ updated? | Steering pathway |
|---|---|---|---|
| TMM (MemGPT, RAG) | Text reinjected into context $C$ | No | Prompt |
| OMM (Memorizing Transformers, LongMem) | External module | No | Side-network read |
| PMM (LoRA, ROME, MEMIT) | Backbone weights or static adapter | Yes, statically | Modified weights |
| **δ-mem** | **Online state $\mathbf{S}_t$, dynamically updated at runtime** | **No** | **Low-rank correction to attention from a dynamic readout** |

This is neither pure $C$-engineering (the state is not in context) nor pure θ-engineering (backbone is frozen, $\mathbf{W}^\Delta$ is also frozen post-training). It is a *third structural locus*: a runtime-evolving auxiliary state coupled to attention. Two open questions follow:

1. **Does the Ω(k²) compositional bound apply?** The Xu et al. bound rests on Assumption 3.2 (bounded in-context composition under approximate retrieval). δ-mem's readout is not text retrieval; it is a continuous linear projection of a state updated by gradient descent on an online regression loss. The bound's applicability to *associative-memory online states* is unestablished. δ-mem's empirical gains on memory-heavy benchmarks (1.31× MAB, 1.20× LoCoMo) are consistent with — but not proof of — escaping the bound.
2. **Does it solve the "frozen novice" problem?** Probably not in Xu et al.'s strong sense: across sessions the state $\mathbf{S}_t$ can be persisted, but the **trainable parameters** ($\mathbf{W}_q^\Delta, \mathbf{W}_o^\Delta, \mathbf{W}^m_{q,k,v}, \mathbf{W}_\beta$) are fixed after the one-epoch QASPER SFT — there is no continual learning of *how to memorize*, only continual updating of the state being memorized into. The Xu et al. critique of "every session begins from the same pretrained weights" applies to δ-mem's $\Delta$-parameter set too.

The Xu et al. paper would likely classify δ-mem as a clever OMM variant: external auxiliary memory whose readout is fused back via attention correction. δ-mem's authors implicitly disagree by placing it as a fourth category. **The wiki records this as an open taxonomic and empirical question**, not a resolved disagreement.

### Tension with [[1910.10683-t5]] / static-adapter conventional wisdom
Conventional [[adapterlayers|adapters]] and [[prefixlm|prefix tuning]] are static post-training. δ-mem's claim that *static* projection weights can yield *dynamic* steering — because their inputs come from a runtime-evolving state — is a non-trivial generalization of the adapter idea. Read alongside [[parammem|ParamMem]] (which argues *parametric* reflections beat external ones) and [[2604.27707-agentic-memory-is-a-memo]] (which argues *only* θ-update consolidates), δ-mem is the first paper in this corpus to argue a *non-weight, non-context* third option works empirically.

### No claimed contradiction with [[2402.01817-llm-modulo]]
δ-mem is silent on planning/self-verification. The OSAM is an information substrate, not a reasoner; no claim is made that it lets a model self-verify. The wiki's [[2402.01817-llm-modulo]] counter-claim against agentic-LLM-as-planner is **unaffected** by this paper.
