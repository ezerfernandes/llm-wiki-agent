## Summary
Singh et al. (Microsoft Research + NUS) argue that interpretability tools used by Agentic Data Science (ADS) systems were designed for humans, not agents. They introduce **AGENTIC-IMODELS**, an autoresearch loop in which a coding agent (e.g. Claude Code) iteratively modifies a scikit-learn-compatible Python class to optimize jointly for predictive performance and a novel **LLM-based simulatability** interpretability metric — measuring whether an LLM can answer questions about a fitted model by reading only its `__str__`. Discovered models extend the Pareto frontier on held-out datasets and new tests, and improve four downstream ADS agents by **8–73%** on the BLADE benchmark.

## Key Claims
- **Interpretability mismatch** — existing tools (decision trees, GAMs, rule lists, plus visualizations) were designed for humans, often impeding agents.
- **LLM-graded simulatability** — replaces human experiments; tests probe predictions, feature effects, counterfactuals from `__str__` alone.
- **Autoresearch loop** — coding agent proposes Python-class modifications; loop scores both metrics across 65 tabular datasets; rank-averaging avoids RMSE-noise sensitivity.
- **Pareto improvement** — evolved AGENTIC-IMODELS dominate baselines (TabPFN, EBM, GBM, PyGAM, OLS, Ridge, FIGS, HSTree, MLP) jointly on accuracy and agent-interpretability.
- **Generalization** — improvements transfer to held-out datasets and unseen interpretability tests.
- **Downstream wins** — 8–73% gain on BLADE for Copilot CLI, Claude Code, Codex when equipped with evolved models vs standard interpretability tools.
- **Qualitative novelty** — evolved models combine known algorithms in new ways and present themselves in agent-amenable forms.

## Key Quotes
> "Rather than designing data-science tools to be interpretable by humans, we aim to design tools that are interpretable by agents."
> "Equipping four different ADS agents with the evolved models improves their performance on the BLADE end-to-end benchmark by 8%–73%."
