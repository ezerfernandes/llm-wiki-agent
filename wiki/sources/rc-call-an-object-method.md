## Summary
This basic object-oriented task asks the programmer to demonstrate the two fundamental ways methods are invoked. The key distinction is between a static (class) method, which belongs to the class itself, and an instance method, which is dispatched on a particular object instance. The point is to show the calling syntax for each kind in a given language.

## Task Requirements
- Show how to call a static or class method (associated with the class itself).
- Show how to call an instance method (associated with an instance of a class).

## Language Coverage
93 languages implement this task, spanning class-based OO languages, prototype-based and functional languages, and even assembler dialects. Representative implementations include Java, C++, C#, Python, Ruby, Smalltalk, Objective-C, JavaScript, Common Lisp, and Rust.
