## Summary
Ge, Peng, Cheng & Gao (Microsoft) introduce **Synthetic Computers at Scale**: a persona-driven methodology that elaborates a persona → user profile → planned filesystem → populated directory hierarchy with content-rich artifacts (docs, spreadsheets, presentations). Conditioned on each synthetic computer, a **setup agent** creates user-specific objectives requiring ~one month of human work, and a **work agent** acts as that user across the computer for >8 hours runtime / >2,000 turns per simulation. They release 100 synthetic computers (50 Windows-style + 50 macOS-style) and retrospective reports for 500 simulations from a 1,000-computer preliminary run.

## Key Claims
- **Productivity work is context-heavy.** Realistic deliverables are grounded in existing files, history, prior decisions, and evolving project state — not isolated tasks.
- **Synthesize the context, not just the task.** Without realistic environments to condition on, synthetic data degenerates into toy workflows. The methodology fills the user-environment gap that real-trajectory collection cannot scale through (privacy, cost).
- **Three-stage computer creation.** Persona → detailed user profile (identity, occupation, organization, responsibilities, recent work history) → planned filesystem (artifacts, folder organization, naming conventions, inter-artifact relationships) → instantiated populated computer.
- **Two-agent simulation loop.** Setup agent generates objectives requiring multiple professional deliverables (reports, spreadsheets, presentations) ≈ one month of human work; work agent navigates filesystem for grounding, coordinates with simulated collaborators, iteratively revises deliverables until objectives complete.
- **Scale claim.** Personas are abundant at billion scale (Ge et al., 2024); the pipeline can in principle scale to millions or billions of synthetic computers with compute. Per-simulation cost: 8 h runtime, 2,000+ turns.
- **Empirical validation.** Long-horizon trajectories produce both process signals (search/plan/revise/coordinate/recover) and outcome signals (deliverable quality); fine-tuning on these yields significant in-domain and out-of-domain agent performance gains.
- **Positioning.** Argued as a foundational substrate for **agent self-improvement** and **agentic RL** in long-horizon productivity scenarios — explicit complement to coding-agent grounding (Cursor, Claude Cowork).

## Key Quotes
> "Productivity work is context-heavy by nature."
> "Synthetic data must synthesize the context, not only the task."

## Contradictions
- Implicit tension with [[2604.27707-agentic-memory-is-a-memo|Xu, Dai & Zhang]]: this paper's premise that long-horizon trajectories yield "rich experiential learning signals" assumes those signals can be turned into capability — which the memory paper says only holds when consolidation reaches the weights, not the context. The two papers are complementary if simulations feed weight-level fine-tuning (which they do here) and contradictory if interpreted as accumulating retrieval traces.
