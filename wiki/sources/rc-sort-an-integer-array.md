## Summary
The task asks the programmer to sort an array (or list) of integers into ascending numerical order, preferring whatever built-in sorting facility the language or its standard library provides. The key point is to demonstrate the idiomatic, library-supported way to sort rather than hand-rolling an algorithm, contrasting with the dedicated sorting-algorithm tasks elsewhere on the site.

## Task Requirements
- Sort an array or list of integers in ascending numerical order.
- Use a sorting facility provided by the language or its library if one is available.

## Language Coverage
174 languages implement this task, reflecting that nearly every general-purpose language ships some sorting primitive. Representative examples include C, C++, Java, Python, Ruby, Rust, Go, Haskell, JavaScript, and Perl.
