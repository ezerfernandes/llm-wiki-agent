## Summary
The task is to build a stack-based evaluator for an expression written in reverse Polish notation (postfix), where operators follow their operands. The key insight is that RPN needs no parentheses or precedence handling: scanning left to right, numbers are pushed onto a stack and each operator pops its operands, computes, and pushes the result. Beyond just producing the answer, the task requires tracing the stack state after every token is processed and displaying it as a table.

## Task Requirements
- Accept a correct, space-separated string of RPN tokens as input.
- Push operands onto a stack; on each operator pop the required operands, apply the operation, and push the result.
- Show the evolving stack contents after each token is processed, formatted as a table.
- Support `+`, `-`, `*`, `/`, and `^` (exponentiation), where `/` is division.
- Test with the expression `3 4 2 * 1 5 - 2 3 ^ ^ / +` (the RPN generated by the Shunting-yard task) and display the output.

## Language Coverage
84 languages implement this task, giving very broad coverage across functional, imperative, and stack-oriented paradigms. Representative implementations include Python, C, C++, Java, Haskell, Forth, Common Lisp, Rust, Go, and Perl.
