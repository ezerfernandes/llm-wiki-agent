## Summary

[[AstonZhang|Zhang]], [[ZacharyLipton|Lipton]], [[MuLi|Li]] & [[AlexanderSmola|Smola]]'s fourteen-section *Computer Vision* chapter — D2L's first **Part 3 application chapter**, which leverages the [[CNN]] / [[ResNet]] / [[VGG]] backbones built in [[d2l-convolutional-neural-networks]] / [[d2l-convolutional-modern]] for the four canonical CV tasks beyond image classification: **object detection** (anchor-based + region-based), **semantic segmentation**, **style transfer**, and **competition-grade image classification**. The narrative arc is: extend classification with [[DataAugmentation|image augmentation]] (cheap regularization) and [[FineTuning|fine-tuning]] (transfer pretrained ImageNet features) → introduce [[BoundingBox|bounding-box]] / [[AnchorBox|anchor-box]] / [[IntersectionOverUnion|IoU]] / [[NonMaxSuppression|NMS]] / [[MultiscaleObjectDetection|multiscale-detection]] primitives → build the two model families ([[SSD]] single-stage and [[RCNN]] / [[FastRCNN]] / [[FasterRCNN]] / [[MaskRCNN]] two-stage) → pivot to pixel-level prediction with [[SemanticSegmentation]] + [[InstanceSegmentation]] + [[Pascal VOC2012]] → derive [[TransposedConvolution|transposed convolution]] as the upsampling primitive that makes pixel-level output shape-compatible with the input → assemble the [[FCN|fully convolutional network]] ([[JonathanLong|Long]], [[EvanShelhamer|Shelhamer]] & [[TrevorDarrell|Darrell]] 2015) on a pretrained ResNet-18 backbone → present [[StyleTransfer|Gatys neural style transfer]] (content loss + style loss via [[GramMatrix|Gram matrices]] + total-variation loss on a VGG-19 feature extractor) → close with two Kaggle case studies ([[CIFAR10]] image classification and dog breed identification on an ImageNet subset). The chapter establishes that "deep neural networks can effectively represent images in multiple levels, [and] such layerwise representations have been successfully used in various computer vision tasks" — making **layerwise / multiscale feature reuse** the unifying theme across detection / segmentation / style transfer.

## Key Claims

- **[[DataAugmentation|Image augmentation]] is cheap regularization.** Random flipping, cropping, color jitter (brightness/contrast/saturation/hue), and `RandomResizedCrop` expand the effective training set and reduce a model's dependence on object position, scale, or color. "It is probably true that image augmentation was indispensable for the success of [[AlexNet]] at that time." Applied only at training time; test-time predictions are deterministic. Combine via `torchvision.transforms.Compose`.
- **[[FineTuning|Fine-tuning]] is the canonical four-step [[TransferLearning|transfer-learning]] recipe.** (1) Pretrain a source model (e.g. [[ResNet|ResNet-18]]) on a large source dataset ([[ImageNet]]); (2) copy all weights except the output layer into a target model; (3) replace the output layer with a randomly-initialized head sized to the target task; (4) train end-to-end with a **smaller LR on copied layers** and a $10\times$-larger LR on the new head. "When target datasets are much smaller than source datasets, fine-tuning helps to improve models' generalization ability." The hot-dog binary classifier demo fine-tunes ResNet-18 from ~1000 ImageNet classes down to 2.
- **Bounding boxes have two equivalent representations.** `(x_1, y_1, x_2, y_2)` corner format or `(c_x, c_y, w, h)` center-width-height format. The chapter provides `box_corner_to_center` / `box_center_to_corner` round-trip-correct converters; matplotlib uses `Rectangle(xy=(x1,y1), width, height)`. Origin is the upper-left corner; +x right, +y down.
- **Anchor boxes parameterize object hypotheses by scale and aspect ratio.** Centered on each pixel, generate boxes of width $ws\sqrt{r}$ and height $hs/\sqrt{r}$ for scales $s\in(0,1]$ and aspect ratios $r>0$. To avoid the $whnm$ blowup, consider only the $n+m-1$ pairs containing $s_1$ or $r_1$, yielding $wh(n+m-1)$ anchors per image. Implemented in `multibox_prior(data, sizes, ratios)`.
- **[[IntersectionOverUnion|IoU = Jaccard index]] measures box similarity.** $J(A,B) = |A\cap B| / |A\cup B|$ on pixel sets, range $[0,1]$. Used both for matching anchor boxes to ground truth during labeling and for suppressing duplicates during prediction. Implemented as vectorized pairwise `box_iou(boxes1, boxes2)` returning a $|boxes_1|\times|boxes_2|$ matrix.
- **Anchor-box training labels = (class, offset).** Greedy assignment: repeatedly pick the highest-IoU pair in the IoU matrix and assign that ground-truth box to that anchor (discarding the row + column), until all ground-truth boxes are assigned; then for remaining anchors, assign the highest-IoU ground truth above an `iou_threshold` (default 0.5). Background → class 0. Offsets are encoded as $((x_b-x_a)/w_a - \mu_x)/\sigma_x$, $((y_b-y_a)/h_a)/\sigma_y$, $\log(w_b/w_a)/\sigma_w$, $\log(h_b/h_a)/\sigma_h$ with $\sigma_{xy}=0.1$, $\sigma_{wh}=0.2$ — a normalization that yields more-uniformly distributed targets.
- **[[NonMaxSuppression|Non-maximum suppression (NMS)]] greedy-deduplicates predicted boxes.** Sort by class confidence; iteratively keep the top box and drop all remaining boxes whose IoU with it exceeds threshold $\epsilon$ (default 0.5). Implemented in `nms(boxes, scores, iou_threshold)` and the full pipeline in `multibox_detection(cls_probs, offset_preds, anchors)`. Soft-NMS (Bodla et al. 2017) is flagged as a learnable / softer alternative.
- **[[MultiscaleObjectDetection|Multiscale detection]] uses feature maps at different layers to detect objects of different sizes.** Generating anchors at every pixel of a $561\times728$ image yields >2M anchors. Instead: at each scale, place anchors on a *feature map* whose units' [[ReceptiveField|receptive fields]] match the target object size — smaller feature maps (closer to output, larger receptive fields) → detect larger objects. The CNN's hierarchical features themselves provide the multiscale pyramid; the same $c$-channel feature vector at a spatial position is transformed into class + offset predictions for the $a$ anchors centered there.
- **[[SSD|Single-Shot Multibox Detection]] (SSD) is the canonical single-stage detector.** [[WeiLiu|Liu]] et al. 2016. Base CNN ([[VGG]] or [[ResNet]] truncated before the classifier) → several **multiscale feature-map blocks** that halve the spatial dims and grow the receptive field at each step → at every block, attach a class-prediction conv ($a(q+1)$ output channels) and a bbox-prediction conv ($4a$ output channels) that share weights across spatial positions. Anchors from all scales are concatenated; one shot, no region proposals. Loss = class cross-entropy + smooth-L1 on offsets (mask out background).
- **The R-CNN family is the two-stage detector lineage.** **[[RCNN]]** ([[RossGirshick|Girshick]] et al. 2014): selective search → 2000 region proposals → resize → CNN forward pass *per proposal* → SVMs for classes + linear regressor for box offsets. Slow (thousands of forward passes). **[[FastRCNN]]** (Girshick 2015): one CNN forward pass on the whole image, then [[ROIPooling|RoI pooling]] extracts fixed-shape $h_2\times w_2$ features per proposal, then FC + softmax + bbox regression. **[[FasterRCNN]]** ([[ShaoqingRen|Ren]], [[KaimingHe|He]], [[RossGirshick|Girshick]] et al. 2015): replace selective search with a *jointly trained* [[RegionProposalNetwork|Region Proposal Network]] (3×3 conv → per-pixel anchor box/binary classification + bbox regression → NMS → RoI pooling). **[[MaskRCNN]]** ([[KaimingHe|He]], [[GeorgiaGkioxari|Gkioxari]], [[PiotrDollar|Dollár]] & Girshick 2017): swap RoI pooling for [[ROIAlign|RoI align]] (bilinear interpolation preserves spatial info) and add a per-RoI pixel-level mask head via an FCN — extending Faster R-CNN from detection to instance segmentation.
- **[[SemanticSegmentation|Semantic segmentation]] predicts a class for every pixel.** Distinguished from (a) image segmentation (clustering pixels by low-level similarity, no semantics) and (b) [[InstanceSegmentation|instance segmentation]] (pixel-level *and* distinguish different instances of the same class). Canonical dataset: [[PascalVOC2012]] — 21 classes (20 + background), encoded as a fixed RGB colormap so the label image is shape-matched to the input image (no random scaling — random crops on (image, label) pairs are the only safe augmentation).
- **[[TransposedConvolution|Transposed convolution]] (= fractionally-strided convolution) is the upsampling primitive.** Where regular convolution *reduces* a $n_h\times n_w$ input via a $k_h\times k_w$ kernel to a smaller output, transposed convolution *broadcasts* each input element by the kernel and sums to produce a $(n_h + k_h - 1)\times(n_w + k_w - 1)$ output. Padding is applied to the *output* (not the input); stride is specified for *intermediate results* (not input strides). For stride $s$, padding $s/2$, kernel $2s$, transposed convolution increases spatial dims by exactly $s$×. The transpose interpretation: if a regular conv corresponds to matrix multiplication $\mathbf{y} = \mathbf{W}\mathbf{x}$, the transposed conv with the same kernel corresponds to $\mathbf{x}' = \mathbf{W}^\top \mathbf{y}'$. [[BilinearInterpolation|Bilinear interpolation]] can be encoded as a fixed transposed-conv kernel and is the standard initialization for FCN's upsampling layer.
- **[[FCN|Fully Convolutional Networks]] make CNNs shape-preserving.** [[JonathanLong|Long]], [[EvanShelhamer|Shelhamer]] & [[TrevorDarrell|Darrell]] 2015. Take a pretrained ImageNet CNN ([[ResNet|ResNet-18]]); strip the global average pool + FC head; insert a $1\times1$ conv mapping $C$ feature channels to $K=21$ class channels; then a transposed-conv layer (kernel 64, padding 16, stride 32) that exactly inverts the 32× spatial reduction. Output is `(batch, K, H, W)` with one class logit per pixel. Train end-to-end with per-pixel softmax cross-entropy on Pascal VOC2012. The transposed-conv layer is **initialized with bilinear-interpolation weights** as a learnable upsampler.
- **[[StyleTransfer|Neural Style Transfer]] iteratively optimizes a synthesized image, not the network.** [[LeonGatys|Gatys]], [[AlexanderEcker|Ecker]] & [[MatthiasBethge|Bethge]] 2016. Freeze a pretrained [[VGG|VGG-19]]; pick a **content layer** (deeper, semantic) and several **style layers** (spread across blocks, all-scales texture). Initialize a synthesized image (e.g. as the content image); the synthesized image *is the only trainable variable*. Loss = (i) **content loss** — MSE between synthesized and content image features at the content layer; (ii) **style loss** — MSE between the [[GramMatrix|Gram matrices]] of feature activations at each style layer; (iii) **total variation loss** — neighboring-pixel-difference penalty to suppress noise. Total = $w_c L_\text{content} + w_s L_\text{style} + w_{tv} L_\text{tv}$, optimized end-to-end via backprop *into the image pixels*.
- **Kaggle capstones bridge from toy datasets to real competitions.** [[CIFAR10]] (50k train / 300k test, 32×32 RGB, 10 classes): the chapter walks through reorganizing raw png files + labels.csv into the train/valid/test directory structure, dataset class, augmentations (resize-and-crop, flip, normalize), training a ResNet-18 variant, and submitting predictions. **Dog Breed Identification** (10222 train / 10357 test, 120 breeds, an ImageNet subset): same workflow scaled up to higher-resolution variable-size images; demonstrates ImageNet-style normalization mean/std `[0.485, 0.456, 0.406] / [0.229, 0.224, 0.225]` and fine-tuning a pretrained ResNet-34. Both serve as "everything-you-need-to-ship-a-classifier-end-to-end" walk-throughs.
- **The unifying theme: layerwise / multiscale feature reuse across CV tasks.** Image augmentation regularizes the input; fine-tuning reuses pretrained features at the parameter level; SSD reuses them at multiple feature-map scales; FCN reuses them as pixel-level semantic encoders; style transfer reuses them as content-and-style feature extractors. Every model in the chapter is **built on top of a pretrained ImageNet CNN** (VGG / ResNet) — the ImageNet-pretraining-as-foundation paradigm that NLP would later mirror with [[BERT]] / [[GPT]] in the [[d2l-attention-and-transformers|Attention chapter]].

## Key Quotes

> "Image augmentation generates similar but distinct training examples after a series of random changes to the training images, thereby expanding the size of the training set. Alternatively, image augmentation can be motivated by the fact that random tweaks of training examples allow models to rely less on certain attributes, thereby improving their generalization ability." — §`image-augmentation`, framing data augmentation as the cheapest regularizer in deep learning's toolkit.

> "When target datasets are much smaller than source datasets, fine-tuning helps to improve models' generalization ability." — §`fine-tuning`, the one-sentence justification for ImageNet pretraining → downstream-task fine-tuning that has defined applied CV (and now NLP / LLMs) for a decade.

> "Intersection over union (IoU), also known as Jaccard index, measures the similarity of two bounding boxes. It is the ratio of their intersection area to their union area." — §`anchor`, defining the single most-cited similarity measure in object detection.

> "Non-maximum suppression is a greedy algorithm that suppresses predicted bounding boxes by *removing* them. Is it possible that some of these removed ones are actually useful? How can this algorithm be modified to suppress *softly*?" — §`anchor` exercises, framing the Soft-NMS (Bodla et al. 2017) research direction as a natural next step beyond hand-crafted greedy suppression.

> "In contrast to the regular convolution that *reduces* input elements via the kernel, the transposed convolution *broadcasts* input elements via the kernel, thereby producing an output that is larger than the input." — §`transposed-conv`, the one-sentence intuition for the upsampling primitive that powers FCN, U-Net, GANs, and diffusion-model decoders.

> "We will leverage layerwise representations of a CNN to automatically apply the style of one image to another image, i.e., *style transfer*." — §`neural-style`, restating Gatys et al. 2016's central insight that CNN features encode style and content at different layers — a hypothesis that has since been generalized to text-image diffusion editing (DDIM inversion, attention-map control) and audio neural style transfer.
