## Summary
This task asks the contributor to write a beginner-oriented guide that walks a programmer (already fluent in some other language) through everything needed to get a "Hello world" program running in the target language. Rather than just showing code, the focus is on the surrounding toolchain: installing the language, choosing or installing a text editor or IDE, compiling/running the example, and locating the output. The key insight is that the hard part of adopting a new language is often the environment setup, not the code itself.

## Task Requirements
- Guide a newcomer through installing the programming language and selecting a text editor if one is needed.
- Run the language's example from the [[Hello world/Text]] task.
- Assume the reader is a competent programmer in another language and can install software for their platform.
- Link to and summarize existing official documentation rather than duplicating it.
- State explicitly where the output can be viewed (terminal, GUI window, file, etc.).
- Explain installation of any non-standard required IDEs or editors.
- Use sub-headings when giving instructions for multiple platforms; prefer the language's most natural output method.

## Language Coverage
118 languages implement this task, spanning compiled systems languages, scripting languages, functional languages, and many BASIC dialects, reflecting how setup instructions vary widely across ecosystems. Representative entries include C, C++, Rust, Go, Python, Java, JavaScript, Haskell, Ruby, and Perl, alongside niche environments like ZX Spectrum Basic and various assembly variants.
