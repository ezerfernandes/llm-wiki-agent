## Summary
This task demonstrates the `while` loop — the most basic pre-tested (entry-controlled) iteration construct, where the condition is checked before each pass. The programmer starts an integer at 1024, and while it is greater than zero, prints the value followed by a newline and halves it. With integer division, the value reaches zero after 11 iterations, terminating the loop.

## Task Requirements
- Start an integer value at 1024.
- Loop while the value is greater than zero.
- On each pass through the loop, print the value followed by a newline.
- Divide the value by two each time through the loop.
