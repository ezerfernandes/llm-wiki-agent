## Summary
This task asks the programmer to write a solver for the 24 game: given four digits (entered by the user or randomly generated), produce an arithmetic expression using each digit exactly once that evaluates to 24. The key insight is that the search space is small and finite — it can be brute-forced by enumerating all permutations of the digits, all combinations of the four binary operators, and all parenthesizations, then checking which expressions equal 24.

## Task Requirements
- Take four digits, either from user input or via random generation.
- Compute arithmetic expressions following the rules of the 24 game (use each digit once with +, -, *, / to reach 24).
- Show examples of solutions generated by the program.
