## Summary
This task asks the programmer to document the common flow-control structures available in a given language — the constructs that direct the order in which statements execute, beyond simple top-to-bottom sequencing. The canonical example cited is the `goto` jump, but the task is deliberately open-ended, inviting coverage of breaks, continues, returns, exceptions, labels, and non-local exits. Conditional and loop structures are explicitly carved out into their own companion tasks.

## Task Requirements
- Document the common flow-control structures the language provides.
- The `goto` construct is given as one representative example.
- Conditional structures and loop/iteration structures are excluded here (they have dedicated tasks).

## Language Coverage
84 languages implement this task, spanning assembly languages where flow control is raw jumps and branches, through structured and functional languages with richer mechanisms. Representative entries include C, C++, C#, Java, Python, Perl, Ruby, Go, Haskell, OCaml, Forth, and assembly variants such as 6502, 68000, and Z80 Assembly.
