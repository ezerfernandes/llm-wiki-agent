## Summary
An adversarial example is an instance with small, intentional feature perturbations that cause a machine learning model to make a false prediction. I recommend reading the chapter about [Counterfactual Explanations](#counterfactual) first, as the concepts are very similar. Adversarial examples are counterfactual examples with the aim to deceive the model, not interpret it.

## Key Claims
- **Methods and examples** — There are many techniques to create adversarial examples.
- **The cybersecurity perspective** — Machine learning deals with known unknowns: predicting unknown data points from a known distribution.
