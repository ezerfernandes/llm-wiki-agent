## Summary
This Rosetta Code task introduces collections as abstractions for representing groups of values. The programmer must create a collection and add a few values to it. The key insight is that in statically-typed languages the elements typically share a common data type, whereas dynamically-typed languages often allow heterogeneous values, so the idiomatic "collection" varies widely by language.

## Task Requirements
- Create a collection.
- Add a few values to it.

## Language Coverage
108 languages implement this task, reflecting that nearly every language ships some built-in or library collection type. Representative entries include Python, Java, C#, C++, Haskell, Ruby, Rust, Go, JavaScript, Clojure, and Lua, ranging from dynamic list/dictionary literals to statically-typed generic containers and assembly-level array layouts.
