## Summary
This task asks the programmer to demonstrate their language's support for inner (nested) classes — a class declared entirely within the body of another class or interface. The key distinction is that an inner class is not the same as a subclass: nesting concerns lexical scope and containment, whereas subclassing concerns inheritance (though an inner class may also be a subclass). Languages lacking native support are expected to describe how to simulate the structure.

## Task Requirements
- Explain what support the language offers for inner/nested classes, or, if none, what can be done to simulate them.
- Illustrate by creating an inner class that has a constructor, an instance method, and a field.
- Show how to instantiate the inner class.
- If the language is not object-oriented, the task may be omitted or substituted with an equivalent structure.

## Language Coverage
15 languages implement this task, spanning class-based OO languages, prototype-based languages, and array/functional languages that simulate nesting. Representative examples include Ada, C++, Go, J, Java, JavaScript, Julia, Perl, Python, Raku, and Wren.
