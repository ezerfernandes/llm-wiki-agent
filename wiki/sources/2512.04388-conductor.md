## Summary
Sakana AI introduces the **Conductor**, a 7B reasoning model trained end-to-end with reinforcement learning to design multi-agent workflows for stronger worker LLMs. The Conductor outputs three Python lists per task — natural-language subtasks, worker IDs, and per-step access lists — letting it freely shape topologies (BoN, sequential chains, trees) plus targeted prompt engineering. With randomized agent pools and a recursive option that lets the Conductor select itself, the model attains state-of-the-art on LiveCodeBench and GPQA Diamond while outperforming costlier multi-agent baselines.

## Key Claims
- **End-to-end RL coordination** — language-model coordination strategies emerge from reward maximization without explicit prompt-engineering supervision; uses GRPO with a two-tier (format / correctness) reward.
- **7B beats heavyweights via orchestration** — a 7B Conductor surpasses any individual worker on its training dataset and beats prior multi-agent methods at lower call cost.
- **Workflow representation** — each step is a `(subtask string, worker id, access list)` tuple; output structure is parsed from a single chain-of-thought response (Figure 2).
- **Adaptability to arbitrary worker pools** — finetuning with randomized agents at each step generalizes to open- and closed-source workers, removing dependence on a fixed agent set.
- **Recursive topologies as a new TTS axis** — allowing the Conductor to address itself unlocks online iterative adaptation as a tunable inference-time scaling dimension.

## Key Quotes
> "A 7B Conductor attains state-of-the-art results on challenging reasoning benchmarks such as LiveCodeBench and GPQA Diamond."
