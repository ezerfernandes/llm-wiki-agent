## Summary
This task asks the programmer to write a `for` loop that counts down rather than up, printing a countdown from 10 to 0 inclusive. The key idea is exercising a loop construct with a negative step (decrementing the loop index), which contrasts with the more common ascending loop and tests how each language expresses reverse iteration.

## Task Requirements
- Write a `for` loop (not a while loop) that writes a countdown.
- The countdown must run from 10 down to 0, inclusive.

## Language Coverage
203 languages implement this task, making it one of the broadest entries in the loop-task family and covering nearly every paradigm and era. Representative implementations include C, Python, Rust, Java, Haskell, COBOL, Forth, Fortran, Lua, and several assembly dialects such as 6502 Assembly and Z80 Assembly.
