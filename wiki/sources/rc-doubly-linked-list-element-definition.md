## Summary
This task asks the programmer to define the data structure for a single element (node) of a doubly-linked list. The element must store a value and hold pointers to both its successor and predecessor in the list. The defining trait of a doubly-linked list element, versus a singly-linked one, is this bidirectional linkage, which permits traversal in either direction.

## Task Requirements
- Define an element type for a doubly-linked list.
- Include a data member holding the element's value.
- Include a pointer to the next element in the list.
- Include a pointer to the previous element in the list.
- Both pointers must be mutable.
