## Summary
This task asks the programmer to write a function that returns the factorial of a number, where the factorial of n is the product of the sequence n, n-1, n-2, ..., 1, and the factorial of 0 is defined as 1. The key insight is that factorial is a canonical example for demonstrating both iterative and recursive function definitions, making it a classic introductory exercise. Trapping errors on negative inputs is optional.

## Task Requirements
- Write a function that returns the factorial of a given number.
- Treat the factorial of 0 as 1 (unity).
- Compute the factorial of a positive integer n as the product n * (n-1) * ... * 1.
- The solution may be implemented iteratively or recursively.
- Support for trapping negative-n errors is optional.
