## Summary
Chapter 8 of OpenStax [[Prealgebra]] 2e is the capstone equation-solving chapter: it assembles the four [[PropertiesOfEquality|Properties of Equality]] (Subtraction, Addition, Division, Multiplication) into a single **General Strategy for Solving Linear Equations**. It moves from one-step equations (Ch 8.1–8.2), to multi-step equations with variables and constants on **both sides** (Ch 8.3), to equations with **fraction or decimal coefficients** that are first cleared via the [[LeastCommonMultiple|LCD]] (Ch 8.4). The throughline is "do the same thing to both sides to keep the equation balanced," with every solution **checked** by substitution into the original equation. See [[SolvingLinearEquations]] for the consolidated strategy.

## Sections
- **8.1 — Subtraction and Addition Properties of Equality.** Defines a *solution* and how to check one; states the Subtraction and Addition Properties; solves one-step equations `x + a = b` and `x − a = b`; translates word sentences into equations using equals-keywords; applies a 7-step problem-solving strategy.
- **8.2 — Division and Multiplication Properties of Equality.** States the Division and Multiplication Properties; isolates the variable by **undoing** multiplication (divide) or division (multiply); handles negative coefficients (`−r = 2` ⇒ rewrite `−1·r`), fractional coefficients (multiply by the [[Reciprocal|reciprocal]]), and simplifying both sides first.
- **8.3 — Variables and Constants on Both Sides.** Introduces the full **General Strategy**: simplify each side, collect variable terms to one side and constants to the other (Addition/Subtraction Property), reduce the coefficient to 1 (Multiplication/Division Property), then check. Tip: put variables on the side with the **larger coefficient** to keep arithmetic easy.
- **8.4 — Fraction or Decimal Coefficients.** "Clearing the equation of fractions": multiply both sides by the **LCD of all fractions** to get an all-integer equivalent equation, then apply the General Strategy. Decimals are cleared the same way by multiplying by the appropriate power of 10 (or by treating them as fractions).
- **8-key-concepts** — chapter summary of the four properties and the general strategy.

## Key Concepts & Definitions
- **Solution of an equation** — "A value of a variable that makes a true statement when substituted into the equation." Checked by substituting, simplifying both sides via [[OrderOfOperations|order of operations]], and confirming the result is true.
- **Linear equation** — an equation reducible to `ax + b = c` (variable to the first power); see [[LinearEquation]].
- **Properties of Equality** — the four operations you may apply to *both sides* without changing the solution set ([[PropertiesOfEquality]]).
- **Clearing the equation of fractions** — multiplying both sides by the LCD of all fractions to produce an equivalent equation with only integer coefficients (Ch 8.4).
- **Coefficient of 1** — the goal of the last solving step: the variable stands alone with coefficient 1.

## Key Procedures / Rules
**The four Properties of Equality** (for real numbers `a, b, c`):
- **Subtraction:** if `a = b`, then `a − c = b − c`.
- **Addition:** if `a = b`, then `a + c = b + c`.
- **Division** ([[DivisionPropertyOfEquality]]), `c ≠ 0`: if `a = b`, then `a/c = b/c`.
- **Multiplication** ([[MultiplicationPropertyOfEquality]]): if `a = b`, then `ac = bc`.

**General Strategy for Solving Linear Equations** (Ch 8.3 "How To"):
1. **Simplify each side** as much as possible — use the [[DistributiveProperty|Distributive Property]] to remove parentheses and **combine like terms**.
2. **Collect all variable terms to one side** using the Addition or Subtraction Property of Equality.
3. **Collect all constant terms to the other side** using the Addition or Subtraction Property of Equality.
4. **Make the variable's coefficient equal to 1** using the Multiplication or Division Property of Equality.
5. **Check** the solution by substituting it into the *original* equation.

**Clearing fractions / decimals** (Ch 8.4 "How To"):
1. Find the **LCD of all the fractions** in the equation.
2. **Multiply both sides** by that LCD — this clears the fractions (for decimals, multiply by the matching power of 10).
3. Solve using the General Strategy for Solving Linear Equations.

**Translating word sentences:** locate the equals-word(s) (*is, is equal to, is the same as, the result is, gives, was, will be*) → `=`; translate each side into an [[AlgebraicExpression|expression]]. Application problems use a 7-step problem-solving strategy (read, identify the unknown, choose a variable, translate to an equation, solve, check for reasonableness, answer in a sentence).
