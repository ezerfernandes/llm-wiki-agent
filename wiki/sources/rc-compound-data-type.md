## Summary
This task asks the programmer to define a compound data type — a structure that bundles multiple independent values under a single named type. The canonical example is a `Point(x, y)` holding two coordinates. The point is to show how each language expresses aggregation: records, structs, classes, tuples, or named fields.

## Task Requirements
- Create a compound data type that holds multiple independent values.
- Use the example of `Point(x, y)`, a type aggregating two coordinate fields.

## Language Coverage
146 languages implement this task, spanning the full range of paradigms from low-level assembly to functional and dynamic languages. Representative entries include C, C++, Rust, Go, Python, Haskell, OCaml, Java, Ada, Common Lisp, and Pascal, which variously model the type as a struct, record, class, tuple, or algebraic data type.
