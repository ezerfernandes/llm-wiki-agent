## Summary
Front matter for [[WesMcKinney]]'s *Python for Data Analysis 3rd Edition*. Open-access web edition hosted at wesmckinney.com/book as a companion to the print/digital O'Reilly releases. Third edition updates content for Python 3.10, current [[pandas]] and [[NumPy]] APIs; conservative about post-2022 libraries to extend shelf life.

## Key Claims
- **Third edition (2022)** — content brought up to date with Python 3.10, NumPy, pandas; held conservative on newer projects to avoid rapid obsolescence.
- **Open access via [[Quarto]]** — J.J. Allaire helped port the book from Docbook XML to Quarto for the web edition.
- **In Memoriam John D. Hunter (1968–2012)** — creator of [[matplotlib]]; close to Fernando Pérez and Brian Granger ([[IPython]] / [[Jupyter]] pioneers).
- **pandas origin** — built starting 2008 at [[AQRCapitalManagement]]; community-owned project since ~2013 with 2000+ contributors.
