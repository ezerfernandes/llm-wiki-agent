## Summary
Given a string of ordered DNA bases (the nucleotides A, C, G, and T), the task is to "pretty print" the sequence and then report how many times each base occurs. The core operation is a simple frequency count over a fixed four-symbol alphabet, with the formatting (line-wrapped output, optional position indices) being the main presentation concern.

## Task Requirements
- Take the given 500-character DNA sequence string as input.
- "Pretty print" the sequence in a readable, line-wrapped layout.
- Count the occurrences of each base: A, C, G, and T.
- Print the total count of each base, and typically the overall total.
