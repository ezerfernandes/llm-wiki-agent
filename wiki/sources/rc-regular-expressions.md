## Summary
This text-processing task asks the programmer to demonstrate basic use of regular expressions in their language. Two operations are required: testing whether a string matches a regex pattern, and performing a regex-based substitution that replaces part of a string. The key insight is that most modern languages provide regex either as built-in syntax or via a standard library, so the task largely surveys how each language exposes those two fundamental capabilities.

## Task Requirements
- Match a string against a regular expression.
- Substitute part of a string using a regular expression.

## Language Coverage
112 languages implement this task, showing very broad coverage across scripting, functional, and systems languages, reflecting how universal regex support has become. Representative implementations include Perl, Python, Ruby, JavaScript, Java, C#, Go, Rust, Haskell, and Tcl.
