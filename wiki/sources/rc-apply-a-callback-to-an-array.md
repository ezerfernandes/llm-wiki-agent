## Summary
This task asks the programmer to take a collection of elements held in an array and apply a given function (a callback) to every element. The core insight is the higher-order function pattern: passing a function as a value to another routine that iterates over the data, the canonical "map" operation found across functional and procedural languages alike.

## Task Requirements
- Take a combined set of elements (an array).
- Apply a function to each element of that set.

## Language Coverage
203 languages implement this task, making it one of the most broadly covered entries and a near-universal idiom.
