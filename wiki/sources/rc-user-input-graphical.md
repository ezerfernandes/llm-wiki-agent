## Summary
This task asks the programmer to obtain input from the user through a graphical user interface rather than the console. Specifically, the program must accept a text string and the integer value 75000 entered via GUI widgets. The key point is demonstrating how each language's toolkit captures input from windows, dialogs, or text fields.

## Task Requirements
- Read a string from a graphical user interface.
- Read the integer 75000 from a graphical user interface.
- Requires graphics/GUI capability (it is the GUI counterpart to the console-based User input/Text task).

## Language Coverage
66 languages implement this task, spanning compiled and interpreted languages plus many BASIC dialects, reflecting the wide variety of GUI toolkits available. Representative implementations include C, C++, Java, JavaScript, Python, Ruby, Go, Haskell, Tcl, and Scala.
