## Summary
The task asks the programmer to render the Barnsley fern, a fractal that resembles a black spleenwort fern and is generated by an iterated function system (IFS). Starting from the point (0, 0), one of four affine transformations is repeatedly applied, each chosen at random with a fixed probability, and the resulting points are plotted. The key insight is that a simple stochastic "chaos game" over a few affine maps converges onto an intricate self-similar fractal attractor.

## Task Requirements
- Plot the fractal fern using an iterated function system with four affine transformations.
- Select transformation f1 1% of the time: x' = 0, y' = 0.16 y.
- Select f2 85% of the time: x' = 0.85 x + 0.04 y, y' = -0.04 x + 0.85 y + 1.6.
- Select f3 7% of the time: x' = 0.2 x - 0.26 y, y' = 0.23 x + 0.22 y + 1.6.
- Select f4 7% of the time: x' = -0.15 x + 0.28 y, y' = 0.26 x + 0.24 y + 0.44.
- Begin iteration from the starting position x = 0, y = 0.
