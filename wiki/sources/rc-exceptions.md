## Summary
This task asks the programmer to demonstrate a language's exception-handling mechanism: write a routine that catches and handles an exception, and also "throw" (raise) a new exception of one's own. It illustrates the standard try/catch/finally style of structured error handling versus alternatives like error codes or condition systems, exposing how each language separates normal control flow from error recovery.

## Task Requirements
- Provide an example of an exception-handling routine that catches and handles an exception.
- Throw (raise) a new, custom exception within that example.

## Language Coverage
115 languages implement this task, showing very broad coverage across paradigms from imperative and object-oriented to functional and even assembly. Representative implementations include C++, Java, C#, Python, Ruby, Rust, Go, Haskell, Common Lisp, Erlang, Swift, and 8086 Assembly.
