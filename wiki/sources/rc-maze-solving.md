## Summary
This task asks the programmer to write a function that finds and displays the shortest path between two cells in a maze produced by the companion Maze generation task. The key insight is that because such mazes are built with a depth-first-search generation algorithm, they form a tree with no circular paths (loops), so a single simple depth-first tree search is guaranteed to find the one and only path between any two cells — that path is therefore necessarily the shortest.

## Task Requirements
- Take as input a maze generated by the related Maze generation task.
- Implement a function that locates the path between two given cells.
- Because the maze is acyclic (a spanning tree), a plain depth-first search suffices; no general shortest-path machinery is required.
- Display the resulting path overlaid on or alongside the maze.
