## Summary
This Rosetta Code task asks the programmer to create an enumeration — a set of named constants — both with explicitly assigned values and without. The key insight is that enumerations bind human-readable symbolic names to (usually integer) values, and most languages either provide a dedicated `enum` construct or simulate one with a sequence of named constants whose values auto-increment when left unspecified.

## Task Requirements
- Create an enumeration of constants.
- Show the case where constants are given explicit values.
- Show the case where constants are declared without explicit values (typically relying on automatic/default assignment).

## Language Coverage
113 languages implement this task, spanning the breadth of typed and untyped paradigms — from systems and assembly languages to scripting and functional ones. Representative implementations include C, C++, C#, Java, Rust, Go, Python, Haskell, OCaml, Ada, and Swift.
