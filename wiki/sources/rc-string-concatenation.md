## Summary
This basic language-learning task asks the programmer to create a string variable holding any text value, then build a second string variable whose value is the first variable concatenated with another string literal. The content of both variables is then displayed. The key insight is illustrating how a given language expresses string joining — whether via an operator (`+`, `.`, `&`, `,`), a function, or an interpolation construct.

## Task Requirements
- Create a string variable equal to any text value.
- Create another string variable whose value is the original variable concatenated with another string literal.
- Show the contents of the variables to illustrate the operation.

## Language Coverage
210 languages implement this task, making it one of the most broadly covered entries — nearly every general-purpose language has an idiomatic answer. Representative implementations include Python, JavaScript, C, C++, Java, Haskell, Ruby, Rust, Go, Lua, and Perl.
