## Summary
This task asks the programmer to demonstrate how to attach documentation to classes, functions, and variables in their language. The key distinction it draws out is whether documentation support is built into the language (special doc comment syntax recognized by the toolchain) or requires external tools to extract and render it. It surveys the wide variety of conventions used across languages, from structured docstrings to specially formatted comments.

## Task Requirements
- Show how to insert documentation for classes, functions, and/or variables in the language.
- If the documentation facility is built into the language, note that.
- If it requires external tools, name those tools.

## Language Coverage
74 languages implement this task, reflecting how every mature ecosystem has its own documentation convention. Representative examples include Python (docstrings + Sphinx), Java (Javadoc), C# (XML doc comments), Haskell (Haddock), Rust (rustdoc `///`), Go (godoc), Ruby (RDoc), Perl (POD), and Common Lisp (docstrings).
