## Summary
Lin, Liu, Pan et al. (Fudan + Peking U + Shanghai Qiji Zhifeng) introduce **Agentic Harness Engineering (AHE)** — a closed-loop framework that automates the previously manual craft of coding-agent harness design. AHE rests on three matched **observability pillars**: ❶ **component observability** exposes seven editable harness component types as files at fixed mount points; ❷ **experience observability** distills millions of raw trajectory tokens into a layered drill-down evidence corpus; ❸ **decision observability** pairs every edit with a self-declared prediction verified against the next round's task-level outcomes. Ten iterations lift Terminal-Bench 2 pass@1 from **69.7% → 77.0%**, beating human-designed Codex CLI (71.9%) and self-evolving baselines ACE (68.9%) and TF-GRPO (72.3%). The frozen harness transfers cross-benchmark (SWE-bench-verified at 12% fewer tokens) and cross-base-model (+5.1 to +10.1 pp on three alternate model families).

## Key Claims
- **Harness, not just model.** Long-horizon coding-agent performance is materially shifted by harness design even with the base model held fixed; optimal harnesses are model-specific and must be re-adapted as base models change.
- **Bottleneck is observability, not optimizer capability.** Once the evolution agent receives structured context over a clear action space, it converges reliably on better harness designs.
- **Seven editable component types.** System prompt, tool description, tool implementation, middleware, skill, sub-agent configuration, long-term memory — each at a fixed mount point in the **NexAU** framework, loosely coupled so component-level edits don't cascade.
- **Falsifiable-contract evolution.** A change manifest pairs each edit with a prediction; if the next round disconfirms the prediction at task-level outcome, the edit is reverted at file granularity. Prevents the loop from collapsing into trial-and-error.
- **Empirical gains.** Terminal-Bench 2 pass@1 69.7 → 77.0% over 10 iterations. SWE-bench-verified: best aggregate success at 12% fewer tokens than the seed without re-evolution. Cross-family +5.1 to +10.1 pp gains on three alternate base-model families — largest where the base model is furthest from saturation.
- **Where the gains live (ablation).** Tools, middleware, and long-term memory each carry the improvement on their own; the system prompt alone regresses. **Factual harness structure transfers; prose-level strategy does not.**
- **Two limits acknowledged.** Components interact non-additively, capping aggregate gain when stacking edits; self-attribution is reliable for fixes but blind to regressions — regression foresight is named as the clearest open problem.

## Key Quotes
> "Harness engineering remains a manual craft, because automating it faces a heterogeneous action space across editable components, voluminous trajectories that bury actionable signal, and edits whose effect is hard to attribute."
> "Once the evolution agent receives structured context over a clear action space, it can reliably converge on better harness designs."
> "Factual harness structure transfers across tasks and models whereas prose-level strategy does not."
