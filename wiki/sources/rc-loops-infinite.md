## Summary
This task asks the programmer to write a loop that never terminates on its own, printing the word "SPAM" followed by a newline forever. It is one of the canonical Rosetta Code iteration exercises, isolating the simplest non-terminating control structure so each language's idiom for an unconditional loop can be compared directly.

## Task Requirements
- Print "SPAM" followed by a newline.
- Do so inside an infinite loop, so the output repeats indefinitely.

## Language Coverage
273 languages implement this task, making it one of the most broadly covered entries on the site and spanning everything from high-level scripting to raw assembly. Representative implementations include C, Python, Java, Haskell, Ruby, Rust, Go, Forth, and the UNIX Shell, alongside esoteric and assembly variants such as Brainf*** and 8086 Assembly.
