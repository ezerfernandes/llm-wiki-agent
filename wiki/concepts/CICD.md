# CI/CD

Continuous Integration / Continuous Deployment — automated pipelines that lint, test, build, and ship code on every change. In MLOps the pipeline extends through training, evaluation, [[CanaryDeployment]], and rollback; tightly coupled with [[Git]], [[GitHooks]], and [[ExperimentTracking]].
