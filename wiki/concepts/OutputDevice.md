# Output Device

An **output device** is a peripheral that **stores or displays the computer's results** — the fifth of the [[VonNeumannArchitecture|von Neumann architecture]]'s five functional units. Per [[dis-5-2-von-neumann|*Dive into Systems* Ch 5.2]]: monitor, speakers, printer, haptic actuators.

Some devices (touchscreens, storage drives, network interfaces) function as **both** input and output — see [[IODevice]] for the umbrella treatment.
