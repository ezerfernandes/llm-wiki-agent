# GUI Agents

**GUI agents** are AI agents that operate software by perceiving and manipulating its **Graphical User Interface** — clicking buttons, typing into fields, reading on-screen elements from screenshots — rather than calling APIs. This is the same capability covered in depth under [[ComputerUse|Computer Use]] in [[agentic-design-patterns-appendices-bg|*Agentic Design Patterns* Appendix B]] (Gulli): the evolution from conversational chatbots to active, task-oriented agents driven by **Agent–Computer Interfaces (ACIs)**.

## In Agentic Design Patterns (Gulli)
Appendix B describes the GUI-interaction loop (Visual Perception → GUI Element Recognition → Contextual Interpretation via an ACI module → Dynamic Action and Response) and names concrete GUI/computer-use agents: [[anthropic|Anthropic]] Computer Use (Claude), [[openai|OpenAI]] ChatGPT Operator, [[google|Google]] Project Mariner (Chrome), and the open-source [[BrowserUse]] library (high-level DOM API). See [[ComputerUse]] for the full treatment.
