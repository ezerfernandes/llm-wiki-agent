# Verification Levels

Fixed enum on every skill manifest: `unverified` (default — every irreversible call HITL'd), `declared` (signer attests caps bound side-effects), `tested` (passes adversarial-ensemble biconditional), `formal` (machine-checked proof — aspirational). Set offline at bootstrap and immutable for the session — a discrete decision auditable and atomically revocable, unlike a continuous trust score.
