# Sequential Deliberation

Second phase of HEAVYSKILL: a (possibly different) LLM aggregates the parallel-reasoning trajectories from a serialized memory cache. Functions as an implicit verifier that compares trajectories. Iterative deliberation re-feeds the deliberation output back into the cache for progressive refinement.
