# Absolute Value

The **absolute value** of a number `n`, written **`|n|`**, is its **distance from 0 on the [[NumberLine|number line]]**. Because distance is never negative, `|n| ≥ 0` for every number. OpenStax [[Prealgebra]] 2e defines it in Chapter 3.1 ([[prealgebra-2e-ch03-integers]]).

Since distance ignores direction, a number and its **opposite** have the **same** absolute value:

- `|5| = 5` and `|−5| = 5`
- `|0| = 0`
- `|−282| = 282`

Absolute value discards the **sign** but keeps the **magnitude** — it answers "how far from zero?", not "which side?".

## Using absolute value in expressions
The absolute-value bars act like grouping symbols in the [[OrderOfOperations|order of operations]]: **simplify the expression inside the bars first**, then take the absolute value. For example, `|−7 + 3| = |−4| = 4`. Absolute-value expressions can then be combined with other operations, e.g. `2|−3| − 1 = 2·3 − 1 = 5`, or compared with `<`, `>`, `=` (such as comparing `|−6|` with `|4|`).

Distinguish `−|n|` from `|−n|`: the leading minus in `−|n|` means "the opposite of the absolute value," so `−|7| = −7`, whereas `|−7| = 7`.
