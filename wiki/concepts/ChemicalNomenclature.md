# Chemical Nomenclature

**Chemical nomenclature** is the collection of [[IUPAC]] rules for systematically naming [[ChemicalCompound|compounds]] (e.g., NaCl, CaCO₃, N₂O₄). The rules differ for ionic compounds, molecular compounds, and acids.

## Ionic Compounds

**Monatomic ions** — name the cation (metal) then the anion (nonmetal with **-ide** suffix):
- NaCl → sodium chloride · Na₂O → sodium oxide · KBr → potassium bromide · CdS → cadmium sulfide

**Polyatomic ions** — cation name + polyatomic-ion name:
- NH₄Cl → ammonium chloride · NaHCO₃ → sodium bicarbonate · CaSO₄ → calcium sulfate · Al₂(CO₃)₃ → aluminum carbonate

**Variable-charge metals (Stock nomenclature)** — specify the metal's charge with a **Roman numeral** in parentheses:
- FeCl₂ → iron(II) chloride · FeCl₃ → iron(III) chloride · HgO → mercury(II) oxide · SnF₂ → tin(II) fluoride
- (Legacy -ic/-ous suffixes, e.g. ferric/ferrous, are now largely abandoned.)

**Hydrates** — add a Greek prefix + "hydrate" for waters of crystallization:
- CuSO₄·5H₂O → copper(II) sulfate pentahydrate · Na₂CO₃·10H₂O → sodium carbonate decahydrate

## Molecular (Covalent) Compounds

Name the more-metallic element first, then the second with **-ide**, using **Greek prefixes** for atom counts (mono- is omitted on the first element; a terminal prefix vowel drops before a vowel, e.g. monoxide):
- CO → carbon monoxide · CO₂ → carbon dioxide · SO₃ → sulfur trioxide · N₂O₄ → dinitrogen tetroxide · SF₆ → sulfur hexafluoride
- Common names persist: NO nitric oxide, N₂O nitrous oxide, H₂O water.

**Greek prefixes:** 1 mono-, 2 di-, 3 tri-, 4 tetra-, 5 penta-, 6 hexa-, 7 hepta-, 8 octa-, 9 nona-, 10 deca-.

## Acids

**Binary acids** (H + one nonmetal): hydrogen → **hydro-**, nonmetal + **-ic**, + "acid":
- HCl(aq) → hydrochloric acid · HF(aq) → hydrofluoric acid · H₂S(aq) → hydrosulfuric acid

**Oxyacids** (H + O + another element): drop "hydrogen", use the anion root, **-ate → -ic** / **-ite → -ous**, + "acid":
- H₂CO₃ → carbonic acid (carbonate) · HNO₃ → nitric acid (nitrate) · HNO₂ → nitrous acid (nitrite) · HClO₄ → perchloric acid (perchlorate) · H₂SO₄ → sulfuric acid · H₂SO₃ → sulfurous acid · H₃PO₄ → phosphoric acid
