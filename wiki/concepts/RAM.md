# Random-Access Memory (RAM)

**Random-access memory (RAM)** is the main working memory of a [[ComputerSystem|computer system]] — fast, volatile storage from which the [[CPU]] fetches instructions and data. Named in [[DiveIntoSystems]] Ch 0 as one of the four core hardware components alongside the [[CPU]], I/O ports, and secondary storage.

RAM sits in the middle of the [[MemoryHierarchy]] — much slower than CPU caches but much faster than disk/SSD/Flash. In modern compact systems it is often integrated directly into the [[SystemOnAChip|SoC]] alongside the CPU.
