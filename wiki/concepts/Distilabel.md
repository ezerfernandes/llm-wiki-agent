# distilabel

**`distilabel`** is [[Argilla|Argilla]]'s open-source AI-feedback library for **synthesizing and labeling LLM training data at scale** — particularly preference pairs for [[DPO]] / [[rlhf|RLHF]] and instruction-response pairs for [[SupervisedFinetuning|SFT]]. The library orchestrates pipelines of LLM-as-judge calls to produce, score, and clean datasets without per-example human labeling.

## In Hands-On LLMs Ch 12

[[hands-on-llm-ch12-fine-tuning-generation-models|Ch 12]] surfaces `distilabel` indirectly through its worked DPO dataset — **`argilla/distilabel-intel-orca-dpo-pairs`** — whose chosen/rejected labels and per-pair scores were generated by `distilabel` (the chapter describes the dataset as *"in part generated by ChatGPT with scores on which output should be accepted and which rejected"*). The `chosen_score >= 8` filter in Ch 12's data-loading code is filtering on the score `distilabel` produced.
