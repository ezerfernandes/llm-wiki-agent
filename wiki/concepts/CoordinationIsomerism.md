# Coordination Isomerism

**Isomers** are different chemical species with the **same chemical formula**. [[CoordinationCompound|Coordination compounds]] display a rich set of isomer types. (Chemistry-specific page name to avoid colliding with the generic "Isomerism" namespace.)

## Stereoisomers (same bonds, different spatial arrangement)

**Geometric isomers (cis/trans).** Same atoms, same bond types, different orientation in space. In an octahedral or square-planar complex with two ligands of one kind: **cis** = adjacent (90°); **trans** = directly across (180°). These are *different compounds with different properties*. Example: [Co(H₂O)₄Cl₂]⁺ is **violet and polar** in the cis form, **green and nonpolar** in the trans form (its dipoles cancel). [Pt(NH₃)₂Cl₂] has cis- and trans-diamminedichloroplatinum(II) isomers — only the **cis** isomer is the anticancer drug cisplatin.

**Optical isomers (enantiomers).** "Two objects are exact mirror images of each other but cannot be lined up so that all parts match" — **nonsuperimposable mirror images**. Enantiomers share identical bp, polarity, and solubility; they differ only in how they rotate plane-polarized light and how they react with *other* chiral species. [M(en)₃]ⁿ⁺ exists as enantiomers; natural right-handed DNA binds only one of them. **cis-[Co(en)₂Cl₂]⁺ is chiral (a pair of enantiomers); the trans isomer is not.**

## Structural isomers (different bonds/connectivity)

**Linkage isomers.** A single ligand binds through two *different* donor atoms. SCN⁻ via S vs N gives [Co(NH₃)₅SCN]²⁺ vs [Co(NH₃)₅NCS]²⁺; CN⁻ via C (cyano) vs N (isocyano).

**Ionization / coordination isomers.** An anionic ligand inside the coordination sphere is swapped with the counter ion outside it. Example: [CoCl₆][Br] vs [CoCl₅Br][Cl].
