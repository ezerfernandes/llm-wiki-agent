# Documentation

Written artifacts (READMEs, design docs, API references, tutorials) that explain how a system works and how to use it. Often layered: [[Docstrings]] → API reference → guides → architecture. A primary failure point in ML systems where [[CodeOrganization]] and dataset semantics are tribal knowledge.
