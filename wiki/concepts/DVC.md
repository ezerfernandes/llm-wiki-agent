# DVC

Data Version Control — a tool that adds [[Git]]-style versioning to large data and model artifacts by storing pointers in Git and blobs in remote object storage. Complements [[GitLFS]] for ML use cases and integrates into [[CICD]] and [[ExperimentTracking]] flows.
