## Definition
**Potential energy** (PE) is energy stored in a system because of the relative positions, shape, or configuration of its parts. It can be defined only for a [[ConservativeForce]], whose [[Work]] is path-independent. The stored energy is fully recoverable — it can be released back as [[KineticEnergy]].

## Key Points
- A property of a system (e.g., object + Earth), not of an isolated object; only differences in PE matter, so the zero reference is arbitrary.
- **Gravitational** PE near Earth: ΔPE_g = mgh (see [[GravitationalPotentialEnergy]]).
- **Elastic/spring** PE follows [[HookesLaw]]: PE_s = ½kx².
- With kinetic energy it forms [[MechanicalEnergy]], conserved under conservative forces.

## Equations
- ΔPE_g = m g h  (gravitational)
- PE_s = ½ k x²  (elastic)
- ΔKE + ΔPE = 0  (conservative forces)
