## Definition
Speed is a [[ScalarQuantity]] giving distance traveled per unit time. It has magnitude only — no direction — which distinguishes it from [[Velocity]].

## Key Points
- **Average speed** = distance traveled / elapsed time (uses [[Distance]] traveled, not [[Displacement]]).
- **Instantaneous speed** is the magnitude of instantaneous velocity.
- Average speed can exceed the magnitude of average velocity when the path reverses direction (because it uses path length, not displacement).
- A car speedometer displays instantaneous speed.
- Example: a round trip to a store gives average velocity = 0 but a nonzero average speed.

## Equations
- average speed = (distance traveled) / Δt
