# Just-In-Time Teaching

Pedagogical principle [[d2l-preface|D2L]] adopts as its organizing thesis: teach a concept *at the moment it is first needed to accomplish a practical end*, rather than front-loading all foundations exhaustively. Explicitly contrasted with [[Bishop2006|Bishop-style]] thorough-foundations-first ordering, which the preface acknowledges as excellent for experts but limiting for true beginners.

In D2L this is operationalized via:
- a brief preliminaries crash course up front (linear algebra + probability);
- "one working example, one notebook" — each chapter has self-contained runnable examples;
- "tools available before explaining them fully" — e.g. SGD is used before being motivated, leaving the reader to "trust us with some curatorial decisions";
- two implementations of each component (from-scratch with [[NumPy]] + [[Autograd|automatic differentiation]], then high-level-API).
