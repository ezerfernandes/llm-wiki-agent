# Data Lake

A storage architecture (typically object storage like S3) that holds raw, semi-structured, and structured data without enforcing schema-on-write. Contrast with [[DataWarehouse]] (schema-on-write) and the hybrid lakehouse pattern; common substrate for [[DataPipeline]] and ML feature backfills.
