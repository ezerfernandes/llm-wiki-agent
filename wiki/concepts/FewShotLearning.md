# Few-Shot Learning

Adapting a model to a new task from only a handful of labeled examples, typically by providing them in the prompt (in-context learning) for an LLM or via meta-learning for smaller models. Hallmark capability of [[transformer]] LMs; complements [[FineTuning]] when data is scarce.
