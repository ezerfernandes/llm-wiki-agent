# Git Hooks

Scripts [[Git]] runs at lifecycle events (pre-commit, pre-push, commit-msg). Typically managed via pre-commit.com to enforce [[CodeStyle]], lint, type-check, and run fast tests before code can land — the first line of defense before [[CICD]].
