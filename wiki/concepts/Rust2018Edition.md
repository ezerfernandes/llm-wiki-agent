# Rust 2018 Edition

Reference snapshot of [[RustLanguage|Rust]] language idioms released in late 2018. Editions let Rust evolve syntax / lints in opt-in steps without breaking existing crates — each crate declares its edition in `Cargo.toml`. The 2018 edition introduced the module-path / `use` reform, non-lexical lifetimes (NLL), and `?` in `main`, among others.

[[TheEmbeddedRustBook]] explicitly targets the 2018 edition: "you should also be familiar with the idioms of the 2018 edition as this book targets Rust 2018" ([[rust-embedded-book-intro-index]]).
