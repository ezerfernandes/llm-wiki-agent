# Code Organization

The discipline of structuring a project into modules, packages, and layers so it remains comprehensible and modifiable as it grows. Closely tied to [[CodeStyle]], [[Documentation]], [[Docstrings]], and the ability to add [[IntegrationTesting]] without invasive refactors.
