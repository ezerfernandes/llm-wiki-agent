# Identity, Inverse, and Zero Properties

This page collects three closely related families of [[RealNumbers|real-number]] properties from OpenStax [[Prealgebra]] 2e (Chapter 7, [[prealgebra-2e-ch07-properties-of-real-numbers]], §7.4): the **identity** elements of addition and multiplication, the **inverses** that undo them, and the special behavior of **zero**.

## Identity properties
An **identity** is the number that leaves a value unchanged under an operation.

- **Additive identity** `0`: adding zero changes nothing — `a + 0 = a` and `0 + a = a`.
- **Multiplicative identity** `1`: multiplying by one changes nothing — `a · 1 = a` and `1 · a = a`.

## Inverse properties
An **inverse** is the number that combines with `a` to give back the identity.

- **Additive inverse** (the **opposite**), written `−a`: a number plus its opposite is the additive identity — `a + (−a) = 0`. (See [[Integer]] for opposites and the meanings of the `−` sign.)
- **Multiplicative inverse** (the **[[Reciprocal|reciprocal]]**), written `1/a` for `a ≠ 0`: a number times its reciprocal is the multiplicative identity — `a · (1/a) = 1`.

So `−a` undoes adding `a`, and `1/a` undoes multiplying by `a`.

## Properties of zero
Zero behaves uniquely under multiplication and division:

- **Multiplication by zero:** the product of any real number and `0` is `0` — `a · 0 = 0` and `0 · a = 0`.
- **Zero as dividend:** zero divided by any *nonzero* number is `0` — `0/a = 0` for `a ≠ 0`.
- **Zero as divisor:** **division by zero is undefined** — `a/0` has no answer, because no real number times `0` could equal a nonzero `a` (and `0/0` is indeterminate). Always flag `a/0` as undefined rather than computing it.

## Using them together
These properties combine with the [[CommutativeProperty|commutative]] and [[AssociativeProperty|associative]] properties to simplify expressions: reorder/regroup so that opposites cancel to `0` (additive inverse) and reciprocals cancel to `1` (multiplicative inverse), then the identities clean up what's left. Example: `3x + 15 − 3x` reorders to `3x − 3x + 15 = 0 + 15 = 15`.
