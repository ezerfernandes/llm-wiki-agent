# Associative Property

The **associative property** says that, when you add or multiply **three or more** [[RealNumbers|real numbers]], **changing the grouping** (which pair you combine first) does not change the result. OpenStax [[Prealgebra]] 2e (Chapter 7, [[prealgebra-2e-ch07-properties-of-real-numbers]], §7.2) states it for the two operations:

- **Associative Property of Addition:** for real numbers `a, b, c`,  `(a + b) + c = a + (b + c)`  (e.g. `(7 + 8) + 2 = 7 + (8 + 2) = 17`).
- **Associative Property of Multiplication:** for real numbers `a, b, c`,  `(a · b) · c = a · (b · c)`  (e.g. `(5 · 1/3) · 3 = 5 · (1/3 · 3) = 5`).

The mnemonic: **associative = grouping** (which numbers go inside the parentheses). This is distinct from the [[CommutativeProperty|commutative property]], which is about *order*.

## Subtraction and division are NOT associative
Regrouping changes the value for the other two operations:

- `(8 − 4) − 1 = 3` but `8 − (4 − 1) = 5`.
- `(24 ÷ 4) ÷ 2 = 3` but `24 ÷ (4 ÷ 2) = 12`.

So neither subtraction nor division has an associative property.

## Using it
The associative property is the tool that lets you **regroup** after the [[CommutativeProperty|commutative property]] has let you **reorder**. Typical simplifications:

- combine **opposites** first: `−84n + (−73n) + 84n = −73n` after regrouping `−84n + 84n` together;
- combine **reciprocals** first: `7/15 · 8/23 · 15/7 = (7/15 · 15/7) · 8/23 = 8/23`;
- group **common-denominator** fractions: `(5/13 + 3/4) + 1/4 = 5/13 + (3/4 + 1/4) = 5/13 + 1`;
- group **round decimals**: `(6.47q + 9.99q) + 1.01q = 6.47q + (9.99q + 1.01q) = 17.47q`;
- absorb a **coefficient** into a product: `6(3x) = (6 · 3)x = 18x`.

Worked-example types in §7.2 include basic regrouping, evaluating an expression with substituted values to compare efficiency, and multi-term simplification that combines like terms.
