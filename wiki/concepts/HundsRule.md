# Hund's Rule

**Hund's rule** governs how electrons fill a set of **degenerate** orbitals (the 3 orbitals of a p subshell, 5 of a d, or 7 of an f):

> "The lowest-energy configuration for an atom with electrons within a set of degenerate orbitals is that having the maximum number of unpaired electrons."

Electrons therefore occupy separate degenerate orbitals **singly, with parallel spins**, before any orbital receives a second (opposite-spin) electron — minimizing electron-electron repulsion.

## Example
Nitrogen's 2p³ fills as [↑ | ↑ | ↑] (three unpaired, parallel), not [↑↓ | ↑ | ]. Carbon's 2p² is [↑ | ↑ | ].
