# JupyterLab

The next-generation [[Jupyter]] IDE — combines notebooks, terminals, file browser, and extensions in one browser-based workspace. Standard tool for exploratory data analysis, [[FeatureEngineering]] prototyping, and pairing with [[IPython]]/[[pandas]] interactively.
