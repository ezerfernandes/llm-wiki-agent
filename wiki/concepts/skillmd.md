# SKILL.md

Portable, harness-neutral file format for procedural knowledge added to LLM agents — text instructions plus referenced scripts. Curated SKILL.md libraries improve agent pass-rates on benchmarks like Mind2Web and Embodied Agent Interface; indiscriminate admission of self-generated skills can degrade or attack agent behavior. The Metere paper treats SKILL.md as untrusted code by default until verified.
