# Raspberry Pi

A family of inexpensive [[SingleBoardComputer|single-board computers]] (SBCs) built around an ARM-based [[SystemOnAChip|SoC]], running a general-purpose [[OperatingSystem|OS]] (typically Raspberry Pi OS, a Debian derivative).

[[DiveIntoSystems]] Ch 0 cites the Raspberry Pi as the canonical contemporary SBC — a credit-card-sized, [[MulticoreProcessor|multicore]] machine that fully qualifies as a [[ComputerSystem|computer system]] under the book's definition (hardware + OS, general-purpose, reprogrammable).
