# Coordination Nomenclature

The IUPAC rules for naming a **[[CoordinationCompound|coordination compound]]** from its formula (and vice versa).

## The five rules

1. **Cation before anion.** For an ionic coordination compound, name the cation first, then the anion (whichever is the complex).
2. **Ligands alphabetically, before the metal.**
   - **Anionic ligands** add **-o** to the stem: F⁻ = *fluoro*, Cl⁻ = *chloro*, CN⁻ = *cyano*, OH⁻ = *hydroxo*, C₂O₄²⁻ = *oxalato*, CO₃²⁻ = *carbonato*.
   - **Neutral ligands** keep the molecule name, except four common ones: **aqua** (H₂O), **ammine** (NH₃), **carbonyl** (CO), **nitrosyl** (NO).
3. **Count prefixes.** di-, tri-, tetra-, penta-, hexa- for the number of identical ligands. If the ligand name already contains di/tri/tetra or begins with a vowel, use **bis-, tris-, tetrakis-** instead (e.g. *bis(ethylenediamine)*).
4. **Cationic / neutral complex:** metal spelled like the element + **oxidation state in Roman numerals** in parentheses. The oxidation state is back-calculated from the ligand charges and the overall complex charge.
5. **Anionic complex:** add **-ate** to the metal stem + Roman numeral. Latin stems are used where the English is awkward: **ferrate** (iron), **plumbate** (lead), **stannate** (tin), **argentate** (silver).

## Worked examples

| Formula | Name |
|---|---|
| [Co(NH₃)₆]Cl₃ | hexaamminecobalt(III) chloride |
| [Ag(NH₃)₂]⁺ | diamminesilver(I) ion |
| [Cr(H₂O)₄Cl₂]Cl | tetraaquadichlorochromium(III) chloride |
| [Co(en)₃]₂(SO₄)₃ | tris(ethylenediamine)cobalt(III) sulfate |
| [Pt(NH₃)₂Cl₄] | diamminetetrachloroplatinum(IV) |
| [Ni(en)₂Cl₂] | dichlorobis(ethylenediamine)nickel(II) |
| [PtCl₆]²⁻ | hexachloroplatinate(IV) ion |
| Na₂[SnCl₆] | sodium hexachlorostannate(IV) |

**Determining oxidation state (Example 19.4):** in Na₂[PtCl₆], the sphere is −2 with six Cl⁻, so −2 = −6 + x → Pt(IV). In K₃[Fe(C₂O₄)₃], −3 = −6 + x → Fe(III). In [Co(NH₃)₅Cl]Cl₂, sphere +2 = −1 + x → Co(III).
