# ICE Table

An **ICE table** (Initial, Change, Equilibrium) is the standard bookkeeping device for [[EquilibriumCalculations|equilibrium calculations]]. It tabulates, for every species, the **I**nitial concentration (or pressure), the **C**hange as the system moves to equilibrium, and the resulting **E**quilibrium value.

| | Reactants | Products |
|---|---|---|
| **Initial (I)** | starting concentrations | starting concentrations |
| **Change (C)** | −x (× stoichiometric coefficient) | +x (× stoichiometric coefficient) |
| **Equilibrium (E)** | Initial + Change | Initial + Change |

The single unknown **x** is scaled by each species' stoichiometric coefficient, with a **minus** sign for species being consumed and a **plus** sign for those being formed — the same stoichiometric coupling used for [[ReactionRate|relative reaction rates]].

## Worked example

For $\mathrm{PCl_5(g) \rightleftharpoons PCl_3(g) + Cl_2(g)}$ starting at [PCl₅] = 1.00 M:

| | PCl₅ | PCl₃ | Cl₂ |
|---|---|---|---|
| Initial | 1.00 | 0 | 0 |
| Change | −x | +x | +x |
| Equilibrium | 1.00 − x | x | x |

Substituting the Equilibrium row into the [[EquilibriumConstant|K]] expression turns the equilibrium problem into an algebra problem in x (here a quadratic — see [[EquilibriumCalculations]]).
