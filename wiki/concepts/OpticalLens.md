## Definition
An optical lens is a transparent element that uses [[Refraction]] to converge or diverge light and form images. A **thin lens** is thin enough that rays bend only once, with negligible dispersion and aberration.

(Distinct from the functional-programming "lens" and from the evaluation metric [[DocLens]] — this is the physical optics element.)

## Key Points
- **Converging (convex) lens:** bends parallel rays toward a single focal point F on the far side; `f > 0`.
- **Diverging (concave) lens:** spreads parallel rays so they appear to come from a focal point on the near side; `f < 0`.
- **Optical power** `P = 1/f` (diopters, D = m⁻¹); shorter focal length = stronger lens.
- Image cases:
  - Convex, object beyond `f`: real, inverted image (cameras, projectors, the eye).
  - Convex, object within `f`: virtual, upright, magnified image (magnifying glass).
  - Concave (any object distance): virtual, upright, diminished image.
- Light paths are reversible: a source at F produces a parallel beam (lighthouse, headlight).
- Governing relation is the [[ThinLensEquation]].

## Equations
- Optical power: `P = 1 / f` (diopters)
- Thin lens equation: `1/d_o + 1/d_i = 1/f`
- Magnification: `m = h_i / h_o = − d_i / d_o`
