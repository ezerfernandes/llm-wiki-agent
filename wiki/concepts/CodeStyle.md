# Code Style

Conventions for formatting and structuring source code (PEP 8 in Python, enforced by Black, Ruff, [[isort]]). Reduces review friction, improves diff legibility in [[Git]] workflows, and is typically enforced via [[GitHooks]] and [[CICD]].
