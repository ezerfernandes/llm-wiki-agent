# Modern Data Stack

A cloud-native composition of warehouses, ELT tools, transformation frameworks, and BI layers (e.g., Snowflake + dbt + Fivetran). Provides the analytical [[OLAP]] foundation that [[MLOps]] pipelines build upon.
