# Nuclide Notation

A **nuclide** is a single, specific type of nucleus, defined by its number of protons and neutrons. **Nucleons** is the collective name for the protons and neutrons packed into the [[AtomicNucleus|nucleus]] (which has radius ~10⁻¹⁵ m and density ~1.8 × 10¹⁴ g/cm³ — far denser than ordinary matter).

A nuclide is written in **nuclide notation**:

$$^{A}_{Z}X$$

- **X** = the element symbol
- **Z** = the [[AtomicNumberAndMassNumber|atomic number]] = number of protons (defines the element)
- **A** = the mass number = number of protons + neutrons

For example, $^{14}_{6}\text{C}$ is "carbon-14" (6 protons, 8 neutrons). [[Isotope|Isotopes]] are nuclides of one element (same Z) with different A. The number of neutrons is A − Z.

Particles in nuclear reactions get the same notation, treating mass number and charge as A and Z:

| Particle | Symbol | A | Z |
|---|---|---|---|
| Alpha | $^{4}_{2}\text{He}$, $^{4}_{2}\alpha$ | 4 | 2 |
| Beta (electron) | $^{0}_{-1}\beta$, $^{0}_{-1}\text{e}$ | 0 | −1 |
| Positron | $^{0}_{+1}\text{e}$, $^{0}_{+1}\beta$ | 0 | +1 |
| Proton | $^{1}_{1}\text{H}$, $^{1}_{1}\text{p}$ | 1 | 1 |
| Neutron | $^{1}_{0}\text{n}$ | 1 | 0 |
| Gamma ray | $\gamma$ | 0 | 0 |

This bookkeeping of A and Z is exactly what makes [[NuclearEquation|nuclear equations]] balanceable.
