# Class

A blueprint in object-oriented programming bundling data (attributes) and behavior (methods) into a reusable type. Foundation for [[CodeOrganization]] in [[PythonLanguage]] codebases, including framework objects like [[Dataset]], [[DataLoader]], and PyTorch modules.
