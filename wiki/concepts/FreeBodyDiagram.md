## Definition
A free-body diagram is a visual problem-solving tool that isolates a chosen body (often as a single point) and shows only the external forces acting on it. Velocity, acceleration, and internal forces are excluded because only external forces change a system's motion.

## Key Points
- Choosing the **system of interest** determines which forces are external (relevant) and which are internal (ignored) — the key conceptual step.
- It supports the standard four-step strategy for Newton's-laws problems:
  1. Identify the physics and sketch the situation with proportional force arrows.
  2. Define the system and draw the free-body diagram of external forces only.
  3. Apply [[NewtonsSecondLaw]] per axis: F_net = ma where there is acceleration, F_net = 0 in equilibrium; decompose forces onto convenient axes (e.g., parallel/perpendicular to an incline).
  4. Check that the result is reasonable and dimensionally consistent (force in newtons).
- Forces on inclines are resolved into components, e.g., w∥ = mg sin θ and w⊥ = mg cos θ.

## Equations
- Per axis: ΣF = ma (or ΣF = 0 in equilibrium)
- Resultant of components: F = √(Fx² + Fy²); θ = tan⁻¹(Fy/Fx)
