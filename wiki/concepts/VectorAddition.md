## Definition
Vector addition combines two or more vectors (see [[VectorQuantity]]) into a single resultant. Because vectors carry direction, they do not add as plain scalars; both magnitude and direction must be accounted for. Subtraction is defined as adding the negative of a vector.

## Key Points
- **Graphical (head-to-tail) method:** place each vector's tail at the previous head; the resultant runs from the first tail to the last head. Magnitude is measured by scaled length, direction by protractor.
- **Analytical method:** resolve each vector into perpendicular [[VectorComponents]], add components axis-by-axis, then recombine — more precise than graphical drawing.
- Addition is commutative: A + B = B + A.
- Subtraction: A − B = A + (−B), where −B has the same magnitude but opposite direction.
- Scalar multiplication: a positive scalar rescales magnitude; a negative scalar rescales magnitude and reverses direction.
- Vector magnitudes do not add directly: 3 m east + 4 m north gives a 5 m resultant, not 7 m.

## Equations
- A + B = B + A
- A − B = A + (−B)
- Component sums: Rx = Ax + Bx ; Ry = Ay + By
- Resultant: R = √(Rx² + Ry²), θ = tan⁻¹(Ry / Rx)
