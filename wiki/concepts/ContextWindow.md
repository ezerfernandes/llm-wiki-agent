# Context Window

Synonym for [[ContextLength|context length]] — the maximum number of tokens an LLM can process in a single forward pass. See [[ContextLength]] for the full definition.

The two terms are used interchangeably in *[[HandsOnLLM|Hands-On LLMs]]* ([[hands-on-llm-ch01-introduction-to-llms|Ch 1]]):

> "A vital part of these completion models is something called the context length or context window."
