# Holdout Dataset

A subset of data set aside and not used for training or model selection, reserved for a single final estimate of [[Generalization]]. Distinct from the validation set used for [[HyperparameterTuning]] and [[EarlyStopping]]; protecting it from reuse is core to honest evaluation.
