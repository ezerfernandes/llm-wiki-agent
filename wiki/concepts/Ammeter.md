## Definition
An ammeter measures the current flowing through a circuit branch. It is connected **in series** with that branch so the same current passes through it. An analog ammeter is a [[Galvanometer]] with a small **shunt** resistor in parallel that diverts most of the current around the sensitive movement.

## Key Points
- Connected in series — series elements carry the same current.
- Built from a galvanometer plus a **small parallel shunt** that bypasses most current.
- An ideal ammeter has near-zero resistance to avoid adding voltage drop to the branch.
- Connecting any ammeter adds some series resistance, introducing measurement error.
- Higher galvanometer sensitivity (smaller full-scale current) allows better meters.

## Equations
- Shunt resistance for full-scale current: `R = r · (I_G / I)`
  - r = galvanometer resistance; I_G = galvanometer full-scale current; I = desired full-scale current
