# Kourovka Notebook

Long-running open-problem collection in **group theory**. **Problem 21.10** asks whether every finite group admits a so-called *just-finite presentation* — a finite presentation where removing any relation results in an infinite group. In [[2605.06651v2-ai-co-mathematician]] §5.1, M. Lackenby used the [[AICoMathematician|AI co-mathematician]] to resolve this question affirmatively.

Key process detail: the system launched two adversarial workstreams (one attempting a proof, one attempting a disproof). The "proof" workstream produced an argument the system itself marked as incorrect, but Lackenby noticed it contained a *"really, really clever proof strategy"* and a single gap; reading the reviewer agent's critique surfaced exactly what to fill. The system then wrote up a complete and correct proof of the corrected argument.
