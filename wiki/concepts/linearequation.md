# Linear Equation

A **linear equation** is an [[Equation|equation]] in which the [[Variable|variable]] appears only to the **first power** — no exponents, roots, or products of variables — so it can be rearranged into the standard form `ax + b = c` (equivalently `ax = b`). The name "linear" reflects that, graphed, such an equation in one variable corresponds to a single point on the number line and in two variables to a straight line. OpenStax [[Prealgebra]] 2e Chapter 8 ([[prealgebra-2e-ch08-solving-linear-equations]]) is devoted to **solving** one-variable linear equations.

A **solution** is a value of the variable that makes the equation true; checking a candidate means substituting it and confirming both sides are equal under the [[OrderOfOperations|order of operations]]. Because the variable is first-degree, a linear equation has exactly **one** solution (unless it simplifies to a contradiction, with no solution, or an identity, with infinitely many).

## Forms encountered in Chapter 8
- One-step additive: `x + a = b`, `x − a = b`
- One-step multiplicative: `ax = b`, `x/a = b`
- Variables and constants on **both sides**: `ax + b = cx + d`
- With parentheses requiring the [[DistributiveProperty|Distributive Property]]: `3(n − 4) − 2n = −3`
- With **fraction or decimal coefficients**, cleared via the [[LeastCommonMultiple|LCD]] before solving

## Solving
All of these are handled by the single [[SolvingLinearEquations|General Strategy for Solving Linear Equations]], which applies the [[PropertiesOfEquality|Properties of Equality]] to isolate the variable: simplify each side, collect variable terms on one side and constants on the other, reduce the coefficient to 1, then check.
