# Model Monitoring

Continuous tracking of a deployed model's inputs, outputs, and performance to detect [[TargetDrift]], [[TrainingServingSkew]], and degradation. A core [[MLOps]] practice using tools like [[StructuredLogging]] and [[Observability]].
