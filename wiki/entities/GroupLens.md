# GroupLens

University of Minnesota research lab; runs **[[MovieLens]]**, the canonical academic recommender-systems dataset and live web service (since 1997). Cited in [[d2l-recommender-systems]] as the dataset host for [[MovieLens]] 100K / 1M / 10M / 20M / 25M releases — *the* benchmark family for academic CF research.

Key paper anchoring D2L: **Herlocker, Konstan, Borchers, Riedl 1999** — *An Algorithmic Framework for Performing Collaborative Filtering* (SIGIR).
