# Stanford MIMI

**Medical Intelligence and Machine Learning Initiative** (`StanfordMIMI` on GitHub and HuggingFace) — research lab at [[stanforduniversity|Stanford University]] led by [[AkshayChaudhari|Akshay Chaudhari]]. Engineering home of the [[MedVAL]] codebase and the public artifact releases. Not to be confused with **MIMIC**, the unrelated MIT-LCP clinical-data corpus (the lab uses MIMIC data but is a different organization).

## Releases

All [[MedVAL]] artifacts ship under this lab:
- **Codebase**: [github.com/StanfordMIMI/MedVAL](https://github.com/StanfordMIMI/MedVAL)
- **[[MedVALBench|MedVAL-Bench]]**: [huggingface.co/datasets/stanfordmimi/MedVAL-Bench](https://huggingface.co/datasets/stanfordmimi/MedVAL-Bench) + PhysioNet release.
- **[[MedVAL4B|MedVAL-4B]]**: [huggingface.co/stanfordmimi/MedVAL-4B](https://huggingface.co/stanfordmimi/MedVAL-4B)
- **MedVAL Demo**: [huggingface.co/stanfordmimi/MedVAL](https://huggingface.co/stanfordmimi/MedVAL)
