# Langflow

Open-source visual builder for [[AIPipelineOrchestration|AI pipeline orchestration]] — drag-and-drop UI over LangChain components. Cited in [[ai-engineering-ch10-architecture-feedback|*AI Engineering* Ch 10]] as one of the named AI orchestration tools:

> *"There are many AI orchestration tools, including LangChain, LlamaIndex, Flowise, Langflow, and Haystack."* — Ch 10

## Position

Langflow occupies the same visual-orchestrator slot as [[Flowise]] — both target rapid prototyping with a node-graph UI atop LangChain primitives. It is widely used as a *playground* for chain design before code-export to a production pipeline.
