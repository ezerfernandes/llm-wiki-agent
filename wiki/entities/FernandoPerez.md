# Fernando Pérez

Started the [[IPython]] project in 2001 as a side project to make a better interactive Python interpreter. Co-founded the [[Jupyter]] project in 2014, broadening IPython's notebook into a language-agnostic interactive-computing platform. Faculty at UC Berkeley; co-founded the Berkeley Institute for Data Science (BIDS). Long-time collaborator with [[JohnHunter]] and Brian Granger.

## Connections
- [[IPython]] — original author.
- [[Jupyter]] — co-founder.
