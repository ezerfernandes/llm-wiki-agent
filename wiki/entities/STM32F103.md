# STM32F103

[[ARMCortexM|ARM Cortex-M3]]-based 32-bit [[Microcontroller|microcontroller]] family from [[STMicroelectronics]]. On the [[STM32F3DISCOVERY]] dev board, an STM32F103 sits next to the application MCU ([[STM32F303VCT6]]) and acts as an **on-board [[STLink|ST-LINK]] programmer / debugger** wired to the host PC over the "USB ST-LINK" Mini-USB port ([[rust-embedded-book-intro-hardware]]). This is the architectural feature that makes the F3 board self-programmable — no external debug probe required.

Outside the Discovery boards, the STM32F103 family ("Blue Pill") is one of the most widely used low-cost MCUs in hobbyist embedded development.

## Connections

- [[STM32F3DISCOVERY]] — the board this MCU is mounted on as the debug probe.
- [[STM32F303VCT6]] — the application MCU the F103 programs and debugs.

- [[ARMCortexM]] — Cortex-M3 core profile.
- [[STLink]] — the debug protocol the on-board F103 implements.
