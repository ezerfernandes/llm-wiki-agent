# AlphaProof

[[googledeepmind|Google DeepMind]]'s **olympiad-level formal mathematical reasoning** system, trained with reinforcement learning over formal proof environments (Hubert et al. 2025; Nature, DOI 10.1038/s41586-025-09833-y).

In [[2605.06651v2-ai-co-mathematician]] the [[AICoMathematician|AI co-mathematician]] is positioned as **complementary** to AlphaProof: the harness is designed to *plug in* AlphaProof as a stronger prover sub-agent, which would raise confidence on proof correctness (relative to the current default of informal proofs via [[GeminiDeepThink|Gemini Deep Think]]) for statements expressible in existing formal mathematics libraries.
