# Snap / SNAP

This page covers **two distinct entities sharing the same abbreviation**, both cited in [[ai-engineering-ch08-dataset-engineering|*AI Engineering* Ch 8]].

## Snap Inc. (the company)

Parent company of Snapchat. Per Ch 8, Snap published a 2022 case study on **augmenting characters to create unrepresented corner cases and mitigate implicit biases**:

> "Given a character, they synthesize similar characters but with different skin colors, body types, hairstyles, clothes, and even facial expressions. These augmented assets are then used to train AI models."

This is one of Ch 8's concrete operational examples of using [[DataAugmentation|augmentation]] to fix dataset biases before model training.

## SNAP — Stanford Network Analysis Platform

The [[stanforduniversity|Stanford]] research group's large-scale graph dataset collection. Per Ch 8's list of public-dataset resources:

> "The Stanford Large Network Dataset Collection is a great repository for graph datasets."

SNAP datasets include social-network graphs, web graphs, citation networks, communication networks, and ground-truth community datasets — widely used in graph-ML research.
