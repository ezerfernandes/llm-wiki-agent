# Grace Hopper (1906–1992)

American computer scientist and U.S. Navy Rear Admiral. Developed **[[COBOL]]** — the first widely used **machine-independent** high-level programming language, decoupling source code from any specific [[ISA|instruction set architecture]] and establishing the cross-architecture portability model every modern compiled language follows.

Per [[dis-5-1-history|*Dive into Systems* Ch 5.1]], Hopper is one of the women whose foundational contributions to computing were historically underrecognized. Her insight that programmers should not need to write in raw machine code — that a [[Compiler|compiler]] should bridge a portable, human-readable syntax to the underlying hardware — is the conceptual seed of every later high-level language ([[CLanguage|C]], Java, Python, etc.).

Also popularized the term *"debugging"* after taping a literal moth into the Harvard [[HarvardMarkI|Mark II]] logbook in 1947.
