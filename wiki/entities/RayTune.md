# Ray Tune

[[Ray]] library for distributed hyperparameter tuning. Used with [[HyperOpt]] / [[Optuna]] search backends and ASHA scheduling in [[madewithml-mlops-tuning]]. [[d2l-hyperparameter-optimization]] §hyperopt-api cites Ray Tune as one of three production HPO libraries (alongside [[SyneTune]] and [[Optuna]]) sharing the same searcher/scheduler decomposition.
