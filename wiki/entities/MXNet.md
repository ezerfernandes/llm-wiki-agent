# MXNet

Apache MXNet — open-source deep-learning framework backed by [[Amazon|AWS]]. The *original* primary framework of *Dive into Deep Learning* ([[d2l-preface]]) before the July 2021 redesign that switched D2L's primary framework to [[PyTorch]]. Every code example in D2L still ships with a parallel MXNet implementation.

## Connections
- [[Amazon]] — primary corporate backer.
- [[MuLi]] — D2L co-author and MXNet core contributor.
- [[PyTorch]] — current D2L primary framework.
- [[TensorFlow]], [[JAX]] — other frameworks D2L supports.
- [[d2l-preface]] — references MXNet as historical primary framework.
