# Rusty-probe

Open-source USB-based hardware debug probe designed to pair with [[ProbeRs|Probe-rs]]. Provides an easy-to-use, cost-effective probe for embedded-Rust developers ([[rust-embedded-book-intro-tooling]]).

## Connections

- [[ProbeRs]] — the software stack Rusty-probe is purpose-built for.
- [[STLink]] / [[JLink]] / [[MCULink]] — alternative probes in the same slot.
- [[JTAG]] / [[SWD]] — supported transport protocols.
- [[OnChipDebugging]] — the operating regime.
- [[TheEmbeddedRustBook]] — listed in the probe survey.
