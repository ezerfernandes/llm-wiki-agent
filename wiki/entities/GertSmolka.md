# Gert Smolka

Researcher at the [[DFKI]] **Programming Systems Lab** (Saarbrücken, Germany) in the 1990s; principal designer of [[Oz]] and author of the [[OPM|Oz Programming Model]]. Smolka's research program merged three previously separate strands — **higher-order functional programming**, **concurrent constraint programming** ([[VijaySaraswat|Saraswat]]'s framework), and **constraint logic programming** — into a single lexically-scoped model that admits objects, agents, and encapsulated search as derived abstractions.

## Body of work cited in this wiki

- *The Oz Programming Model* (Smolka 1995, LNCS Vol. 1000) — [[vol1000-oz-programming-model]] — informal exposition of [[OPM]]
- *The Definition of Kernel Oz* (Smolka 1995, LNCS Vol. 910) — formal calculus for OPM (referenced)
- *A Foundation for Higher-Order Concurrent Constraint Programming* (Smolka 1994, CCL'94) — referenced
- *An Oz Primer* (Smolka 1995, DFKI documentation series) — introduction-to-Oz companion
- *Fresh: A higher-order language with unification and multiple results* (Smolka 1986) — earliest source for interfacing variables and procedures through freshly chosen names
- *Records for logic programming* (Smolka & Treinen 1994) — feature-tree constraint structure underlying Oz's records (CFT)
- *A feature-based constraint system for logic programming with entailment* (Aït-Kaci, Podelski & Smolka 1994) — entailment-based feature constraint system

## Position in the wiki

The wiki's first entry from the **programming-language-theory** research community — distinct from the ML / DL / clinical-NLP cluster that dominates the corpus. Smolka's *concurrent constraint + first-class procedures + cells + encapsulated search* synthesis is conceptually upstream of every later constraint-programming system (Mozart/Oz, Gecode, Choco) and influenced multi-paradigm languages that fuse logic and functional programming.
