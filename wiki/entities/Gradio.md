# Gradio

Open-source Python library for building quick web UIs and demos around machine-learning models — a few lines of Python wrap a model in an interactive browser interface. Now stewarded by [[HuggingFace|Hugging Face]] and the standard way to publish demos on Hugging Face Spaces. In *[[practical-deep-learning-for-coders|Practical Deep Learning for Coders]]*, Gradio is the deployment tool used to ship trained models as shareable apps (Lesson 2, Deployment).
