# ISLR R Package

Companion [[Rlanguage|R]] package for [[islr-seventh-printing|An Introduction to Statistical Learning]], distributing the data sets used in chapter labs and exercises: `Auto`, `Boston` (from [[MASS]]), `Caravan`, `Carseats`, `College`, `Default`, `Hitters`, `Khan`, `NCI60`, `OJ`, `Portfolio`, `Smarket`, `USArrests`, `Wage`, `Weekly` (Table 1.1).
