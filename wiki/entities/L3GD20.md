# L3GD20

[[STMicroelectronics]] 3-axis MEMS [[Gyroscope]] chip, accessed over [[SPI]]. Mounted on the [[STM32F3DISCOVERY]] dev board; together with the [[LSM303DLHC]] (accelerometer + magnetometer) it completes the board's 9-axis [[IMU|inertial motion unit]] ([[rust-embedded-book-intro-hardware]]).

The L3GD20 / [[LSM303DLHC]] pairing is also a clean pedagogical exhibit of the two canonical sensor-bus families the prior chapter listed as prerequisite knowledge — one sensor on each of [[I2C]] (LSM303DLHC) and [[SPI]] (L3GD20).

## Connections

- [[STM32F3DISCOVERY]] — the board this chip is mounted on.
- [[STMicroelectronics]] — manufacturer.
- [[Gyroscope]] — the sensor class.
- [[SPI]] — the host bus the chip is read over.
- [[LSM303DLHC]] — sibling chip on the same board providing the accelerometer + magnetometer.
