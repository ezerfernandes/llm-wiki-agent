# Dask

Parallel computing in Python with pandas-like and NumPy-like APIs. Mentioned as an alternative to [[Ray]] for distributed pandas-style work in [[madewithml-mlops-distributed-data]] and [[madewithml-foundations-pandas]]; also a backend for [[Modin]].
