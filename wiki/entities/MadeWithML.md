# Made With ML

Open-source MLOps course created by [[GokuMohandas]] (~40k GitHub stars), now part of the [[Anyscale]] ecosystem. Combines a **Foundations** track (NumPy/pandas/PyTorch + classical ML + DL primer) with an end-to-end **MLOps** track that builds a real content-tagging service using [[Ray]], [[RayTrain]], [[RayServe]], [[MLflow]], and [[GitHubActions]]. The 39-lesson curriculum is ingested under the `madewithml-` slug prefix.

## Connections
- [[GokuMohandas]] — founder/author
- [[Anyscale]] — hosts the cluster compute and Jobs/Services platform used throughout the course
- [[Ray]] — distributed compute substrate
