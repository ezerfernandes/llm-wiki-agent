# Slack

**Slack** is the enterprise-messaging platform — named in [[ai-engineering-ch06-rag-agents|*AI Engineering* Ch 6]] as one of the enterprise APIs that **[[Composio]] focuses on** (alongside [[google|Google Apps]] and [[GitHub]]):

> *"Composio focuses on enterprise APIs (Google Apps, GitHub, and Slack)."*

In agent-design terms, Slack is a [[KnowledgeAugmentation|knowledge-augmentation]] tool target (Slack retrieval — search messages, channels, threads) and a [[WriteAction|write-action]] target (send messages, create channels, react to threads).

## Position in the wiki

Adjacent to other enterprise tools cited in *AI Engineering* and the LLM Engineer's Handbook — Slack belongs to the same productivity-API surface as Gmail (Google Apps) and GitHub.
