# Enclawed

Open-source single-user AI assistant gateway hardened against the same threat surface skills now expose. Implements the Bell–LaPadula classification scheme, Ed25519 signed-module loader with clearance-bounded trust root, hash-chained audit log, egress guard, regex DLP scanner, HITL controller with checkpointable session state machine, and a transaction buffer with rollback. Reference implementation behind the [[2605.00424-skills-as-verifiable-artifacts]] paper.
