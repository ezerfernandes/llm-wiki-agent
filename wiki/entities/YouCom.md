# You.com

Web search engine and conversational search company. Provider of the **search API** that grounds [[2408.15232-co-storm|Co-STORM]]'s expert turns and moderator question-generation (with retrieval filtered to the [[Wikipedia]] *Reliable sources* whitelist, following [[Shao2024|Shao et al. 2024]]). API docs: <https://documentation.you.com/api-reference/search>.

You.com provided a discounted search API to the Co-STORM research team (acknowledged in §Acknowledgements).
