## What it is
Pulumi is an open-source Infrastructure-as-Code (IaC) framework that lets engineers define cloud resources in real programming languages (Python, TypeScript, Go, C#, Java) rather than declarative DSLs like Terraform/HCL.

## In LLM Engineer's Handbook
Ch. 3 ([[leh-ch03-data-engineering]]) references Pulumi as the IaC tool used in Ch. 4 to provision infrastructure for the RAG feature pipeline (mentioned in passing as part of the broader tooling story).
