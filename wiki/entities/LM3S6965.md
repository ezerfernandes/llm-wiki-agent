# LM3S6965

Texas Instruments (originally Luminary Micro) **[[ARMCortexM|Cortex-M3]] microcontroller** chosen by *[[TheEmbeddedRustBook]]* as the target for its first code example ([[rust-embedded-book-start-qemu]]) "because it [can be emulated](https://wiki.qemu.org/Documentation/Platforms/ARM#Supported_in_qemu-system-arm) using QEMU so you don't need to fiddle with hardware in this section and we can focus on the tooling and the development process."

The book's [[LinkerScript|`memory.x`]] pins its memory layout:

```text
FLASH : ORIGIN = 0x00000000, LENGTH = 256K
RAM   : ORIGIN = 0x20000000, LENGTH = 64K
```

— 256 KiB [[FlashMemory|Flash]] at the Cortex-M reset vector / 64 KiB [[SRAM]] at the standard Cortex-M SRAM base, with the [[VectorTable|vector table]] occupying the first 1 KiB of Flash. Built for the [[RustTarget|target triple]] `thumbv7m-none-eabi`. Runs under [[QEMU]] via `qemu-system-arm -cpu cortex-m3 -machine lm3s6965evb` — the latter naming the LM3S6965EVB evaluation board.

The choice is pedagogical: among the Cortex-M MCUs QEMU's `qemu-system-arm` can emulate, the LM3S6965 is one of the few with a complete machine model, making it the book's no-hardware substrate for chapters 11+ before the worked examples shift to the physical [[STM32F3DISCOVERY]] board.

## Connections

- [[ARMCortexM]] — Cortex-M3 (the `thumbv7m-none-eabi` target).
- [[QEMU]] — the emulator that hosts it (`-machine lm3s6965evb`).
- [[TheEmbeddedRustBook]] — uses it as the first code-example target.
- [[STM32F3DISCOVERY]] — the *physical* board the book later transitions to.
- [[VectorTable]] / [[LinkerScript]] — the LM3S6965-specific memory map is the canonical worked example for both.
