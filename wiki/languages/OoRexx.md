## Summary
Open Object Rexx (ooRexx) is a dynamically typed, multi-paradigm scripting language that adds full single-rooted object orientation, message passing, and multiple inheritance to the classic Rexx language while remaining largely backward compatible with it. It originated as IBM's Object REXX in the 1990s and was released as open source in 2004 under the stewardship of the Rexx Language Association, with the RexxLA community maintaining it ever since. Like its Rexx ancestor it features an English-like, easy-to-read syntax, freeform tokens, decimal arithmetic of arbitrary precision, and powerful string handling through stem variables (associative arrays). It is typically used for macro and glue scripting, automation, rapid prototyping, and general-purpose application development across Windows, Linux, and other platforms.
