## Summary
Chipmunk Basic is an interpreted dialect of the BASIC programming language, written by Ronald H. Nicholson Jr. and first released in 1991, originally for the classic Mac OS and later ported to Windows, Linux, and other Unix-like systems. It is an imperative, procedural language that follows the traditional unstructured BASIC model, using optional line numbers, GOTO/GOSUB control flow, and dynamically typed variables that distinguish numeric values from strings (the latter marked with a trailing $). Lightweight and freely available, it is used mainly for learning programming, quick scripting, and as a nostalgic recreation of the interactive 1980s home-computer BASIC environment.
