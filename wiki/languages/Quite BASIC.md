## Summary
Quite BASIC is an imperative, line-numbered dialect of BASIC that runs entirely in a web browser, created in the late 2000s by Einar Egilsson as a free educational tool for teaching elementary programming concepts. It follows the classic procedural style of vintage 1960s–1980s BASIC, with numbered statements, GOTO/GOSUB flow control, dynamically typed scalar variables and arrays (numbers and strings), and a small built-in command set. Notably it includes simple turtle-style graphics commands for drawing on a canvas, making it well suited to beginners and classroom demonstrations rather than production software.
