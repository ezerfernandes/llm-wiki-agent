## Summary
Verbexx is an experimental, multi-paradigm programming language created around 2014 by an individual developer who documented it largely through Rosetta Code task solutions. Its most distinctive feature is a uniform, verb-centric syntax in which nearly every construct — including control flow and operators — is expressed as a "verb" call written with an `@verb` prefix, giving the language a highly regular, Lisp-like homoiconic structure layered over an infix-friendly surface. It is dynamically typed and interpreted, supporting first-class functions, lambdas, and user-definable verbs that let programmers extend the core language with new control structures. Verbexx is primarily a hobbyist and research vehicle for exploring extensible, macro-like syntax rather than a language intended for production use.
