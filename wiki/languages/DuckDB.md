## Summary
DuckDB is an in-process analytical (OLAP) database management system whose primary interface is SQL, a declarative, set-oriented query language with static, strongly typed columnar data; in the Rosetta Code context "DuckDB" denotes solving tasks via this dialect of SQL, which extends standard ANSI SQL with conveniences such as list and struct types, friendly syntax, and rich aggregate and window functions. Created in 2018–2019 by Mark Raasveldt and Hannes Mühleisen at CWI in Amsterdam and released as open source, it is designed to run embedded inside a host process (much like SQLite) but optimized for vectorized, column-store analytical workloads. It is typically used for fast local data analysis, querying Parquet/CSV/JSON files directly, and as an embeddable analytics engine within data-science pipelines and applications.
