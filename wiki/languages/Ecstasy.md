## Summary
Ecstasy is a general-purpose, object-oriented and functional programming language created by Cameron Purdy and others at xqiz.it, with development emerging in the late 2010s. It is statically and strongly typed, featuring a sophisticated type system with generics, immutability, nullability tracking, and union/intersection types, and it compiles to a managed intermediate representation that runs on its own runtime (the XVM). Designed from the ground up for secure, cloud-native and serverless applications, Ecstasy emphasizes a fully containerized execution model where code runs without ambient authority, making capabilities explicit. Its typical use targets modern distributed and multi-tenant server software where security, isolation, and resource governance are first-class concerns.
