## Summary
Vala is a statically typed, object-oriented programming language created by Jürgen Pfeifer and Raffaele Sandrini around 2006 under the GNOME project, designed to bring modern language features—such as classes, properties, signals, generics, closures, and automatic reference-counting memory management—to the GObject type system. Its compiler emits C source code that links against the GLib/GObject libraries, so Vala programs run with the performance and ABI of hand-written C while avoiding the boilerplate of the GObject framework. Syntactically it resembles C# and Java, and it is used primarily for building GTK and GNOME desktop applications and libraries on Linux.
