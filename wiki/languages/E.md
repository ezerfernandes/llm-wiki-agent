## Summary
E is an object-oriented, message-passing programming language created by Mark S. Miller and others around 1997, designed to unify secure distributed computing with a capability-based security model. It is dynamically typed and runs on the Java Virtual Machine, blending influences from Java and the concurrent object language Joule. Its defining features are object-capability security (authority is conveyed only by holding object references) and a promise-based asynchronous concurrency model using event loops, "vats," and the eventual-send operator to coordinate non-blocking remote calls. E is used primarily for research and experimentation in secure cooperation among mutually suspicious parties and safe distributed systems.
