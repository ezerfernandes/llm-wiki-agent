## Summary
Hexiscript is a small, imperative scripting language created in the early 2010s, originally designed as the embedded command and automation language for the Hexis text editor. It is dynamically typed with C-like syntax, supporting variables, arrays, dictionaries, user-defined functions, and standard control-flow constructs, and uses explicit `let` declarations and `endif`/`endwhile`-style block terminators. As an interpreted scripting language, it is used primarily for editor automation, lightweight glue scripting, and general procedural programming tasks rather than large applications.
