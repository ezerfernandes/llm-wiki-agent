## Summary
Zoea is a declarative, example-driven programming language in which programs are specified entirely through concrete input-output examples rather than imperative instructions or explicit control flow. Created by Edward Pratt and released in the early 2020s, it uses inductive program synthesis to automatically derive working code from the supplied test cases, so the developer describes what a program should do while the compiler figures out how. Being specification-based, it has no traditional variables, loops, or static type annotations; data shapes are inferred from the examples themselves. Its typical use is rapid construction of small data-transformation and business-logic routines, particularly via the Zoea Visual environment that integrates the example-driven workflow into a graphical IDE.
