## Summary
Common Lisp is a multi-paradigm dialect of Lisp that blends functional, procedural, and object-oriented programming, with the Common Lisp Object System (CLOS) providing multiple dispatch, multiple inheritance, and a metaobject protocol. It is dynamically and strongly typed, with optional type declarations that compilers can use for optimization, and it offers powerful runtime metaprogramming through its homoiconic syntax and macro system. Standardized by ANSI in 1994 after emerging in the 1980s to unify the many divergent Lisp dialects, it features automatic garbage collection, a condition/restart-based error-handling system, and an interactive REPL with incremental compilation. It is used for artificial intelligence research, symbolic computation, rapid prototyping, language and compiler development, and long-lived applications that benefit from interactive, image-based development.
