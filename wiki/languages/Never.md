## Summary
Never is a statically typed, functional programming language created by Slawomir Maludzinski in the mid-2010s, with a syntax reminiscent of C but a semantics centered on first-class functions and closures. Programs are organized around functions and expressions rather than statements, and the language supports recursion, arrays, and higher-order functions while compiling to bytecode that runs on its own small virtual machine. Its type system is checked at compile time, catching arity and type mismatches before execution. Never is primarily an educational and experimental language used to explore functional programming, type checking, and the construction of compilers and virtual machines.
