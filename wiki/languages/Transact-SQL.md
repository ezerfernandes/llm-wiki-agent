## Summary
Transact-SQL (T-SQL) is Microsoft and Sybase's proprietary procedural extension to the SQL standard, originating in the late 1980s and shipping as the native query and programming language of Microsoft SQL Server and Azure SQL. It augments declarative, set-oriented SQL with imperative control-of-flow constructs (variables, IF/WHILE blocks, BEGIN/END), error handling (TRY/CATCH), stored procedures, user-defined functions, and triggers, using a statically typed system rooted in SQL data types. Statement results are predominantly set-based and statically typed, with explicit and implicit conversions governing how values move between the rich catalog of built-in types. It is used chiefly for relational data manipulation, server-side business logic, batch scripting, and database administration within the SQL Server ecosystem.
