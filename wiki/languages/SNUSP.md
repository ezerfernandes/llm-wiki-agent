## Summary
SNUSP is an esoteric, two-dimensional programming language created by Daniel Brockman around 2002 as a Brainfuck variant, with its name a recursive acronym ("SNUSP's Not Unix, Same Project") and a playful nod to "thnusp." It retains Brainfuck's untyped, byte-cell memory tape and pointer-manipulation model, but replaces linear instruction flow with an instruction pointer that moves across a grid of characters, using direction-changing operators (\ and /) to steer execution. The language comes in tiered variants — Core SNUSP, Modular SNUSP (adding subroutines via a call stack), and Bloated SNUSP (adding a second data pointer and threading) — making it a Turing-complete curiosity. Like other esolangs it has no practical application and exists purely for recreational programming, puzzle-solving, and exploring minimalist computation.
