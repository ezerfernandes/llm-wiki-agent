## Summary
Vim Script (also called Vimscript or VimL) is the dynamically typed, imperative scripting language built into the Vim text editor, introduced by Bram Moolenaar in the early 1990s and substantially expanded over the editor's evolution. It is interpreted and weakly typed, with core data types including numbers, strings, lists, and dictionaries, and supports functions, autocommands, and ex-mode commands intermixed with editor configuration. The language is used almost exclusively to configure Vim, automate editing tasks, and write plugins, where it manipulates buffers, windows, registers, and key mappings. Though procedural at heart, it accommodates a loosely functional style through anonymous functions and dictionary-based pseudo-objects, and remains the dominant customization language for Vim despite the later addition of Lua support in Neovim.
