## Summary
R is a dynamically typed, multi-paradigm language and software environment specialized for statistical computing, data analysis, and graphics. Created by Ross Ihaka and Robert Gentleman at the University of Auckland in the early-to-mid 1990s as a free, open-source implementation of the S language, it combines functional programming (first-class functions, vectorized operations, lazy evaluation) with imperative and object-oriented styles via several object systems (S3, S4, R5/Reference Classes, and R6). Its vector- and data-frame-centric design, lazy argument evaluation, and rich package ecosystem on CRAN make it the de facto standard for statisticians, bioinformaticians, and data scientists. R is most commonly used for exploratory data analysis, statistical modeling, machine learning, and publication-quality visualization, typically run interactively or through tools like RStudio.
