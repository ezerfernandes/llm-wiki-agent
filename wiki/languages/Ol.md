## Summary
Ol (short for "Otus Lisp") is a small, embeddable, functional Lisp dialect that implements a substantial subset of the R7RS Scheme standard, created by Yuriy Chumak in the mid-2010s. It is dynamically typed and emphasizes purely functional programming with immutable data structures, exact rational and arbitrarily large integer arithmetic, and persistent (referentially transparent) values, compiling source down to a compact bytecode that runs on a tiny portable virtual machine. The implementation is designed to be extremely lightweight and cross-platform, running on everything from desktop operating systems to embedded devices and WebAssembly. It is typically used for scripting, teaching, and embedding a Scheme-like language into other applications where a minimal footprint matters.
