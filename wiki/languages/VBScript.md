## Summary
VBScript is an interpreted scripting language developed by Microsoft in 1996 as a lightweight subset of Visual Basic, designed for the Windows platform and hosted by the Windows Script Host, Internet Explorer, and classic ASP. It is dynamically typed, using the variant type for all values, and supports imperative and rudimentary object-based programming through COM automation. Its typical uses include Windows system administration scripting, automation of Office and other COM applications, and legacy server-side web pages, though Microsoft has deprecated it in favor of PowerShell and JScript and is gradually removing it from Windows.
