## Summary
XSLT (Extensible Stylesheet Language Transformations) is a declarative, functional, Turing-complete language for transforming XML documents into other XML, HTML, or plain-text outputs. Developed by the W3C and first standardized in 1999 (XSLT 1.0), with later 2.0 and 3.0 versions adding stronger XPath-based data typing, it is itself written as XML and relies on template rules that pattern-match nodes in a source tree. Being side-effect-free and based on recursion rather than loops or mutable variables, it favors a functional style, and is most commonly used for rendering and reformatting XML data in publishing pipelines, document conversion, and web content generation.
