## Summary
11l (pronounced "eleventy-one") is a statically typed, multi-paradigm programming language created around 2017 by Alexander Tretyak, designed for high-performance computing while retaining a concise, Python-influenced syntax. It blends imperative, object-oriented, and functional styles, uses type inference to keep code terse, and transpiles to C++ to achieve native-level execution speed. The language is best known in the Rosetta Code community as a compact, readable vehicle for algorithm and code-golf style solutions, and is typically used for numeric, scientific, and general-purpose programming where both brevity and speed matter.
