## Summary
REALbasic is an object-oriented, statically typed dialect of BASIC created by REAL Software (now Xojo, Inc.) in 1998, originally for the classic Mac OS and later extended to a cross-platform RAD environment targeting macOS, Windows, and Linux. It combines a familiar, readable BASIC syntax with modern features such as classes, inheritance, interfaces, events, and exception handling, all built around a drag-and-drop visual GUI designer. The language compiles to native machine code rather than running interpreted, making it well suited to building standalone desktop applications and small business tools. It was renamed Real Studio in 2010 and superseded by Xojo in 2013, which remains its direct successor.
