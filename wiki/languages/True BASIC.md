## Summary
True BASIC is a structured, imperative procedural programming language created in 1983 by John G. Kemeny and Thomas E. Kurtz, the original authors of BASIC at Dartmouth College, as a standards-conforming successor intended to restore disciplined programming after the proliferation of incompatible microcomputer BASIC dialects. It uses dynamic typing with numeric and string types, eschews mandatory line numbers in favor of named subroutines, functions, and structured control flow (DO/LOOP, SELECT CASE, FOR/NEXT), and provides built-in matrix arithmetic and device-independent graphics. Implemented as a portable cross-platform commercial product for DOS, Windows, and Macintosh, it was used primarily in education and for scientific and mathematical computing where its array and matrix facilities were especially convenient.
