## Summary
MUMPS (Massachusetts General Hospital Utility Multi-Programming System), also standardized as M, is a dynamically and weakly typed, imperative procedural language created in the late 1960s at Massachusetts General Hospital. Its defining feature is a built-in hierarchical, schema-less key-value database in which the same sparse multidimensional array syntax addresses both transient local variables and persistent disk-resident "globals," giving the language integrated, transparent persistence without a separate database layer. The syntax is famously terse, supporting single-letter command abbreviations, line-level scoping, and post-conditional execution, and everything is treated as a string that is coerced to a number when needed. It remains in heavy production use today as the foundation of electronic health record and financial systems such as Epic, VistA, and InterSystems Caché/IRIS.
