## Summary
Whitespace is an esoteric, stack-based imperative programming language created by Edwin Brady and Chris Morris in 2003, notorious for using only whitespace characters — spaces, tabs, and line feeds — as syntactically meaningful tokens, while all other characters are treated as comments and ignored. Programs operate on an integer stack and a heap addressed by integers, with instructions grouped into stack manipulation, arithmetic, heap access, flow control (labels, jumps, and subroutine calls), and I/O; it is essentially untyped, working with arbitrary-precision integers and characters. Conceived partly as a joke released around April Fools' Day, it has no practical application and exists mainly as a curiosity and a challenge for writing assemblers, interpreters, and programs whose source is literally invisible in most text editors.
