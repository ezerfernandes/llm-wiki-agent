## Summary
Computer/zero Assembly is the assembly language for Computer/zero, a deliberately minimal hypothetical 8-bit von Neumann machine designed as a teaching tool to illustrate the fundamentals of stored-program computing. It is a low-level, imperative, untyped language in which every value is simply a byte in the single 32-byte memory space shared by code and data; the architecture exposes one accumulator and an instruction set of only eight opcodes (NOP, LDA, STA, ADD, SUB, BRZ, JMP, STP). Each program is hand-assembled into raw machine words, with operands referring directly to memory addresses, so there is no concept of high-level data structures, subroutines, or type checking. Originating in the contemporary Rosetta Code community as a pedagogical simulator rather than real hardware, it is used almost exclusively to demonstrate how arithmetic, branching, and loops are expressed at the bare-metal level on a maximally simplified CPU.
