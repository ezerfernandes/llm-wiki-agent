## Summary
SPAD is the strongly-typed, higher-order functional programming language used to write the library and algebra of the Axiom computer algebra system (originally developed at IBM Research in the 1970s and 1980s as Scratchpad). It features one of the most expressive type systems of any language, built around categories, domains, and packages that model abstract mathematical structures (groups, rings, fields) with dependent and parameterized types, allowing generic algorithms to be specialized over algebraic hierarchies. The language is compiled and is distinct from Axiom's interactive interpreter language (the user-facing read-eval loop), being intended for implementing the system's mathematical algorithms. It remains in use today through the open-source Axiom, FriCAS, and OpenAxiom forks, primarily for symbolic mathematics and computer algebra research.
