## Summary
Visual Basic (classic VB, versions 1.0 through 6.0) is an event-driven programming language and integrated development environment created by Microsoft, first released in 1991 and derived from the earlier BASIC family. It is statically typed (with optional dynamic Variant types) and procedural with limited object-based support, and it became hugely popular for its rapid application development (RAD) model in which developers visually drag and drop controls onto forms to build Windows GUI applications. Through the 1990s it was a dominant tool for line-of-business desktop software, COM/ActiveX components, and database front-ends on Windows. Microsoft discontinued classic VB6 in favor of the substantially redesigned, .NET-based Visual Basic .NET in 2002.
