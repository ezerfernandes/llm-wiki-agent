## Summary
Modula-2 is a structured, imperative, procedural programming language designed by Niklaus Wirth at ETH Zurich around 1978 as a successor to Pascal. It is statically and strongly typed, and its defining innovation is the module — a first-class unit of separately compilable code split into a definition part (the exported interface) and an implementation part — which provides information hiding and clean abstraction boundaries. The language also adds lightweight concurrency via coroutines and dedicated low-level facilities (the SYSTEM module) for systems and embedded programming. It was widely used in the 1980s for teaching, systems software, and real-time applications before being largely supplanted by its own successor, Oberon, and by C and Ada.
