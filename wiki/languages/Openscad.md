## Summary
OpenSCAD is a domain-specific, declarative programming language for creating solid 3D CAD models through code rather than interactive mouse-driven modeling. First released by Marius Kintel and Clifford Wolf in 2010, it is functional in spirit and dynamically typed, with immutable variables and no traditional reassignment, instead composing geometry through constructive solid geometry operations (union, difference, intersection) applied to primitives. Geometry is built using modules and functions that transform and combine shapes, and the language is widely used by makers and engineers to generate precise, parametric models for 3D printing and CNC fabrication.
