## Summary
YAMLScript is a functional, dynamically typed programming language created by Ingy döt Net (a co-creator of YAML) in the early 2020s, whose syntax is itself valid YAML, letting it double as both a programming language and a YAML loader that can compute, transform, and template data at load time. It is a Lisp dialect built on the Clojure-inspired runtime, compiling its YAML-based source through an intermediate Lisp-like form and shipping as a native binary (via GraalVM) with bindings for many host languages. Its primary use is to make static configuration files dynamic — supporting variables, functions, imports, conditionals, and data manipulation — while remaining parseable by ordinary YAML tooling, and it is commonly embedded wherever YAML configuration needs programmability.
