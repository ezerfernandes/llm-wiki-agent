## Summary
The Friendly interactive shell (fish) is an imperative command-line shell and scripting language for Unix-like systems, first released in 2005 with a focus on usability, discoverability, and sane out-of-the-box defaults rather than POSIX sh compatibility. As a shell language it is dynamically typed and effectively string- and list-oriented: every value is a list of strings, and there are no implicit scalar/array distinctions, with control flow handled by familiar constructs like if, switch, for, while, and function. Fish is known for rich interactive features such as syntax highlighting, autosuggestions based on history, and tab completions derived from man pages, deliberately diverging from Bash/Zsh syntax in favor of cleaner, more consistent semantics. It is used primarily for interactive terminal work and shell scripting, automating tasks and gluing together command-line programs.
