## Summary
C3 is a systems programming language created by Christoffer Lerno around 2019 as an evolution of C, aiming to retain C's simplicity and ABI compatibility while modernizing its ergonomics and safety. It is statically and strongly typed with manual memory management, and follows a primarily imperative, procedural paradigm augmented with modern features such as modules, generics (parametric polymorphism via macros and generic modules), optional error handling through fault types, contracts, and built-in slices and vectors. The language compiles ahead-of-time to native code through an LLVM backend and seamlessly interoperates with existing C libraries. It is typically used for low-level and performance-sensitive work where C would be chosen — operating systems, embedded software, tooling, and game engines — but with stronger guard rails against common C pitfalls.
