## Summary
Diego is a small, esoteric stack-oriented programming language created for recreational and pedagogical use, in the same spirit as concatenative toys like Forth and the various Rosetta Code "draft" languages. It is dynamically typed, manipulating values on an implicit operand stack via terse postfix operators rather than named variables, which makes its programs compact but somewhat write-only. Originating in the modern hobbyist-language era, it has no commercial footprint and is encountered almost exclusively as a curiosity for solving short algorithmic puzzles and exploring minimalist language design.
