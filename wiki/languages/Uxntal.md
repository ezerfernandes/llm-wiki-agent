## Summary
Uxntal is the stack-based assembly language for the Uxn virtual machine, a tiny 8-bit personal computing platform created by Devine Lu Linvega of the Hundred Rabbits collective around 2021. As a low-level concatenative language, it has no static type system in the conventional sense; programmers manipulate a working stack of bytes and shorts directly using reverse-Polish notation, with opcodes annotated by mode flags (short, keep, return) rather than declared types. Programs are hand-written and assembled into compact ROM images that run on the minimal Uxn/Varvara stack machine, which exposes simple devices for screen, audio, input, and file I/O. It is used chiefly for small, portable, durable software and creative-computing experiments where minimalism, longevity, and the ability to run on extremely constrained or self-hosted hardware are the primary goals.
