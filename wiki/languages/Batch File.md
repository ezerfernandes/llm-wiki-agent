## Summary
Batch File is the scripting language interpreted by the Windows command processor (cmd.exe), the successor to the MS-DOS COMMAND.COM batch language whose roots reach back to the early 1980s. It is an imperative, interpreted language with no real type system: everything is an untyped string, and even arithmetic must be requested explicitly via SET /A. Programs are plain text files with .bat or .cmd extensions consisting of console commands, control-flow keywords (IF, FOR, GOTO, CALL), labels, and environment-variable expansion, with extra capabilities unlocked by command extensions and delayed expansion. It is used chiefly for system administration, build and deployment automation, software installation, and gluing together command-line utilities on Windows, where its ubiquity guarantees it runs without any additional runtime.
