## Summary
BQN is a modern array programming language in the APL family, created by Marshall Lochbaum in 2020 as a successor that retains APL's terse mathematical notation while cleaning up its semantics. It is a dynamically typed, functional language built around immutable multidimensional arrays and a small set of higher-order operators (combinators), and it introduces a strict tacit (point-free) programming model along with based array theory, where scalars and nested arrays are unified. Programs are written with a compact Unicode glyph set, and BQN runs on implementations such as CBQN, dzaima/BQN, and a self-hosted JavaScript version. It is used primarily for concise data manipulation, numerical and algorithmic experimentation, and array-oriented problem solving rather than large-scale systems programming.
