## Summary
GolfScript is a stack-based, concatenative esoteric programming language created by Darren Smith around 2007, designed specifically for code golf — writing programs in as few characters as possible. It is dynamically typed with a small set of core types (integers, strings, arrays, and blocks), where nearly every operation manipulates an implicit stack and most built-in operators are single ASCII characters. Programs are highly terse and often unreadable, with the language relying on overloaded operators whose behavior depends on operand types. It is used almost exclusively for recreational programming competitions rather than production software.
