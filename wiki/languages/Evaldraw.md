## Summary
Evaldraw is an interactive graphing and visualization environment created by Ken Silverman (author of the Build engine) in the 2000s, centered on a small C-like, dynamically typed scripting language whose expressions are re-evaluated continuously to drive real-time 2D and 3D plots. Programs are written in an imperative, expression-oriented style with built-in operators for vectors, matrices, and graphics, and the editor immediately renders the output as the source is edited. It is used primarily for mathematical experimentation, function plotting, demoscene-style procedural graphics, and rapid visual prototyping rather than for general-purpose application development.
