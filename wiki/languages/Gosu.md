## Summary
Gosu is a statically typed, object-oriented general-purpose programming language that runs on the Java Virtual Machine, originating around 2010 from Guidewire Software where it evolved out of an internal scripting language called GScript. It is fully interoperable with Java but adds modern conveniences such as type inference, closures (blocks), enhancements that retroactively add methods to existing types, and a powerful open type system that lets developers plug in custom types from arbitrary data sources. The language supports both imperative and functional styles and emphasizes a clean, readable syntax while preserving Java-level performance and library access. It is most commonly used for business application development and configuration scripting, particularly within Guidewire's insurance platform products.
