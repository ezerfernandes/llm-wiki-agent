## Summary
AmigaE (often just "E") is a statically typed, compiled procedural programming language created by Wouter van Oortmerssen and released in 1993 for the Commodore Amiga. Syntactically influenced by C, Modula-2, and Ada, it pairs a fast single-pass compiler that emits native 68000 machine code with built-in support for object orientation, exception handling, lightweight inline assembly, and list/string primitives. It was designed for high-productivity application and systems development on AmigaOS, where its tight integration with the Amiga operating system libraries and its compilation speed made it a popular alternative to C among Amiga programmers.
