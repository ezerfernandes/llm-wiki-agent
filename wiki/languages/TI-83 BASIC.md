## Summary
TI-83 BASIC is the interpreted, imperative scripting language built into Texas Instruments' TI-83 series of graphing calculators, introduced in 1996 as part of the TI-82/83 lineage of educational hardware. It is a line-numbered, command-driven dialect of BASIC with dynamic, weakly typed values restricted to a small set of fixed variable names — real numbers (A–Z, theta), lists, matrices, strings, and the answer register Ans — and uses tokenized program storage where each keyword occupies a single byte. The language offers structured control flow (If/Then/Else, For, While, Repeat, Goto/Lbl) alongside calculator-specific primitives for graphing, statistics, and direct screen and I/O manipulation. It is used almost exclusively for on-device math utilities, classroom problem-solving, and simple games, written directly on the calculator keypad or transferred via the TI-GraphLink interface.
