## Summary
BBC BASIC is an imperative, procedural dialect of the BASIC programming language, originally developed by Acorn Computers in 1981 (chiefly designed by Sophie Wilson) for the BBC Micro as part of the BBC's Computer Literacy Project. It is statically and weakly typed with a small set of built-in types, using sigils to distinguish numeric, integer, and string variables, and it notably extended early BASIC with named procedures (PROC), functions (FN), structured control flow, and inline assembly. Successive implementations include the original ROM versions, BBC BASIC for Windows, and the cross-platform BBC BASIC for SDL 2.0, keeping the language in use today for retro-computing, education, and hobbyist programming.
