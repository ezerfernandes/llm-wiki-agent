## Summary
RPG (Report Program Generator) is a high-level, statically typed business-oriented programming language originally created by IBM in 1959 for the IBM 1401, and most strongly associated with the IBM midrange platforms (System/3, System/38, AS/400, and today's IBM i). Early versions used a distinctive fixed-format, column-positional syntax built around an implicit program cycle that automatically read input records, performed calculations, and produced printed reports, reflecting its roots in punched-card tabulating and batch report generation. The language evolved substantially over the decades — RPG II, RPG III, RPG/400, and especially RPG IV (ILE RPG) with its free-format syntax introduced in 2001 — adding modular procedures, structured control flow, embedded SQL, and modern data types while remaining compiled and largely procedural. It is used predominantly for transaction processing and database-driven business applications on IBM i, where vast amounts of legacy enterprise code remain in active production.
