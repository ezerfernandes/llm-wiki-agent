## Summary
ZX Spectrum Basic is the dialect of BASIC built into the ROM of the Sinclair ZX Spectrum, an 8-bit home computer launched in 1982; it was written by Steve Vickers and based on the earlier Sinclair ZX81 BASIC. It is an imperative, line-numbered, interpreted language with dynamic but weak typing, distinguishing only numeric variables, string variables (suffixed with $), and arrays, and it is famous for its single-keystroke keyword entry system where each key stamps a whole token like PRINT or GOTO. Programs rely on GOTO/GOSUB control flow, single-letter FOR loop variables, and direct hardware access via PEEK, POKE, and machine-code calls (USR) for graphics, sound (BEEP), and speed-critical routines. It was the primary introductory and games-programming language for a generation of British home users in the 1980s, and today survives mainly through emulators and retro-computing hobbyists.
