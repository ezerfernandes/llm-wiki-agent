## Summary
The UNIX shell is an imperative, command-oriented scripting language and interactive command interpreter, originating with Ken Thompson's Thompson shell in early-1970s Unix and maturing through the Bourne shell (1979) and its successors such as the Korn shell, C shell, and the POSIX-standardized and now-ubiquitous Bash. It is dynamically and weakly typed, treating nearly everything as untyped strings that are word-split and expanded at runtime, with control flow, pipelines, and command substitution layered over the orchestration of external programs. Programs are written as sequences of commands glued together by pipes, redirection, and variable expansion rather than rich data structures, giving the language its characteristic terseness and reliance on standard Unix utilities. It is used primarily for system administration, build and deployment automation, file and text processing, and gluing together other tools, serving as the default automation layer on virtually every Unix-like operating system.
