## Summary
Quackery is a concatenative, stack-based programming language created by Gordon Charlton in the late 2010s, heavily inspired by Forth and implemented as a small interpreter that runs on top of Python. Like Forth it is procedural and dynamically typed, manipulating values on a data stack via space-delimited words and reverse Polish notation, while adding modern conveniences such as arbitrary-precision (bignum) integers, nested lists, and a built-in unicode-aware text model. Programs are built by defining new words from existing ones, encouraging a bottom-up factoring style, and the language ships with a literate, self-documenting "shaker" of vocabulary words. It is primarily a hobbyist and educational language, popular for recreational programming and puzzle-solving on sites such as Rosetta Code rather than for production software.
