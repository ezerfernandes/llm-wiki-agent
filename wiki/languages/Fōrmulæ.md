## Summary
Fōrmulæ is a visual, structure-oriented programming environment created by Laurentiu Cristofor in which programs are written and manipulated as editable expression trees rather than as flat character-based source text. Programs are represented internally as semantic expressions and rendered with rich mathematical notation, blending a functional and symbolic-computation style with term-rewriting and dynamic typing. Originating in the 2010s and built on web and JavaScript technologies, it ships as a browser-based IDE where computation proceeds by applying reduction rules to expressions. It is used mainly for mathematical, educational, and exploratory programming where notation and visual structure matter as much as the underlying logic.
