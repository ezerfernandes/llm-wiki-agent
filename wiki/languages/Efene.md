## Summary
Efene is a programming language created around 2011 by Mariano Guerra that targets the Erlang virtual machine (BEAM), offering an alternative, more conventional syntax over Erlang's Prolog-inspired notation while compiling down to the same bytecode. It is functional and concurrent, embracing the actor model and lightweight processes that the BEAM provides, and is dynamically typed in keeping with Erlang's runtime semantics. The language supports two surface syntaxes — a C/Python-like form and a Lisp-like form (ifene) — both of which interoperate seamlessly with existing Erlang and Elixir code. It is typically used for the same domains as Erlang: highly concurrent, fault-tolerant, distributed server-side systems.
