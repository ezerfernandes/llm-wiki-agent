## Summary
Sinclair ZX81 BASIC is the dialect of BASIC built into the ROM of the Sinclair ZX81, the inexpensive 8-bit home microcomputer released in 1981. It is an imperative, line-numbered, interpreted language in the classic Dartmouth BASIC tradition, with weak dynamic typing centered on floating-point numbers and strings, and it relied on a distinctive single-keystroke keyword-entry system to fit within the machine's tiny 1 KB of RAM. The dialect was notably constrained, lacking string arrays and multi-dimensional string handling, and arithmetic ran slowly because the Z80 CPU was shared with screen generation. It was used chiefly for hobbyist programming, learning to code, and small games and utilities on early-1980s home computers.
