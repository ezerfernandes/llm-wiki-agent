## Summary
GlovePIE (Glove Programmable Input Emulator) is a free Windows scripting environment created by Carl Kenner in the mid-2000s, originally to emulate input from the Essential Reality P5 data glove and later expanded to map almost any input device — Wii Remotes, joysticks, keyboards, mice, MIDI, voice recognition, and more — onto emulated keyboard, mouse, and gamepad output. Its language is an event-driven, dynamically typed scripting language whose lines are continuously re-evaluated each frame, so a script reads as a set of declarative bindings (e.g. mapping a button to a keypress) rather than a conventional sequential program, though it also supports variables, conditionals, and standard imperative control flow. Typing is dynamic and weak, with automatic coercion between numbers, strings, and booleans, and built-in physical units for sensor data. It is used almost exclusively for input remapping, accessibility hacks, and unconventional human-computer interaction setups rather than general-purpose application development.
