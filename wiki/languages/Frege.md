## Summary
Frege is a purely functional, statically typed programming language for the Java Virtual Machine, designed by Ingo Wechsung and first released around 2011 as a close dialect of Haskell. It features lazy (non-strict) evaluation, Hindley-Milner type inference with type classes, algebraic data types, and the same monadic approach to side effects as Haskell, while compiling down to JVM bytecode. Its defining characteristic is seamless interoperability with the Java ecosystem, letting developers call Java libraries and run on the JVM while writing idiomatic Haskell-style code. It is typically used to bring pure functional programming to Java-platform projects and is named after the logician Gottlob Frege.
