## Summary
Arturo is a free, open-source programming language created by Yanis Zafirópulos (Dr.Kameleon) and first released in 2019. It is an interpreted, expressive, multi-paradigm language built around homoiconic code and a flexible Lisp-inspired core, while presenting concise, Ruby-like surface syntax; it is dynamically typed and organizes computation around blocks of values, symbols, and functions, blending functional, imperative, and concatenative styles. Everything is treated as a first-class value, and the runtime supports rich built-in types together with a large standard library of functions. Arturo is typically used for scripting, rapid prototyping, command-line tools, and small web or general-purpose applications where terse, readable code and quick iteration are valued.
