## Summary
Fantom is a general-purpose, object-oriented programming language created by Brian and Andy Frank, first released in 2005, designed to run portably across both the Java Virtual Machine and the .NET Common Language Runtime (with later JavaScript support for the browser). It is statically typed but supports a dynamic invocation operator and optional nullable types, blending the safety of static typing with the flexibility of dynamic dispatch, and it emphasizes a clean, concise syntax with first-class closures, built-in immutability, and an actor-based concurrency model. Fantom ships with its own portable module and namespace system and a rich standard library, targeting cross-platform application development where the same code must deploy across multiple runtime environments.
