## Summary
Cowgol is a small, statically typed, imperative procedural programming language created by David Given in the late 2010s, with an ALGOL- and Pascal-influenced syntax. It is designed expressly for self-hosting on extremely resource-constrained 8-bit and 16-bit machines such as the Z80, 6502, 8080, and PDP-11, so its compiler is structured as a chain of small passes that can run within tiny memory budgets. The language emphasizes explicit, fixed-width integer and pointer types, manual memory management, and a deliberately minimal feature set with no runtime garbage collection. It is used primarily for retrocomputing and bare-metal systems programming where producing compact, efficient native code on legacy hardware is the goal.
