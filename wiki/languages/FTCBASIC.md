## Summary
FTCBASIC is a compact, imperative dialect of the BASIC programming language designed for FTC (the Compact BASIC Compiler / FTC BASIC compiler) targeting small systems and resource-constrained environments. Like classic BASIC variants it is procedural and uses weak, mostly static typing centered on numeric and string types, with line-oriented or structured statements depending on the implementation. It belongs to the long lineage of microcomputer-era BASIC compilers and is used chiefly for small utility programs, learning exercises, and lightweight computational tasks rather than large-scale software.
