## Summary
6502 Assembly is the low-level, imperative assembly language for the MOS Technology 6502, an 8-bit microprocessor introduced in 1975 that powered seminal machines such as the Apple II, Commodore 64, Atari 2600/800, and the Nintendo Entertainment System. The language is untyped, operating directly on bytes in registers (the accumulator A, index registers X and Y, stack pointer, and processor status flags) and a 16-bit address space, with programming centered on hand-managed memory, zero-page addressing tricks, and a compact instruction set lacking hardware multiply or divide. Code is written as mnemonics (LDA, STA, JSR, BNE, etc.) assembled to native machine code, demanding manual control flow, subroutine and stack management, and careful cycle counting. It remains widely used in retrocomputing, emulator and demoscene development, embedded 8-bit projects, and as a teaching vehicle for computer architecture fundamentals.
