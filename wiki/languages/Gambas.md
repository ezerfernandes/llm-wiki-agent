## Summary
Gambas is a free, object-oriented, event-driven programming language with a BASIC-derived syntax, created by Benoît Minisini around 1999 and inspired by Microsoft's Visual Basic. It is statically typed (with optional type inference via the `Dim ... As` declarations) and runs on a bytecode interpreter, shipping with an integrated development environment that emphasizes rapid GUI application development on Linux and other Unix-like systems. Gambas applications are organized into projects of classes and forms, and the language is most commonly used to build desktop applications, database front-ends, and small utilities, offering a gentle, accessible path for former Visual Basic developers moving to open-source platforms.
