## Summary
Jactl is a JVM-based scripting and programming language created by James Crawford around 2022, with a syntax heavily influenced by Java, Groovy, and Perl. It is a dynamically typed language that also supports optional static typing, blends imperative and functional styles, and offers first-class functions, closures, regular expressions, and built-in JSON handling. Jactl compiles to JVM bytecode and is designed to be embedded within Java applications as a secure, sandboxed scripting layer, supporting features like asynchronous, non-blocking execution and suspendable/resumable continuations. Its typical use is event-driven and customization scripting inside larger Java systems where untrusted or user-supplied logic must run safely without blocking host threads.
