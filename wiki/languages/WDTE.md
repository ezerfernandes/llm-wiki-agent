## Summary
WDTE is a small, embeddable, functional scripting language designed to be imported into Go programs, emerging in the late 2010s as a lightweight alternative to embedding heavier interpreters. It is dynamically typed and emphasizes a minimal, expression-oriented syntax built around first-class functions, currying, and a pipe-style chaining operator that threads data through transformations. Programs are typically written as collections of small functions, with control flow expressed through function application and switch expressions rather than imperative statements. Its primary use is as a configuration and extension language, letting host Go applications expose their own functions to user-supplied scripts while keeping the runtime sandboxed and dependency-free.
