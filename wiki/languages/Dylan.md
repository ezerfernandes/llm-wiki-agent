## Summary
Dylan is a multi-paradigm language blending functional and object-oriented programming, descended from Lisp and CLOS, with a more conventional, optionally infix syntax. It was created by Apple in the early 1990s (originally intended for the Newton platform) and uses dynamic typing by default while supporting optional static type annotations to enable performance optimization. Distinctive features include multiple dispatch via generic functions, a powerful macro system, first-class functions, and a hygienic module/library system. Though never widely adopted commercially, it influenced later languages and remains in use through the Open Dylan implementation, mainly for research, teaching, and experimental systems programming.
