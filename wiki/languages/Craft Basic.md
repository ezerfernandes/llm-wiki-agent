## Summary
Craft Basic is a modern interpreted dialect of the BASIC programming language created by Craig DeForest (under the "Craft" software banner) for Windows in the 2010s era. It is an imperative, procedural language with dynamic typing and the traditional line-oriented, unstructured-to-lightly-structured BASIC style, supporting numeric and string variables, GOTO/GOSUB control flow, and built-in graphics and form commands. Distributed as a freeware IDE-and-interpreter package, it targets hobbyist programming, retro-style BASIC coding, simple GUI applications, and educational use rather than large-scale or systems software.
