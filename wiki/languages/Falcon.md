## Summary
Falcon is a multi-paradigm, dynamically typed scripting language created by Giancarlo Niccolai in the mid-2000s, blending procedural, object-oriented, functional, and message-oriented programming styles in a single, embeddable engine. It uses dynamic typing with automatic garbage collection and was designed primarily to be embedded inside larger C/C++ applications as well as run standalone, offering features such as coroutines, closures, and a rich virtual-machine-based runtime. In practice it was used for application scripting, rapid prototyping, and extending host programs, though the project has seen little active development in recent years.
