## Summary
ReScript is a strongly, statically typed functional programming language that compiles to readable, performant JavaScript, evolving out of the BuckleScript/ReasonML lineage and rebranded under its own name and JavaScript-flavored syntax in 2020. Rooted in OCaml's type system and semantics, it features sound type inference (Hindley-Milner with row polymorphism), algebraic data types, pattern matching, and immutability by default, eliminating most runtime type errors without requiring explicit annotations. It targets front-end and full-stack web development as a safer, more ergonomic alternative to TypeScript, interoperating cleanly with existing JavaScript and React codebases.
