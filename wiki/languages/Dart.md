## Summary
Dart is a class-based, object-oriented programming language developed by Google and first released in 2011, originally intended as a more structured alternative to JavaScript for web development. It is statically typed with sound null safety, supports type inference, and combines multi-paradigm features including object-oriented, imperative, and functional styles with first-class support for asynchronous programming via futures, streams, and async/await. Dart compiles ahead-of-time to native machine code or to JavaScript, and offers a just-in-time compiler with hot reload during development. Today it is most prominently used as the language behind the Flutter framework for building cross-platform mobile, web, and desktop applications from a single codebase.
