## Summary
Tiny BASIC is a minimalist, imperative dialect of BASIC designed in 1975-1976 as part of the People's Computer Company response to the high cost of Altair BASIC, intended to fit in just a few kilobytes of memory on early microcomputers. It is an interpreted, line-numbered, unstructured language whose programs are built from GOTO/GOSUB control flow and a single data type: 16-bit signed integers stored in 26 fixed variables named A through Z. Its tiny specification—typically implemented via a compact virtual machine and an interpretive language (IL) bytecode—made it a popular hobbyist target for bootstrapping a usable programming environment on resource-constrained 8-bit hardware. Today it survives mainly as an educational curiosity and a benchmark for writing minimal interpreters.
