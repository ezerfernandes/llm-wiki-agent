## Summary
Liberty BASIC is a commercial dialect of the BASIC programming language created by Carl Gundel and first released in 1992 for Microsoft Windows. It is an imperative, procedural, event-driven language with dynamic, weak typing (variables are untyped, with a trailing `$` distinguishing strings from numbers), interpreted via a Smalltalk-based runtime rather than compiled to native code. Its defining feature is built-in, beginner-friendly support for rapid GUI development, letting programmers create windows, buttons, and graphics with simple commands. It targets hobbyists, students, and educators on Windows, prioritizing approachability over performance.
