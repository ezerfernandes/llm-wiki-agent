## Summary
Ela is a pure, dynamically typed functional programming language created around 2011 by Basil Voronkov, drawing heavily on Haskell, Clean, and other ML-family languages while trading static type checking for runtime flexibility. It is non-strict (lazy by default), supports first-class functions, pattern matching, algebraic data types, type classes, and partial application, and runs on a portable virtual machine implemented on the .NET/CLR platform. Despite its functional purity it embraces a dynamic typing discipline, allowing rapid, REPL-driven exploration in a Haskell-like syntactic style. It is primarily an experimental and research-oriented language used for studying functional programming techniques rather than for mainstream production work.
