## Summary
SSEM refers to programming the Manchester Small-Scale Experimental Machine (the "Baby"), the world's first electronic stored-program computer, which ran its first program in June 1948. It is an imperative, low-level machine language driven by a minimal instruction set of just seven opcodes, operating on a single 32-word store of signed 32-bit integers held in Williams-Kilburn cathode-ray-tube memory. Notably, words are stored and read least-significant-bit first, the machine has only subtraction (no addition) and negation for arithmetic, and there is a single accumulator with no general-purpose registers. As a historical architecture it is used today almost exclusively for emulation, teaching the origins of computing, and demonstrating how higher-level constructs reduce to primitive bit-level operations.
