## Summary
BootBASIC is a minimalist, imperative BASIC dialect designed to run from a PC boot sector — the entire interpreter and runtime fit within the 512-byte master boot record, so it executes in 16-bit real mode without an underlying operating system. Like classic line-numbered BASIC, it is an interpreted, dynamically typed language built around a tiny command set (variables, arithmetic, GOTO/GOSUB-style control flow, and direct keyboard and screen I/O) rather than structured programming constructs. It emerged in the modern hobbyist and retrocomputing scene as a demonstration of extreme code-size constraints, and its typical use is educational and recreational: writing tiny self-booting programs that explore what is possible at the bare-metal, sub-kilobyte level.
