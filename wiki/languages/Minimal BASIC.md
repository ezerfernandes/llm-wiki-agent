## Summary
Minimal BASIC is the language defined by the ANSI X3.60-1978 and ISO 6373:1984 standards, codifying the smallest conforming subset of BASIC that every implementation must support. It is an imperative, line-numbered procedural language with mandatory GOTO/GOSUB control flow, a single numeric (floating-point) type plus string variables, and arrays limited to one or two dimensions, reflecting the interactive, interpreted style of mid-1960s through 1970s BASIC dialects pioneered at Dartmouth. Typing is weak and largely implicit, with variable names restricted to a single letter optionally followed by a digit, and string variables denoted by a trailing dollar sign. It originated as an effort to standardize and ensure portability across the proliferation of incompatible BASIC interpreters, and today it serves mainly as a historical reference point and a target for writing maximally portable, retro-compatible BASIC programs.
