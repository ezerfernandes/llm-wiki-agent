## Summary
Plain TeX is the macro package and base format that Donald Knuth bundled with the TeX typesetting system in the early 1980s, providing a minimal layer of macros atop TeX's primitive commands for document preparation. As a typesetting language it is fundamentally macro-expansion based and Turing complete, but it is dynamically and untyped in any conventional sense, treating everything as token streams manipulated through definitions, expansion, boxes, and glue. Its programming model is unusual—stringly typed, with mouth/stomach token processing, integer and dimension registers, and no native data structures—making general computation awkward yet possible. In practice it is used to format technical documents, books, and mathematics, and it served as the foundation later extended by LaTeX, though Rosetta Code tasks exploit its macro machinery to perform arithmetic, string, and algorithmic exercises.
