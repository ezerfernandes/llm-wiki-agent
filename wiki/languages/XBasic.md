## Summary
XBasic is a procedural, statically typed dialect of BASIC originally developed by Max Reason in the early 1990s for the Amiga and later ported to Windows and Linux, where it was eventually released as free software. It ships with an integrated visual development environment for building GUI applications and supports an explicit type system with both 32-bit and 64-bit data types, pointers, and inline assembly, compiling programs to native machine code rather than interpreting them. The language separates each program into distinct "PROGRAM" sections with explicit variable declarations, giving it a more structured feel than classic line-numbered BASIC. It was primarily used for cross-platform desktop application development and graphical tools during the late 1990s and 2000s.
