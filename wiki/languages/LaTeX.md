## Summary
LaTeX is a document preparation and typesetting system built as a macro package on top of Donald Knuth's TeX, originally created by Leslie Lamport in the mid-1980s. Its underlying TeX engine is a macro-expansion language that is Turing-complete, so although LaTeX is used declaratively for marking up structured documents, its programming model is essentially untyped macro rewriting where everything is treated as token streams rather than typed values. It is dominated by stack-based, expandable macros and length/counter registers, with arithmetic and control flow handled by primitives or helper packages such as calc, ifthen, and pgf/TikZ. LaTeX is most commonly used to produce technical and scientific documents — papers, books, theses, and mathematical notation — but in the Rosetta Code context it is occasionally pushed into general computation to demonstrate the typesetting language's surprising programmability.
