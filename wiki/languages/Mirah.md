## Summary
Mirah is a statically typed, object-oriented programming language created by Charles Oliver Nutter around 2008–2010, originally under the name "Duby." It pairs a Ruby-inspired syntax with local type inference and compiles directly to JVM bytecode, producing class files that run on the Java Virtual Machine with no additional runtime library or performance penalty. Mirah supports Java interoperability, optional explicit type annotations, and AST macros for compile-time metaprogramming, blending Ruby's expressiveness with Java's performance. It was used chiefly for writing fast, dependency-free JVM code with a clean, scripting-like feel, and inspired later JVM languages such as Mirah-derived tooling in the JRuby ecosystem.
