## Summary
Axe is an imperative, structured programming language created around 2010 by Kevin Horowitz (Quigibo) for Texas Instruments TI-83/84 series graphing calculators, built atop the Z80 assembly toolchain. It is statically and weakly typed, operating almost entirely on untyped 16-bit integers and raw memory pointers with no floating-point support, giving it a low-level, assembly-adjacent character. The Axe Parser compiles its C-like source directly into native Z80 machine code, producing standalone executables far faster than interpreted TI-BASIC. It is used primarily by the calculator hobbyist and homebrew community to write games, graphics demos, and utilities that need real-time performance on resource-constrained hardware.
