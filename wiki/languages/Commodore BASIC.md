## Summary
Commodore BASIC is a dialect of the BASIC programming language that shipped in the ROM of Commodore's 8-bit home computers, beginning with the PET in 1977 and famously including the version 2.0 found in the VIC-20 and Commodore 64. Derived from a Microsoft BASIC license, it is an imperative, line-numbered, interpreted language with weak dynamic typing built around floating-point numerics, integer and string variables, and arrays. Programs were entered and edited interactively at the screen prompt, and the language was the default user interface and primary programming environment for these machines, often supplemented by PEEK/POKE and machine-language calls to reach hardware features such as sprites and sound. It defined the first programming experience for a generation of home users in the late 1970s and 1980s.
