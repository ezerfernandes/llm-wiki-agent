## Summary
Rascal is a domain-specific, statically typed metaprogramming language created around 2009 by Paul Klint, Jurgen Vinju, and Tijs van der Storm at CWI in the Netherlands, designed for source code analysis, transformation, and the construction of domain-specific languages. It blends functional and rule-based paradigms with built-in immutable collection types, rich pattern matching, term rewriting, relational calculus operators, and concrete syntax matching backed by parsing technology derived from SDF/GLL. The language runs on the JVM and integrates with Eclipse and VS Code, exposing libraries for grammars, abstract syntax trees, fact extraction, and visualization. It is used primarily in software language engineering, reverse engineering, and empirical software analysis tasks where querying and rewriting large program representations is central.
