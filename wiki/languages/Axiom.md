## Summary
Axiom is an open-source general-purpose computer algebra system descended from IBM's Scratchpad, whose development began in the 1970s before the system was commercialized as Axiom in the 1990s and later released as free software in 2002. It combines symbolic mathematics with a strongly and statically typed, interpreted programming language whose distinctive feature is a rich hierarchy of mathematical types organized through categories, domains, and packages, supporting dependent types and parametric polymorphism that mirror abstract algebraic structures. The language is largely functional in style and emphasizes mathematical rigor, automatically inferring or coercing types so that expressions are evaluated within the most appropriate algebraic domain. It is used primarily for advanced symbolic computation, research-grade mathematics, and education, with extension code typically written in its companion language SPAD.
