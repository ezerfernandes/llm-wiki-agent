## Summary
ed is the standard line-oriented text editor for Unix, written by Ken Thompson around 1969 at Bell Labs and one of the first programs developed for the original Unix system. On Rosetta Code it is treated as a "language" because its terse command set — addressing lines by number, regular-expression context, or relative offset, then applying operations like substitute (s), append (a), delete (d), and write (w) — can be scripted to perform programmatic text transformations. It is an imperative, command-driven editor with no real notion of data types: everything is manipulated as lines of text held in an edit buffer. Though largely superseded for interactive use by vi and modern editors, ed remains useful in scripts, on minimal or recovery systems, and is the conceptual ancestor of the ed-style regular-expression and substitution syntax later inherited by sed, grep, and vi.
