## Summary
Agena is a procedural, dynamically typed scripting language created by Alexander Walz in the mid-2000s, designed as a more feature-rich and accessible alternative to Lua, from whose virtual machine it derives. It combines Algol 68 and Lua-inspired syntax with a rich built-in standard library covering mathematics, string processing, and data structures, supporting first-class functions, multiple assignment, and native types such as complex numbers, sets, sequences, registers, and pairs. The language is interpreted and embeddable, running on Windows, Linux, macOS, and other platforms, and is typically used for interactive numerical and scientific computation, rapid prototyping, text manipulation, and general-purpose scripting.
