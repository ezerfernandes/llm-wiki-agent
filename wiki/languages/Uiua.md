## Summary
Uiua is a stack-based, array-oriented programming language created by Kai Schmidt in 2023, drawing heavily on the APL/J/BQN tradition while combining it with a concatenative, point-free style reminiscent of Forth and Joy. It is dynamically typed over a small set of value types (numbers, characters, boxes, and multidimensional arrays) and enforces a distinctive syntactic rule whereby functions are written with tacit composition and most primitives are denoted by single Unicode glyphs, so well-formed code can be tokenized unambiguously without naming intermediate values. Programs manipulate a value stack using terse combinators (modifiers like reduce, rows, and fork) that apply rank-polymorphic operations across entire arrays at once. It is used primarily for concise numerical and data-transformation tasks, mathematical experimentation, and code-golf-style problem solving where its compact array idioms shine.
