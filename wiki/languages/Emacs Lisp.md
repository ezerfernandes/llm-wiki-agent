## Summary
Emacs Lisp (Elisp) is a dialect of Lisp that serves as the extension and scripting language of the GNU Emacs text editor, introduced by Richard Stallman in the mid-1980s and derived largely from Maclisp. It is a dynamically typed, predominantly functional language that also embraces imperative and rudimentary object-oriented styles, and—unlike Common Lisp or Scheme—it is deeply integrated with the editor, exposing buffers, windows, and text properties as first-class objects. Traditionally interpreted (with an optional byte-compiler and, in modern versions, native compilation via libgccjit), it uses dynamic scoping by default while supporting lexical binding since Emacs 24. Its typical use is customizing and automating Emacs itself, from key bindings and minor modes to full applications like the Org-mode planner, Gnus mail reader, and Magit Git interface.
