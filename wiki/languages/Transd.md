## Summary
Transd is a general-purpose, multi-paradigm programming language created in the early 2020s that blends object-oriented, procedural, and functional styles around a uniform "program text" representation in which code and data share a common s-expression-like syntax. It is statically typed with strong type inference, distinguishing it from many scripting languages while keeping source notation compact and embeddable. The reference implementation runs as an interpreter (and embeddable engine) targeting C++ host applications, and it ships its standard library as Transd source. In practice it is used for scripting, embedding logic into native programs, and prototyping, where its concise syntax and rich built-in collection and string facilities make it well suited to the kinds of algorithmic tasks collected on Rosetta Code.
