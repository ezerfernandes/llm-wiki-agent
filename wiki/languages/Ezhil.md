## Summary
Ezhil is an imperative, procedural programming language with dynamic typing whose keywords, syntax, and number system are written entirely in the Tamil script, making it one of the few programming languages designed around a non-Latin natural language. Created by Muthiah Annamalai and released around 2007-2009, it is interpreted and implemented in Python, with semantics broadly similar to BASIC or Python translated into Tamil. Its primary purpose is educational: to teach computer programming and computational thinking to native Tamil speakers, particularly schoolchildren, in their own language rather than through English-based syntax.
