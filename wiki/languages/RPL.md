## Summary
RPL (Reverse Polish Lisp) is a stack-based, postfix programming language developed by Hewlett-Packard in the 1980s as the system and user language for its high-end graphing and scientific calculators, beginning with the HP-28C in 1986 and continuing through the HP-48, HP-49, and HP-50g series. It blends a Forth-like Reverse Polish Notation execution model with structured-programming control constructs and Lisp-inspired ideas such as treating programs and objects as first-class data on a runtime stack. The language is dynamically typed, operating over a rich set of built-in object types — reals, complex numbers, vectors, matrices, strings, lists, algebraic expressions, and embedded programs — making it well suited to interactive mathematics, symbolic algebra, and engineering computation on resource-constrained handheld hardware. RPL exists in two layers, an internal "System RPL" used to implement the calculator firmware and the higher-level "User RPL" exposed to end users for writing keystroke and computational programs.
