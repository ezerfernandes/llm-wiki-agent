## Summary
Euphoria (End-User Programming with Hierarchical Objects for Robust Interpreted Applications) is an imperative, procedural programming language created by Robert Craig and first released in 1993, originally for DOS. It uses a simple, readable syntax and a deliberately minimal type system built on just two fundamental data types — atoms (numbers) and sequences (dynamic, arbitrarily nested arrays) — with optional user-defined types that are checked at runtime, giving it a dynamic but optionally constrained typing discipline. Programs are typically run through an interpreter or translated to C and compiled for speed, and the language was later modernized in the open-source OpenEuphoria fork. It has been used mainly for general-purpose scripting, educational programming, text and data processing, and small to medium applications where ease of learning and fast development matter more than enterprise tooling.
