## Summary
Unlambda is a minimalist, purely functional esoteric programming language created by David Madore in 1999, designed to demonstrate programming based entirely on the SKI combinator calculus while deliberately omitting features programmers take for granted. It is essentially untyped, having no variables, no named functions, no data structures, and no numbers; everything is a function applied via the prefix application operator backtick, with the core primitives being the s and k combinators plus i (identity). Its only side-effecting facilities are character I/O builtins and the notorious c continuation operator (call/cc), making it a favorite vehicle for exploring first-class continuations and lazy versus eager evaluation. In practice Unlambda is used purely for academic and recreational purposes as a proof that combinator-only computation is Turing-complete, not for any real-world software.
