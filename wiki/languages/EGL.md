## Summary
EGL (Enterprise Generation Language) is a statically typed, high-level procedural language created by IBM in the mid-2000s, evolving from earlier 4GL tools such as VisualAge Generator and Informix 4GL. It follows a write-once, generate-anywhere model in which EGL source is compiled into target platform code (Java, JavaScript, or COBOL), letting developers build end-to-end business applications without hand-writing the underlying runtime languages. Its declarative records, data-access constructs, and built-in support for web, rich-client, and batch tiers make it primarily suited to enterprise data-processing and transactional systems. EGL was later released as open source through the Eclipse EGL Development Tools (EDT) project.
