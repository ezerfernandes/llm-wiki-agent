## Summary
TMG (TransMoGrifier) is a recursive-descent compiler-compiler created by Robert M. McClure around 1963, used to write language translators by specifying parsing rules and the corresponding output actions. It is a declarative, rule-based metalanguage in which a program is a set of named parsing productions that match input, build syntax trees, and emit translated text, rather than a general-purpose imperative language with a conventional type system. TMG is best known historically as the tool Ken Thompson used to implement the B language on early Unix, and it ran on systems such as Multics and the PDP-7/PDP-11. Today it is essentially a research and retrocomputing curiosity, predating and influencing later parser-generator tools like yacc and lex.
