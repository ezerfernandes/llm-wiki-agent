## Summary
Stax is a stack-based, concatenative golfing language created by Tom Theisen around 2018, designed expressly to solve programming puzzles in as few bytes as possible. It is dynamically typed with a small set of values (integers, rationals, floats, strings/arrays, and blocks), manipulating an implicit data stack through terse single-character instructions. Stax offers two interchangeable representations — a readable ASCII source form and a tightly packed binary form that uses a custom code page — so programs can be authored legibly and then compressed for byte-count competitions. Like other golfing languages it is used almost exclusively for code-golf challenges and recreational programming rather than production software.
