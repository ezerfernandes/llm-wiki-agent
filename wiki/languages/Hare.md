## Summary
Hare is a systems programming language created by Drew DeVault and first announced in 2022, designed as a simpler, more conservative alternative to C for writing operating systems, compilers, and other low-level software. It is a statically and strongly typed, compiled, imperative language with manual memory management, a small specification, and no runtime garbage collector, emphasizing stability, minimalism, and a complete standard library that avoids external dependencies. Hare uses the QBE compiler backend, targets a handful of platforms (primarily Linux and BSD on common architectures), and deliberately omits features like generics and macros to keep the language and toolchain easy to understand and maintain.
