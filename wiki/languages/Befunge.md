## Summary
Befunge is an esoteric, stack-based programming language created by Chris Pressey in 1993, notable for being one of the first deliberately multidimensional languages: its source code is a two-dimensional grid that an instruction pointer traverses in any of four directions, with control-flow arrows redirecting execution rather than the usual top-to-bottom flow. It is untyped at the language level, operating on a single stack of integers (with characters represented by their numeric values), and the canonical Befunge-93 dialect is self-modifying, allowing a program to read and overwrite its own cells at runtime. Designed expressly to be hard to compile, it serves no practical production role and instead lives in the realm of recreational programming, code golf, obfuscation contests, and explorations of unconventional execution models.
