## Summary
Lambdatalk is a purely functional, applicative programming language created by Alain Marty around 2015, designed to be embedded directly in HTML wiki pages so that documents and the code that generates them live together. Its uniform syntax is built from S-expression-like braced forms `{function args...}` evaluated by a small lambda-calculus-inspired engine called LAMBDA TANK, with first-class lambdas, lazy special forms, and a macro-style `def` for defining new words. The language is dynamically typed, treating most values as strings or whitespace-separated lists, and avoids mutable state in favor of function composition and recursion. It is used chiefly for live, literate web authoring—interactive math, graphics (SVG), and educational demonstrations—rather than general systems programming.
