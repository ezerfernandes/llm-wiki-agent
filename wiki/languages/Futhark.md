## Summary
Futhark is a purely functional, statically typed array programming language designed for data-parallel computation, with a strict (eager) evaluation model and Hindley-Milner-style type inference augmented by size types that track array dimensions. Developed since around 2013 by a research group at the University of Copenhagen (notably Troels Henriksen), it compiles to efficient parallel code targeting GPUs via CUDA and OpenCL as well as multicore CPUs and sequential C. The language deliberately omits I/O and general recursion in favor of bulk parallel operations such as map, reduce, scan, and scatter, leaving program orchestration and side effects to a host language. It is typically used as an embedded high-performance kernel language, generating libraries callable from Python, C, Haskell, and other ecosystems for numerical and scientific workloads.
