## Summary
ArkScript is a small, functional, Lisp-like scripting language created by Alexandre Plateau around 2019, designed to be embedded in C++ applications. It is dynamically typed and compiles source code to bytecode that runs on a lightweight register/stack-based virtual machine, supporting features such as first-class functions, closures, macros, tail-call optimization, and a minimal s-expression syntax. The language emphasizes a tiny, dependency-free footprint and easy interoperability with host C++ code, making it well suited for scripting, configuration, and extending native applications rather than standalone large-scale development.
