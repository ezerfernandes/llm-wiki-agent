## Summary
Xojo is a commercial, object-oriented programming language and cross-platform RAD (rapid application development) environment, originally released in 1998 as REALbasic and renamed Xojo in 2013. It uses a statically typed, BASIC-derived syntax and centers on a drag-and-drop visual designer paired with an event-driven, class-based programming model. From a single codebase it compiles native desktop applications for macOS, Windows, and Linux, as well as web, iOS, Android, and Raspberry Pi targets. It is most commonly used by small teams and independent developers to build business and line-of-business GUI applications without the steep learning curve of lower-level languages.
