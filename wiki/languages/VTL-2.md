## Summary
VTL-2 (Very Tiny Language, version 2) is a minimalist interpreted programming language created by Frank McCoy and Gary Shannon in 1977 for the MITS Altair 680b microcomputer, where its complete interpreter fit within 768 bytes of ROM. It is an imperative, line-numbered language in the BASIC tradition, but radically terse: program flow, I/O, and even system state are manipulated through assignments to a small set of magic single-character system variables (such as # for the current line number, ? for console I/O, and $ for character output), with all user variables being single letters holding 16-bit unsigned integers. Typing is effectively untyped at the surface, treating every value as a machine integer, and expressions are evaluated strictly left to right with no operator precedence. Designed for severely memory-constrained 8-bit hobbyist machines, it is today encountered chiefly as a retrocomputing curiosity and a benchmark of extreme language economy.
