## Summary
Robotic is the imperative, event-driven scripting language built into Mega Zeux (MZX), a tile-based game-creation system originating in the late 1990s as a successor to ZZT. Each on-screen Robot object runs its own program composed of simple line-oriented commands and labels, with execution paused and resumed by message-passing cycles tied to the game loop. It is weakly and dynamically typed, exposing a fixed pool of global numeric counters and string variables rather than user-defined data structures, and relies on labels with GOTO/SEND-style control flow instead of conventional functions. Its typical use is authoring game logic, enemy behavior, and interactive puzzles within MegaZeux worlds rather than general-purpose programming.
