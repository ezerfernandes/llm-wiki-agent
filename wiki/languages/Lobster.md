## Summary
Lobster is a statically typed, multi-paradigm programming language created by Wouter van Oortmerssen, first released around 2014. It blends imperative, functional, and object-oriented styles with a Python-like indentation-based syntax, and is notable for its compile-time type inference (so type annotations are usually optional) and its compile-time memory management based on reference counting with lifetime analysis, avoiding a runtime garbage collector. Lobster compiles to its own bytecode VM or to C++ for native performance, and ships with built-in support for graphics, sound, and physics. It is primarily aimed at game development and other interactive, real-time multimedia applications.
