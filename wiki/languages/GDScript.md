## Summary
GDScript is a high-level, object-oriented and imperative scripting language created specifically for the open-source Godot game engine, first appearing around 2014. Its Python-like syntax uses significant indentation and supports both dynamic typing and optional static type hints (introduced in Godot 3.1), with the engine offering type inference and runtime checks. The language is purpose-built for game development, integrating tightly with Godot's scene tree, node system, and signal-based event model, and it is compiled to bytecode executed by the engine's own virtual machine. It is most commonly used to script gameplay logic, entity behavior, and UI in 2D and 3D Godot projects.
