## Summary
SmileBASIC is a dialect of the BASIC programming language developed by SmileBoom for Nintendo handheld and home consoles, first released for the Nintendo DSi in 2011 and later for the 3DS and Switch (as BASIC Programming for Nintendo Switch). It is an imperative, procedurally structured language with dynamic, weak typing built around a small set of types (numbers and strings, plus arrays), where string-typed variable and array names are conventionally suffixed with a dollar sign. The language targets hobbyist and educational game development directly on the console, pairing classic line-oriented BASIC control flow with built-in commands for sprites, backgrounds, sound, touch input, and other hardware features. It is typically used to write small games and graphical demos that run natively on Nintendo devices.
