## Summary
MAXScript is the built-in scripting language of Autodesk 3ds Max, introduced in 1997 with 3ds Max 2 to automate modeling, animation, rendering, and tool development inside the application. It is a dynamically typed, interpreted language that blends imperative and object-oriented styles, with first-class support for the 3ds Max object model, expressive constructs for working with scene nodes, and a "rollout" framework for building custom UI dialogs. Its syntax is forgiving and English-like, emphasizing rapid procedural automation over formal program structure, and it provides direct access to nearly every feature exposed by the 3ds Max SDK. It is used almost exclusively by 3D artists and technical directors for pipeline tooling, batch processing, and parametric scene generation within the 3ds Max environment.
