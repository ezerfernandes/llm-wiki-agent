## Summary
Ioke is a dynamic, prototype-based programming language created by Ola Bini around 2008 to run on the Java Virtual Machine (and later the Common Language Runtime). Strongly inspired by Io, Self, Ruby, and Lisp, it is a homoiconic, expression-oriented language with dynamic typing, first-class macros, and an extremely flexible syntax that makes it well suited for building expressive internal domain-specific languages. Everything is a message send against objects (mimics) that inherit behavior through prototype delegation rather than classes. Designed primarily as a language-experimentation and DSL-authoring playground rather than for production systems, Ioke prioritizes programmer expressiveness and metaprogramming power over raw performance.
