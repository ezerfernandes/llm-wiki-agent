## Summary
FunL is a dynamically typed, impure functional programming language created by Bart Kiers around 2011, designed to run on the Java Virtual Machine and interoperate seamlessly with Java libraries. Its syntax draws heavily from Python and Scala, combining indentation-based blocks with functional features such as first-class and higher-order functions, pattern matching, immutable data structures, list and set comprehensions, and tail-call optimization. The language is multi-paradigm, allowing imperative and object-oriented constructs alongside its functional core, and uses arbitrary-precision integers and rationals by default. FunL is typically used for scripting, rapid prototyping, and educational purposes where concise functional expression and JVM integration are desirable.
