## Summary
FALSE is a small stack-based, concatenative esoteric programming language created by Wouter van Oortmerssen in 1993, famous for inspiring later golfing and stack languages such as brainfuck and Befunge. It is untyped beyond raw integers and characters, manipulating an operand stack with terse single-character operators, and supports lambdas (quoted code blocks) stored in 26 single-letter variables, making it one of the earliest minimalist functional/imperative hybrids. Its original compiler famously fit in about 1 kilobyte of 68000 assembly, and the language is used almost exclusively for recreational programming, code-golf, and demonstrating how much expressive power can be packed into a tiny, cryptic syntax.
