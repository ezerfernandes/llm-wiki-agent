## Summary
PowerShell is a task-automation and configuration-management shell and scripting language built on the .NET runtime, introduced by Microsoft in 2006 and re-released as the open-source, cross-platform PowerShell Core (now simply PowerShell) on .NET Core in 2016. It is multi-paradigm—combining imperative, object-oriented, pipeline-oriented, and functional styles—and is dynamically typed with optional static type annotations, with the distinctive trait that its pipeline passes structured .NET objects rather than plain text streams. Commands are exposed as composable verb-noun "cmdlets," and the language integrates tightly with the full .NET class library, WMI/CIM, and COM. It is most commonly used for Windows and cross-platform system administration, DevOps automation, CI/CD pipelines, and cloud management (notably Azure).
