## Summary
Neko is a dynamically typed, high-level scripting language created by Nicolas Cannasse around 2005, designed primarily as a common runtime target rather than a language for hand-writing application code. It follows a multi-paradigm, imperative and functional style with first-class functions, objects built from prototypes, and a small set of built-in types (int, float, string, array, object, function, and null). Programs are compiled to bytecode that runs on the NekoVM, a lightweight virtual machine featuring a fast interpreter, exception handling, and a C foreign-function interface, with the bytecode also compilable to native code via a C backend. Its main historical role was as the original compilation target for the Haxe language, and it remains used for embedding scripting in applications and for web and tooling work where a compact, embeddable VM is desirable.
