## Summary
BaCon (Basic Converter) is an imperative, procedural BASIC dialect created by Peter van Eerten around 2009 that acts as a source-to-source transpiler, converting BASIC code into portable C that is then compiled by an existing C compiler such as GCC or Clang. It is statically typed in the manner of C but offers BASIC's loose, beginner-friendly syntax, automatic variable handling, and built-in string and array facilities, while allowing inline C for low-level work. Because it produces native C binaries, BaCon targets Unix-like systems (Linux, BSD, macOS) and is typically used for small to mid-sized command-line utilities, system scripts, and GUI applications via bindings to toolkits like GTK. It appeals to programmers who want BASIC's approachability combined with the performance and ecosystem of compiled C.
