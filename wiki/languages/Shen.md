## Summary
Shen is a functional programming language in the Lisp family, created by Mark Tarver and first released in 2011 as the successor to his earlier Qi language. It is multi-paradigm but predominantly functional, featuring pattern matching, partial application, and an optional, fully integrated type system based on sequent calculus that lets programmers turn static type checking on or off and even define their own type theories. Shen is designed for high portability, running atop a small "Shen kernel" that has been hosted on many platforms including Common Lisp, Clojure, Scheme, Python, JavaScript, and the JVM. It is typically used for research and applications involving symbolic computation, embedded logic and theorem proving, language and compiler construction, and other tasks where its built-in Prolog-like logic engine and customizable type discipline are valuable.
