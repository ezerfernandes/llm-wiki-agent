## Summary
nroff/troff (collectively roff) is a venerable Unix document-formatting system whose embedded macro and request language is Turing-complete, making it usable as an esoteric, imperative programming language. Originating at Bell Labs in the early 1970s (descended from RUNOFF), it is interpreted and untyped, manipulating registers (numeric variables), string definitions, and conditional/looping requests like .nr, .ds, .if, and .while. Programs are typically written using GNU troff (groff) and produce output by formatting text to a terminal or typesetter, so "computation" is expressed as a side effect of generating formatted output. In practice it remains the engine behind Unix man pages and traditional technical typesetting rather than general-purpose application development.
