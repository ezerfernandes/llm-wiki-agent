## Summary
CMake is an imperative, macro-oriented scripting language built into the CMake build-system generator, created by Kitware around 2000 to produce native build files (Makefiles, Ninja, Visual Studio projects) across platforms. Its dynamically typed model treats essentially everything as a string or a semicolon-separated list, with variables, control flow, functions, and macros exposed through a verbose command-call syntax. Though designed primarily as a configuration and build-orchestration DSL for C and C++ projects, its Turing-complete command language is occasionally pressed into general-purpose scripting. It is interpreted at configure time by the cmake executable rather than compiled, and is ubiquitous in modern cross-platform C/C++ tooling.
