## Summary
Beeswax is an esoteric, two-dimensional programming language created by Martin Rosenau around 2015, inspired by Befunge but built on a hexagonal grid of cells rather than a square one. Instruction pointers (called "bees") move across the source plane following directional and flow-control glyphs, manipulating data through a global double-ended queue and per-bee local registers, with values treated as untyped 64-bit integers or floating-point numbers as the operation demands. As an instruction-pointer-on-a-2D-playfield language it is procedural and imperative in spirit but stack/queue-oriented in execution. Like most fungeoids it is used recreationally — for code golf, puzzle solving, and Rosetta Code style algorithmic demonstrations rather than production software.
