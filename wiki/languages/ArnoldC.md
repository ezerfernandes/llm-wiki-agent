## Summary
ArnoldC is an esoteric, imperative programming language created by Lauri Hartikka in 2014 whose keywords are replaced entirely with one-liner quotes from Arnold Schwarzenegger movies — for example, "GET TO THE CHOPPER" begins an assignment and "TALK TO THE HAND" prints output. It is a small, statically structured procedural language compiled to Java bytecode via a Scala-based compiler, supporting integer and boolean values, conditionals, while loops, and methods, but with no real practical use beyond humor and programming-puzzle novelty. As a joke language it is primarily valuable for entertainment, teaching basic interpreter/compiler concepts, and as a recreational challenge on sites like Rosetta Code.
