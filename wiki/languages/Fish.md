## Summary
Fish (the "friendly interactive shell") is a Unix command-line shell and imperative scripting language first released in 2005, designed to be user-friendly out of the box with features like syntax highlighting, autosuggestions, and tab completion that require no configuration. As a shell language it is dynamically typed and string-oriented, with all variables treated as lists of strings and program structure built from commands, pipelines, functions, and block constructs such as if, for, while, and switch. It deliberately departs from POSIX sh/bash conventions, favoring a cleaner, more consistent syntax (for example using command substitution with parentheses and explicit set for variable assignment). It is used primarily as an interactive login shell and for writing short automation and glue scripts rather than for large application development.
