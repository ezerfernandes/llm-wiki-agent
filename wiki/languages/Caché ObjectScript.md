## Summary
Caché ObjectScript is the native procedural and object-oriented scripting language of InterSystems' Caché, a high-performance multi-model database platform that emerged in 1997 as the successor to InterSystems' M/MUMPS technology. Descended directly from MUMPS, it retains that language's distinctive sparse, hierarchical multidimensional arrays (globals) for transparently persistent storage while layering on a full class-based object model, embedded SQL, and exception handling. It is dynamically typed, with values held in a single universal string-based representation that is coerced to numbers or other forms as context requires, and it uses globals as the primary mechanism for tightly integrating in-memory code with on-disk data. The language is used chiefly to build transactional, data-intensive enterprise applications—most prominently in healthcare, finance, and other domains demanding fast access to large volumes of structured records (for example via InterSystems' HealthShare and TrakCare products).
