## Summary
Palo Alto Tiny BASIC (PATB) is a minimalist, imperative dialect of the BASIC programming language written by Li-Chen Wang and published in Dr. Dobb's Journal in 1976 as a free, "copyleft" implementation for early 8080/Z80 microcomputers. Like other Tiny BASICs of the era, it is interpreted, line-numbered, and unstructured, relying on GOTO/GOSUB for control flow, with a single value type: 16-bit signed integers (no floating point or string variables), and only the 26 single-letter variables A–Z plus a small array. Designed to run in extremely constrained memory (roughly 2 KB), it omitted features like multi-character variable names and string handling in favor of a tiny, fast interpreter. It was widely used for hobbyist computing and education on machines such as the SOL-20 and TRS-80, and influenced many later Tiny BASIC variants.
