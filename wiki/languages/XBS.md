## Summary
XBS (short for "eXtra Basic Script") is a small, dynamically typed scripting language created in the early 2020s, distributed as an open-source interpreter implemented in JavaScript and run on Node.js. It follows an imperative, procedural paradigm with a deliberately verbose, keyword-heavy syntax (for example, blocks are opened with keywords and closed with explicit terminators), and supports variables, functions, conditionals, loops, and basic collection types. As a hobbyist project rather than a production toolchain, it is used mainly for learning, experimentation, and recreational programming challenges such as the Rosetta Code task set.
