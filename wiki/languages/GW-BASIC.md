## Summary
GW-BASIC is an imperative, procedural dialect of the BASIC programming language released by Microsoft in 1983, shipped with MS-DOS and IBM PC-compatible machines throughout the 1980s as the successor to IBM Cassette/Disk BASIC. It is an interpreted language with dynamic but weak typing, distinguishing only between numeric (single- and double-precision floating point, integer) and string values, the latter marked with a trailing dollar sign; programs traditionally use mandatory line numbers and unstructured control flow built around GOTO and GOSUB. Its dialect features include built-in graphics and sound statements, direct hardware access via PEEK/POKE, and an interactive immediate mode for entering and running code at the prompt. Once a ubiquitous environment for hobbyist programming and learning, GW-BASIC was superseded by QBasic in 1991 and is today retained mainly for legacy compatibility and retrocomputing.
