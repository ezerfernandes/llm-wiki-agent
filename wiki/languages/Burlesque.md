## Summary
Burlesque is a concatenative, stack-based esoteric programming language created by Roman Müntener around 2012, designed primarily for code golf and terse one-liners. Like Forth, Joy, and Factor, it composes programs from postfix operators that manipulate an implicit data stack, with dynamic typing over values such as integers, floating-point numbers, strings, and blocks (quoted code). Its standard library is rich in concise list- and string-processing builtins, encouraging extremely compact solutions to combinatorial and text-manipulation problems. It is rarely used for production software, instead serving golfing challenges and Rosetta Code-style algorithmic puzzles where minimizing source length matters most.
