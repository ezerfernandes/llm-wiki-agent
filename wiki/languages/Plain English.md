## Summary
Plain English is an imperative, procedural programming language developed by Gerry Rzeppa and Paul Boswell (the "Osmosian" project) in the 2000s, whose defining feature is a near-natural-language syntax: programs read as ordinary English sentences, with routines, types, and data declared in prose rather than terse symbolic notation. It is statically typed, with types ("things") and named fields declared explicitly, and it compiles to native machine code through a self-hosting toolchain — the entire compiler, IDE, and supporting environment are written in Plain English itself. The language emphasizes readability and accessibility for newcomers, using pointer-based data structures, conversational control flow ("Loop. ... Repeat."), and a literate, comment-like style. It is primarily a demonstration and educational system showing that low-level systems software can be built in a human-readable dialect rather than a mainstream production tool.
