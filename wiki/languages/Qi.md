## Summary
Qi is a functional programming language built on top of Common Lisp, created by Mark Tarver and first released in the early 2000s. It pairs Lisp's macro power and S-expression syntax with an advanced, optionally enabled static type system based on sequent calculus, plus pattern matching, currying, and a built-in logic-programming engine (a Prolog-like system called Qi-Prolog). Its most distinctive feature is type-checking expressed through user-definable inference rules, giving programmers an extensible Turing-complete type discipline rather than a fixed one. Qi was later succeeded by Shen, which generalized the design to run on platforms beyond Common Lisp; it is used mainly for research and teaching in advanced type theory and symbolic computation.
