## Summary
Janet is a functional and imperative Lisp-dialect scripting language created by Calvin Rose around 2017, drawing influence from Clojure, Scheme, and Lua. It is dynamically typed with first-class functions, immutable and mutable data structures, fibers for lightweight coroutine-based concurrency, and a built-in PEG (Parsing Expression Grammar) module for text processing. Janet compiles to bytecode for a small, fast register-based virtual machine and embeds easily in C programs, shipping as a single small static library with no external dependencies. It is typically used for scripting, embedded extension languages, command-line tools, and rapid prototyping where a compact, self-contained interpreter is desirable.
