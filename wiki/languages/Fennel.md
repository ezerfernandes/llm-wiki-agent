## Summary
Fennel is a Lisp dialect, created by Phil Hagelberg in 2016, that compiles directly to Lua and runs anywhere Lua does. It is a dynamically typed, multi-paradigm language that pairs the full macro system and S-expression syntax of a Lisp with Lua's small, fast runtime and semantics, adding no runtime overhead and interoperating seamlessly with existing Lua code and libraries. Like Lua, it embraces functional and imperative styles around first-class functions, closures, and tables as its core data structure. It is commonly used for scripting, game development (notably with the LÖVE and TIC-80 engines), and embedding in applications where a compact, Lua-compatible Lisp is desirable.
