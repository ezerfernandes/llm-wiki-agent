## Summary
LSL (Linden Scripting Language) is a statically typed, event-driven scripting language created by Linden Lab in the early-to-mid 2000s to script the behavior of objects within the virtual world of Second Life (and later compatible platforms such as OpenSimulator). Its C/Java-flavored syntax is organized around states and event handlers, so programs respond to in-world stimuli like touches, collisions, timers, and chat messages rather than running as conventional top-down procedures. The language offers a small fixed set of types (integer, float, string, key, vector, rotation, and list) and runs in a sandboxed per-object virtual machine, giving each script its own limited memory and execution environment. It is used almost exclusively for interactive 3D content—animating objects, building vehicles and HUDs, handling avatar interactions, and communicating with external web services via HTTP.
