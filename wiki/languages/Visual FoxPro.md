## Summary
Visual FoxPro (VFP) is a data-centric, dynamically typed programming language and integrated development environment built around an xBase-dialect procedural language with object-oriented extensions and an embedded relational database engine. Descended from the dBASE/FoxBASE/FoxPro lineage, it was developed by Microsoft after acquiring Fox Software in 1992, with the "Visual" releases spanning 1995 through the final version 9.0 (2004); mainstream support ended in 2015. It pairs a tightly coupled native data store and SQL-like query commands with event-driven forms, classes, and reports, making it well suited to rapid development of desktop database and line-of-business applications on Windows.
