## Summary
HolyC is an imperative, procedural systems language created by Terry A. Davis in the late 2000s as the native programming and shell language of his TempleOS operating system, where it doubles as both a compiled language and an interactive JIT-compiled command interpreter. Derived from C, it is statically typed with a default 64-bit signed integer (I64) word size, and relaxes C conventions by allowing functions to be called without parentheses, permitting code at file scope to run immediately, and treating the language itself as the OS shell. It targets ring-0 x86-64 directly with no separation between kernel and user space, and supports inline assembly, making it suited to low-level OS, driver, and bare-metal programming rather than portable application development. Because it exists only within TempleOS, HolyC is used almost exclusively for hobbyist exploration and as a historical curiosity rather than in production software.
