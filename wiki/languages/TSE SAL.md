## Summary
TSE SAL is the macro and scripting language built into The SemWare Editor (TSE), a fast, lightweight programmable text editor for MS-DOS and Windows that traces its lineage to the late 1980s editor QEdit. SAL (the Sal Application Language) is an imperative, procedural language with C- and Pascal-influenced syntax, statically declared variables, and a small set of primitive types (chiefly integers and strings) oriented toward manipulating editor buffers, text, and the user interface rather than general-purpose computing. It is typically used to write editor extensions, custom commands, keyboard macros, and automation scripts that drive TSE, with programs compiled to a bytecode form that the editor executes. As an editor-embedded domain-specific language, its idioms revolve around cursor movement, buffer and marking operations, and prompting the user, making Rosetta Code solutions expressed in terms of editor primitives.
