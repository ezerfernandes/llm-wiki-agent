## Summary
Haskell is a purely functional programming language with lazy (non-strict) evaluation by default and a strong, statically inferred type system based on the Hindley-Milner discipline extended with type classes. It emerged in 1990 from an academic committee formed to consolidate the many competing lazy functional languages, and is named after logician Haskell Curry; the language is standardized by the Haskell 98/2010 reports and most commonly compiled with GHC. Side effects are managed explicitly through monads (notably the IO monad), keeping pure code referentially transparent, and the language emphasizes immutability, higher-order functions, algebraic data types, and pattern matching. It is widely used in compilers, programming-language research, formal verification, financial systems, and as an influential testbed for advanced type-system features.
