## Summary
Jsish is a small, embeddable JavaScript interpreter written in C, created by Peter MacDonald and first released around 2014, implementing a substantial subset of ECMAScript along with its own extensions. It is multi-paradigm in the JavaScript tradition (imperative, functional, and prototype-based object-oriented) and dynamically typed, but distinguishes itself with optional type and signature annotations that can be enforced at runtime to catch errors early. The language ships with batteries-included facilities such as SQLite bindings, a built-in web server and WebSocket support, JSON handling, and a unit-testing mode that makes inline `;expr;` self-validating documentation. It is typically used for embedding scripting into C applications, building small web and IoT services, and writing self-testing command-line utilities.
