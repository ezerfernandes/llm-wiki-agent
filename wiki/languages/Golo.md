## Summary
Golo is a lightweight, dynamically typed programming language for the Java Virtual Machine, created at INRIA in 2012 and later donated to the Eclipse Foundation. It was designed primarily as a showcase for the JVM's invokedynamic instruction and the JSR-292 dynamic linking facilities introduced in Java 7, demonstrating how a simple dynamic language can run efficiently atop modern bytecode. Golo is multi-paradigm, blending imperative and functional styles with closures, structures, dynamic objects, pattern matching, and seamless Java interoperability. It is typically used for scripting, embedding within Java applications, and as a teaching vehicle for JVM language implementation techniques.
