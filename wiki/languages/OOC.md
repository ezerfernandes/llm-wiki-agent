## Summary
ooc is a small object-oriented programming language created by Amos Wenger around 2009, designed to be expressive and approachable while compiling down to C for portability and native performance. It is statically typed with type inference, and supports object orientation, generics, first-class functions and closures, operator overloading, and managed memory via a garbage collector, blending high-level convenience with low-level C interoperability. Its clean Python-influenced syntax and C backend made it suited to general-purpose application and systems-adjacent programming, though it remained primarily an experimental and hobbyist language rather than seeing wide industrial adoption.
