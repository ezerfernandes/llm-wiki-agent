## Summary
MSX BASIC is a dialect of Microsoft BASIC developed by Microsoft for the MSX home computer standard, which launched in 1983 and was especially popular in Japan, Korea, the Netherlands, Spain, and parts of South America. It is an imperative, line-numbered, interpreted procedural language with weak, dynamic typing, distinguishing variables by type-suffix sigils (such as $ for strings and % for integers) and offering only a small set of fundamental data types. Bundled in ROM as the machine's default boot environment, it provided hardware-aware extensions for graphics, sprites, sound (via the PSG), and cassette/disk I/O, making it the primary way users wrote games and utilities on 8-bit MSX machines. Like other microcomputer BASICs of its era, it relied on GOTO/GOSUB control flow and was geared toward hobbyist programming and education rather than large-scale software.
