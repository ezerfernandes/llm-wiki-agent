## Summary
The EDSAC order code is the native machine language of the EDSAC (Electronic Delay Storage Automatic Calculator), one of the first practical stored-program computers, built by Maurice Wilkes and his team at the University of Cambridge and operational in 1949. It is a low-level, imperative instruction set in which each "order" consists of a single-letter operation followed by an address and a length specifier (short or long word), entered as mnemonic codes punched onto paper tape; there is no typing discipline beyond raw binary words representing 17-bit short or 35-bit long fixed-point fractional numbers. Programming is done directly against the machine's accumulator and multiplier registers and mercury delay-line memory, with the pioneering "initial orders" acting as a primitive bootstrap assembler. Today it survives essentially only as a historical curiosity studied through emulators, valued for understanding the origins of practical programming, subroutine libraries, and stored-program computing.
