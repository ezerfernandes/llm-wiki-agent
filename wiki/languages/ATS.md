## Summary
ATS (Applied Type System) is a statically typed, multi-paradigm language designed by Hongwei Xi at Boston University, with its first releases appearing in the mid-2000s; it descends from ML-family languages and unifies functional, imperative, and modular programming under a single rich type system. Its defining feature is the combination of dependent types and linear types, which lets programmers prove properties about programs—such as array-bounds safety, resource usage, and pointer correctness—at compile time, enabling memory-safe systems code without a garbage collector. ATS compiles to efficient C, giving it performance comparable to hand-written C while eliminating broad classes of runtime errors through static verification. It is typically used for low-level and safety-critical systems programming, embedded development, and as a research vehicle for advanced type theory.
