## Summary
Object Icon is an object-oriented dialect of the Icon programming language, developed primarily by Robert Parlett in the 2000s as a derivative of Unicon and the original Icon created by Ralph Griswold at the University of Arizona. It is a dynamically typed, multi-paradigm language that retains Icon's signature features — goal-directed evaluation, generators, string scanning, and the success/failure expression model — while adding a full class-based object system with inheritance, packages, and modern garbage-collected runtime support. Like its ancestors it excels at text processing, string manipulation, and rapid prototyping, and is typically compiled to bytecode run on a virtual machine. It remains a niche research and hobbyist language favored by those drawn to Icon's expressive control flow combined with object-oriented structure.
