## Summary
JavaScript is a dynamically and weakly typed, multi-paradigm language supporting imperative, functional, event-driven, and prototype-based object-oriented styles. Created by Brendan Eich at Netscape in 1995 and standardized as ECMAScript, it began as a scripting language for interactive web pages and runs in every modern browser. With the advent of Node.js it expanded to server-side and general-purpose use, and today powers full-stack web development, build tooling, and cross-platform applications. Its single-threaded event loop with asynchronous callbacks, promises, and async/await makes it well suited to I/O-bound, concurrent workloads.
