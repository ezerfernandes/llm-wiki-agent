## Summary
Gnuplot is the command and scripting language of the gnuplot plotting utility, originally created in 1986 to render mathematical functions and data as 2D and 3D graphs across many output terminals. It is an interpreted, imperative scripting language with dynamic, weak typing, organized around a set of plotting commands (plot, splot, set) plus variables, user-defined functions, loops, and string operations. Though purpose-built for interactive and batch data visualization, it is Turing-capable enough to handle small general-purpose computations, and it is most commonly used to generate publication-quality charts from scientific and engineering datasets.
