## Summary
GML (GameMaker Language) is the proprietary scripting language built into YoYo Games' GameMaker engine, first appearing with Game Maker in the late 1990s and evolving steadily through GameMaker Studio and GameMaker Studio 2. It is an imperative, event-driven, dynamically and weakly typed language with C-like syntax, designed to attach behavior to game objects via events and scripts while abstracting away low-level engine details. Over time it has gained more structured and object-oriented features such as structs, constructors, and anonymous functions, but it remains fundamentally a high-level glue language. Its typical use is rapid 2D game development, where designers and indie developers script gameplay logic, sprites, rooms, and collisions without writing native engine code.
