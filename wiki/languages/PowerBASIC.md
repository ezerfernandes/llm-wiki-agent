## Summary
PowerBASIC is a commercial, compiled procedural and structured BASIC dialect for the x86 platform, descended from Borland's Turbo Basic and developed by PowerBASIC, Inc. from the early 1990s onward. It is statically typed, compiling directly to fast native machine code, and provides inline assembler, explicit pointers, and low-level memory access alongside conventional BASIC syntax. The product line splits into PB/CC for console applications and PB/Win for native Win32 GUI development, the latter relying on Dynamic Dialog Tools and direct Windows API calls. It is typically used to build small, dependency-free Windows executables and DLLs where execution speed and a compact distributable matter.
