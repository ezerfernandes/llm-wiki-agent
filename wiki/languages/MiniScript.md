## Summary
MiniScript is a high-level, imperative and object-oriented scripting language created by Joe Strout and first released around 2016, designed to be small, clean, and easy to embed in other applications and games. It is dynamically typed with a compact set of core types (numbers, strings, lists, and maps), and its object model is prototype-based, using maps with an `__isa` chain rather than classical classes. The language is implemented in both C# and C++ for easy integration into host applications such as the Unity engine and the standalone "Mini Micro" virtual computer. It is typically used for game scripting, teaching programming, and lightweight automation where an approachable, embeddable interpreter is desirable.
