## Summary
Rust is a statically and strongly typed, multi-paradigm systems programming language that blends imperative, functional, and trait-based generic styles, with type inference and algebraic data types. Originating at Mozilla Research (Graydon Hoare, 2010) and reaching its stable 1.0 release in 2015, its defining innovation is a compile-time ownership and borrowing model that guarantees memory and thread safety without a garbage collector. It compiles to native code via LLVM, offering performance comparable to C and C++ while preventing data races and common memory errors. Rust is widely used for operating systems, browser and game engines, embedded and WebAssembly targets, command-line tools, and high-performance networking and backend services.
