## Summary
Phixmonti is a small, stack-based concatenative programming language created around 2015 by Pablo Salatino (Aldo), drawing inspiration from Forth and the Phix language. Programs are written in reverse Polish (postfix) notation, operating on a single data stack with dynamically typed values such as integers, floats, strings, and lists, and control structures expressed as bracketed blocks. As a niche hobbyist language, it is used primarily for exploring stack-oriented programming and for solving recreational programming puzzles, where it appears notably across many Rosetta Code tasks.
