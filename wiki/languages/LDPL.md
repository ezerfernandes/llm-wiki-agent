## Summary
LDPL (Lartu's Definitive Programming Language) is an imperative, procedural programming language created by Martín del Río around 2018, intentionally designed to be highly readable using an English-like, statement-oriented syntax reminiscent of COBOL. It is statically typed with a small set of explicitly declared types (numbers, text, and indexed/associative containers), is case-insensitive, and compiles to C++ for portability across platforms including 64-bit computers, ARM systems, and even legacy hardware. LDPL is typically used for writing maintainable command-line utilities and educational programs, and supports Unicode along with the ability to extend programs with native C++ code.
