## Summary
Lang5 is a stack-based, concatenative array programming language that fuses the postfix (Reverse Polish) evaluation model of Forth with the data-parallel array semantics of APL and J. Created by Thomas Cislo in the late 2000s and implemented in Perl, it is dynamically typed and treats nested arrays as first-class values on which arithmetic and other operators broadcast element-wise. Programs are built by composing words that push and consume operands on a data stack, with vectorized operations replacing explicit loops. It is a niche, experimental language used mainly for exploring the intersection of array-oriented and stack-oriented programming rather than for production work.
