## Summary
Spin is a multitasking, imperative high-level programming language created by Parallax Inc. in 2006 specifically for its Propeller multicore microcontroller. It is statically typed with a small set of primitive types (bytes, words, and longs) and uses significant indentation to delimit code blocks, pairing the interpreted Spin language with inline Propeller assembly for time-critical routines. The language exposes the Propeller's eight parallel processing cores (cogs) directly, letting programmers launch and coordinate concurrent methods, which makes it well suited to embedded and real-time hobbyist and industrial control applications.
