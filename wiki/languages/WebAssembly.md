## Summary
WebAssembly (Wasm) is a low-level, stack-based virtual instruction set architecture with a compact binary format and a human-readable text counterpart (WAT) that uses S-expression syntax. Introduced in 2017 by the major browser vendors through the W3C, it is statically typed over a small set of numeric value types (i32, i64, f32, f64, plus later additions like reference and vector types) and runs inside a sandboxed, deterministic stack machine. Rather than being written by hand, it usually serves as a portable compilation target for languages such as C, C++, and Rust, executing at near-native speed. Its typical use is running performance-sensitive code in web browsers, but it has expanded to server-side runtimes, edge computing, and plugin systems via standards like WASI.
