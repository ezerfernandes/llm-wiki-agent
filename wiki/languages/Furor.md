## Summary
Furor is a small, stack-based, concatenative programming language in the Forth tradition, developed in the 2010s as a hobbyist/experimental project. Like Forth, it is imperative and procedural, manipulating values on an explicit data stack through reverse-Polish (postfix) word definitions rather than conventional infix expressions, and it is essentially untyped, treating stack cells as raw machine words. Its minimal syntax and interpreter-driven model make it suited to compact scripting, learning stack-machine concepts, and exploring Forth-style language design rather than production software.
