## Summary
MOO is a dynamically typed, prototype-based object-oriented scripting language created by Stephen White in 1990 and later developed by Pavel Curtis at Xerox PARC as the embedded programming language of the LambdaMOO server. It powers MOOs (MUD, Object-Oriented), text-based multi-user virtual worlds, where the language lives inside a persistent object database and is used to define rooms, objects, players, and their behaviors (verbs) interactively at runtime. MOO is imperative and interpreted, supports first-class lists and associative maps, permission-based verb and property security, and a single-inheritance object model with delegation to parent objects. It remains primarily used for building and extending social/textual virtual environments and educational MUDs rather than general-purpose application development.
