## Summary
Arc is a dialect of Lisp designed by Paul Graham and Robert Morris, with a public release in 2008, intended as a minimalist, hackable language for exploratory programming and rapid web application development. It is a dynamically typed, functional-first language built atop a small set of axiomatic operators, while still supporting imperative and macro-based metaprogramming styles characteristic of the Lisp family. The reference implementation runs on Racket (originally MzScheme/PLT Scheme), and the language emphasizes terse syntax, brevity, and powerful macros over a large standard library. In practice Arc has been used mainly for web programming—most notably the Hacker News site—and as an experiment in language design rather than for mainstream production software.
