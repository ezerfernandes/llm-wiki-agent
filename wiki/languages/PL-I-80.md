## Summary
PL/I-80 is Digital Research's implementation of the PL/I programming language, released in 1980 for 8080/Z80 microcomputers running the CP/M operating system. Like its IBM-mainframe ancestor PL/I, it is an imperative, procedural, statically and strongly typed language supporting block structure, structured data aggregates, pointers, exception handling via ON-conditions, and a rich set of fixed-point, floating-point, and character/bit string types. PL/I-80 implemented the ANSI Subset G dialect and shipped as a native-code compiler with a linker and runtime library, targeting systems programming and business applications on early personal computers. It saw limited adoption compared to mainframe PL/I and is now largely of historical interest, having been superseded as CP/M itself faded.
