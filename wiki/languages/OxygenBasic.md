## Summary
OxygenBasic is a free, open-source procedural BASIC dialect created by Charles Pegge in the late 2000s, distributed as a self-contained JIT/assembling compiler engine (Oxygen.dll) that produces native x86/x64 machine code rather than relying on an external toolchain. It is statically typed but unusually flexible, blending classic BASIC syntax with low-level features more typical of C and assembly: inline x86 assembler, raw pointers, explicit memory management, macros, and direct calling of Windows API and external DLLs. Largely Windows-centric and used mostly by hobbyist and demoscene-style programmers, it targets performance-sensitive and systems-level tasks where developers want BASIC ergonomics with near-C speed and the ability to embed the compiler at runtime for scripting and code generation.
