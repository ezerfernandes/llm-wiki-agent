## Summary
Arendelle is an esoteric, imperative programming language created by Iranian developer Pooya Eimandar (Beygi) around 2012, designed to be compact and minimalistic. Programs are written as a single stream of characters where text is printed literally and special bracket-delimited constructs control flow, while data is held in a numbered space of dynamically typed variables along with named string variables. Its loops, conditionals, and function-like blocks are expressed through terse symbolic syntax such as parentheses, square brackets, and quotes rather than keywords. As an esolang it is used chiefly for recreational programming, code-golf-style brevity experiments, and exploring unconventional language design rather than for production software.
