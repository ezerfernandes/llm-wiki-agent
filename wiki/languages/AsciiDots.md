## Summary
AsciiDots is an esoteric, two-dimensional dataflow programming language created by Aaron Janse around 2016, in which "dots" travel along ASCII-art wires drawn from characters like hyphens, pipes, and slashes, with operators and control structures placed inline along those paths. Computation is expressed visually as the movement and interaction of these dot tokens rather than as conventional sequential statements, making it a non-textual, flow-based paradigm with no static type system. Like most esolangs it is intended for recreation, puzzle-solving, and code-art demonstrations rather than practical software development.
