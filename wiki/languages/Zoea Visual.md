## Summary
Zoea Visual is a visual programming-by-example language and environment in which developers specify software behavior by supplying concrete examples of inputs and their corresponding outputs rather than writing imperative code. It is the diagram-based front end to Zoea, a declarative inductive programming system that automatically synthesizes working programs from these example specifications, so the language is effectively example-driven and intent-based rather than statically or dynamically typed in the conventional sense. Emerging in the late 2010s, it targets developers and non-programmers alike, and is typically used for rapid prototyping and for generating routines—such as data transformations, string and list manipulations, and the algorithmic tasks featured on Rosetta Code—directly from worked examples.
