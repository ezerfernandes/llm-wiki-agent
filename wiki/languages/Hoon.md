## Summary
Hoon is a strict, purely functional programming language created by Curtis Yarvin and developed by Tlon as the system language of Urbit, first appearing in the early 2010s. It is statically typed with a structural type system whose types ("molds") double as data-validation functions, and it compiles down to Nock, Urbit's minimal combinator-based bytecode, with subject-oriented programming replacing conventional lexical scoping. Its syntax is famously dense, favoring digraph "runes" (ASCII operator pairs like `|=` and `=/`) over keywords. Hoon is used almost exclusively for building applications, agents, and kernel components within the Urbit personal-server platform.
