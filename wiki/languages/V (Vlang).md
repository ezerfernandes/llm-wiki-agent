## Summary
V (also written Vlang) is a statically typed, compiled systems and application programming language created by Alexander Medvedev and first released publicly in 2019. Its syntax is heavily inspired by Go, emphasizing simplicity, fast compilation, and minimalism, while adding features such as compile-time immutability by default, no null, option/result types for error handling, and built-in memory management via automatic freeing (autofree) alongside optional manual and garbage-collected modes. V is primarily multi-paradigm with an imperative and structural style augmented by methods on structs, generics, and a sum-type-based approach rather than classical inheritance. It is commonly used for systems programming, CLI tools, web backends, and as a transpilation-friendly language that can emit C for portable native binaries.
