## Summary
Order is a pure functional programming language that runs entirely within the C preprocessor, implemented as a header-only library of macros. Emerging in the late 2000s, it treats the preprocessor's textual macro expansion as a Turing-complete interpreter, providing lazily-evaluated, dynamically-typed constructs such as integers, tuples, lists, higher-order functions, and recursion built atop the Boost.Preprocessor metaprogramming tradition. Because all computation happens at C/C++ compile time, Order is used for advanced template and macro metaprogramming, generating code and performing arithmetic or list manipulation before the actual program is compiled. It is a niche, esoteric tool rather than a general-purpose language, valued chiefly for pushing preprocessor metaprogramming to its limits.
