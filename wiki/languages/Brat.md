## Summary
Brat is a small, dynamically typed scripting language created around 2011 by Wade Mealing, designed for simplicity and an unusually flexible, minimal syntax that blends ideas from Ruby, Lisp, and other dynamic languages. It is multi-paradigm, supporting object-oriented and functional styles, and treats nearly everything as an object with first-class functions, lightweight prototype-like objects, and built-in pattern matching for control flow. Originally implemented to run on the Rubinius VM and later compiling to Lua, Brat is primarily an experimental and hobbyist language used for exploring concise, expressive program design rather than production systems.
