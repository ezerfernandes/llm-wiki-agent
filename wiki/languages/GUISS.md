## Summary
GUISS (Graphical User Interface Support Script), also known as "Gussie," is an esoteric language created for Rosetta Code that does not describe computation in the conventional sense but instead scripts the actions of a hypothetical unintelligent human operator sitting at a graphical desktop. Rather than executing logic, a GUISS program issues a literal sequence of GUI interactions — moving and clicking the mouse, dragging icons, typing into windows, and reading the screen — so the "computer" merely follows surface-level instructions like opening a calculator and pressing buttons. It is therefore an imperative, action-oriented and effectively untyped notation with no real variables, control flow, or data structures, conceived in the late-2000s Rosetta Code era purely as a programming-puzzle curiosity. Its only practical use is demonstrating, often humorously, how far an everyday point-and-click workflow can be stretched to mimic the output of a normal program.
