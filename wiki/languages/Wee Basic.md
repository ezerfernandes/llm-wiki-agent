## Summary
Wee Basic is a small, imperative BASIC dialect created in the 2010s for the Nintendo DS and 3DS homebrew scene, distributed as a downloadable interpreter that runs directly on the handheld. Like classic BASIC variants it uses line- and statement-oriented control flow with dynamically typed variables and built-in commands for text, graphics, and touchscreen input, keeping the language deliberately minimal and beginner-friendly. It is procedural and interpreted rather than compiled, with no object-oriented or functional features. In practice it is used for hobbyist programming, simple games, and educational experiments on Nintendo handheld hardware.
