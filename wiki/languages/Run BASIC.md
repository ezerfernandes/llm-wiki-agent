## Summary
Run BASIC is an imperative, procedural dialect of the BASIC language created by Carl Gundel of Shoptalk Systems and released in 2003 as a web application server built on the Liberty BASIC interpreter. It is dynamically typed, with simple scalar and array variables and string handling typical of classic BASIC, and runs programs as self-contained personal web servers that emit HTML. Its defining feature is server-side web programming: keywords such as PRINT, INPUT, and form/link handlers let a single BASIC script render interactive web pages and process requests without separate front-end code. It is used chiefly for rapid prototyping of small database-backed web applications and as an accessible teaching tool for web-oriented programming.
