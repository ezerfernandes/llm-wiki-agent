## Summary
IS-BASIC is the built-in dialect of BASIC for the Enterprise (also marketed as Elan or Flan) home computer, a Zilog Z80-based machine released around 1985. It is an imperative, line-numbered procedural language in the classic 8-bit BASIC tradition, with dynamic, weakly checked typing distinguishing numeric values from strings (the latter denoted by a `$` suffix). Compared with contemporaries it offered relatively advanced features such as structured control constructs, named procedures, multiple text and graphics windows, and sound commands. Today it survives mainly through emulators and the retrocomputing community, where it appears in programming exercises like the Rosetta Code tasks below.
