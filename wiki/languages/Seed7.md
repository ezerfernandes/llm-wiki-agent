## Summary
Seed7 is a general-purpose, statically and strongly typed imperative programming language created by Thomas Mertes, with its first public releases appearing in the early 2000s. Its defining characteristic is an extensible syntax: programmers can define new statements and operators in user code, so much of the language—including control structures—is implemented in Seed7 itself rather than hardwired into the compiler. It supports object orientation, generic and call-by-name parameters, exception handling, and overloading, and runs both via an interpreter and an optimizing C-generating compiler. Seed7 is used mainly for systems and application programming where portability and a clean, type-safe model are desired, and it is a frequent contributor on Rosetta Code.
