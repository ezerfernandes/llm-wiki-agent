## Summary
Avail is a multi-paradigm programming language designed by Todd Smith and Mark van Gulik, with development tracing back to the late 1990s and an open-source compiler/IDE (the Avail Workbench) emerging in the 2010s. Its defining feature is an extraordinarily flexible, fully extensible grammar: nearly the entire language is defined in user-space libraries, and developers can introduce new syntax, control structures, and "macro" definitions so that code reads like domain-specific natural language. It is strongly and statically typed with a rich type system that includes structural types, type-valued expressions, and metacovariance, while supporting functional, imperative, and object-oriented styles. Avail targets the writing of highly readable, self-documenting programs and the construction of domain-specific languages where the syntax can be tailored precisely to the problem domain.
