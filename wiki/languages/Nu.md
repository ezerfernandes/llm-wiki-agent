## Summary
Nu is an interpreted, object-oriented scripting language created by Tim Burks around 2007 that blends the Lisp tradition with the Objective-C runtime on macOS. Programs are written in a parenthesized, Lisp-like S-expression syntax, but every object is a first-class Objective-C/Cocoa object, so Nu code can directly call into Apple's frameworks and bridge dynamically with Objective-C classes. It is dynamically typed and reflective, supporting closures, macros, operator overloading, and message-passing in the Smalltalk/Objective-C style. Typical use is as an embeddable, rapid-prototyping and configuration language for Cocoa and macOS/iOS applications, where its homoiconic syntax and tight runtime integration let developers script and extend native Objective-C software.
