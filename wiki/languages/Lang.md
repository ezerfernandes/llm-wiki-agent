## Summary
Lang is a dynamically typed, interpreted general-purpose programming language created by Jens Ole Lauridsen, implemented on the Java Virtual Machine and distributed as the Standard Lang interpreter. It is primarily imperative and procedural with optional object-oriented constructs, and it places heavy emphasis on a translation/internationalization layer in which programs are organized around translation key-value pairs, making locale-aware text handling a first-class language feature. Originating in the 2010s as a hobbyist and community-driven project, Lang offers parser-level constructs, structs, and tight Java interoperability. It is typically used for scripting, learning, embedding within JVM applications, and solving small algorithmic tasks such as those on Rosetta Code.
