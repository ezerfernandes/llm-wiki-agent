## Summary
Nim is a statically typed, compiled systems programming language created by Andreas Rumpf, first released in 2008 (originally under the name Nimrod). It is multi-paradigm, supporting imperative, procedural, object-oriented, functional, and metaprogramming styles, and is distinguished by its powerful AST-based macro system, hygienic templates, and significant-whitespace Python-like syntax. Nim compiles to C, C++, or JavaScript, giving it C-level performance with optional automatic memory management (including modern ARC/ORC reference counting). It is typically used for systems and application programming, command-line tools, game development, embedded software, and web frontends where a high-level, expressive syntax combined with native performance is desired.
