## Summary
Coco is a multi-paradigm scripting language created in the early 2010s as a dialect of CoffeeScript that compiles to JavaScript, blending functional, object-oriented, and imperative styles. Like its JavaScript target it is dynamically typed and uses an indentation-significant, expression-oriented syntax, while adding features such as pattern matching, more aggressive operator and word-list sugar, and pipelining borrowed from languages like LiveScript (which descends from it). It runs anywhere JavaScript does, most commonly on Node.js or in the browser, and is used chiefly for concise client- and server-side web scripting where developers want terser, more functional code than plain JavaScript provides.
