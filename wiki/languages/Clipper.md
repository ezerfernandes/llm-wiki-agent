## Summary
Clipper is an imperative, procedural programming language and compiler that emerged in the mid-1980s as a superset of the dBASE III database language, originally developed by Nantucket Corporation and later acquired by Computer Associates. It is dynamically typed, with first-class support for database tables, indexes, and a built-in code block construct that adds limited functional and macro-style metaprogramming capabilities. Clipper was the dominant tool for building DOS-based business and database applications throughout the late 1980s and 1990s, allowing developers to compile xBase code into standalone executables. Its legacy lives on through open-source successors such as Harbour and xHarbour, which extend the language with object-oriented features and modern platform support.
