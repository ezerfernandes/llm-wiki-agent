## Summary
AutoLISP is a dialect of the Lisp programming language, derived from XLISP, that was built into Autodesk's AutoCAD beginning in the mid-1980s to let users script and customize the CAD environment. Like its Lisp ancestors it is a dynamically typed, interpreted, largely functional language built around s-expressions, list processing, and runtime evaluation, with prefix notation and parenthesized syntax. Its principal domain-specific strength is direct access to AutoCAD's drawing database and command set, allowing programmatic creation and manipulation of geometric entities. It remains in widespread use for automating drafting tasks, batch operations, and custom commands within AutoCAD, having largely supplanted earlier macro approaches and later complemented by the object-oriented Visual LISP extensions.
