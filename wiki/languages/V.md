## Summary
V (also written Vlang) is a statically typed, compiled, multi-paradigm systems and applications programming language created by Alexander Medvednikov around 2019, with a syntax heavily inspired by Go and influences from Rust, Oberon, and Swift. It emphasizes simplicity, fast compilation, memory safety without a tracing garbage collector (via an optional autofree and value-semantics model), and minimal runtime, while compiling down to readable C and supporting cross-compilation. The language favors immutability by default, has no global variables and no null, and ships with built-in tooling for formatting, testing, and dependency management. V is typically used for command-line tools, web backends, and other systems-level and general-purpose software where a small, dependency-free binary and predictable performance are desired.
