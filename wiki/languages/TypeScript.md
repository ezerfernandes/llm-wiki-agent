## Summary
TypeScript is a multi-paradigm language developed by Microsoft and first released in 2012 as a strict syntactic superset of JavaScript, adding optional static typing through structural type inference, generics, interfaces, and enums on top of JavaScript's dynamic, prototype-based core. It supports imperative, object-oriented, and functional styles, and compiles ("transpiles") down to plain JavaScript that runs in browsers, Node.js, and other runtimes. Its type system is gradual and structurally typed, erased at compile time so it imposes no runtime overhead. TypeScript is widely used for building large-scale web frontends, server-side applications, and tooling where the additional type safety and editor support improve maintainability over plain JavaScript.
