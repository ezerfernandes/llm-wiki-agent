## Summary
SQL (Structured Query Language) is a declarative, special-purpose language for defining, querying, and manipulating data held in relational database management systems, based on Edgar F. Codd's relational model and tuple/relational calculus. Developed at IBM in the early 1970s (originally as SEQUEL) and first standardized by ANSI in 1986, it uses a statically typed schema in which each column carries a fixed data type, while the language itself emphasizes set-oriented operations expressed through SELECT, INSERT, UPDATE, DELETE, and DDL statements rather than imperative control flow. Though not Turing-complete in its core form, it is augmented by procedural extensions such as PL/SQL, T-SQL, and PL/pgSQL, and remains the dominant interface for transactional databases, analytics, and data warehousing across nearly every major commercial and open-source RDBMS.
