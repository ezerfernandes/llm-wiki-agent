## Summary
ASIC is a procedural, imperative interpreter for a dialect of the BASIC programming language, originally released for MS-DOS in the late 1980s by 80/20 Software. It uses BASIC's traditional weakly typed model with line-oriented or labeled control flow, GOTO/GOSUB, and a small set of numeric and string types, targeting beginners and small DOS utilities. As a compact freeware BASIC that could compile programs to standalone executables, ASIC was typically used for learning programming and writing simple console-based applications on early PC hardware.
