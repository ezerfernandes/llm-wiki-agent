## Summary
Nanoquery is a general-purpose, dynamically typed scripting language created by Mark Edgington in the late 2000s, originally conceived as a query-oriented language before evolving into a full imperative and object-oriented programming language. Its syntax draws heavily from Python and Java, supporting first-class functions, classes, exceptions, and a small standard library, and it runs on the Java Virtual Machine via a tree-walking interpreter. The language emphasizes simplicity and readability, making it well suited for quick scripting, data manipulation, and educational use rather than performance-critical applications.
