## Summary
Picat is a multi-paradigm logic-based programming language created in 2013 by Neng-Fa Zhou and Jonathan Fruhman, combining the relational and unification features of Prolog with imperative constructs, functions, list comprehensions, and pattern-matching rules. It is dynamically typed and supports several distinct constraint-solving and search backends—including constraint programming (CP), SAT, mixed-integer programming (MIP), and tabled logic programming—through unified built-in modules. Picat blends declarative and procedural styles, offering both nondeterministic predicates and deterministic functions, along with assignable variables and explicit loops. It is most commonly used for constraint satisfaction and optimization, combinatorial search, planning problems, and scripting tasks that benefit from concise rule-based and pattern-matching code.
