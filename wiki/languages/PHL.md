## Summary
PHL is a small, statically typed, compiled imperative programming language with C-influenced syntax that compiles to PHP, allowing programs to be written in a more conventional structured style while running on the ubiquitous PHP runtime. Created in the late 2000s as a hobby/experimental project, it supports familiar constructs such as functions, loops, and typed variables, and transpiles its source into PHP code for execution. It is primarily of interest as a niche example of a language targeting PHP as a backend rather than for production web development, and sees most of its visibility through programming-task collections like Rosetta Code.
