## Summary
DCL (DIGITAL Command Language) is the imperative, command-driven scripting language used as the interactive shell and batch command interpreter for OpenVMS (and earlier VAX/VMS) systems, introduced by Digital Equipment Corporation around 1977. It is dynamically and weakly typed, working primarily with string and integer symbols whose values are interpreted at runtime, and offers control-flow constructs such as IF/THEN, GOTO labels, and subroutine calls (GOSUB/CALL) rather than structured blocks. Verb-oriented commands are parsed via a centralized command-definition mechanism, with qualifiers (the /switch syntax) and lexical functions (F$-prefixed) providing parameter handling and built-in operations. It is mainly used for system administration, automation, and batch job orchestration on VMS, where it serves the role that shells like Bash fill on Unix.
