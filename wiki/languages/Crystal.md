## Summary
Crystal is a general-purpose, object-oriented programming language with a Ruby-inspired syntax, first released in 2014 and reaching its 1.0 stable version in 2021. It is statically typed yet feels dynamic thanks to global type inference, which lets developers omit most type annotations while the compiler still verifies types ahead of time; union types and null-safety checks catch many errors before runtime. Programs are compiled to native machine code via LLVM, giving performance comparable to C while retaining concurrency through lightweight fibers and a built-in macro system for compile-time metaprogramming. It is typically used for high-performance web services, command-line tools, and systems-level utilities where Ruby-like ergonomics are desired alongside the speed and efficiency of a compiled binary.
