## Summary
Pluto is a superset of Lua that adds modern conveniences while remaining backward-compatible with Lua 5.4 code, emerging in the early 2020s from the community around the open-source Lua interpreter. Like its base language it is dynamically typed, imperative, and multi-paradigm—supporting procedural, functional, and prototype-based object-oriented styles—but layers on features such as compound assignment and ternary operators, optional static type annotations and runtime checks, string indexing, default function arguments, switch statements, and an expanded standard library. It targets developers who want Lua's lightweight embeddability and fast interpreter while enjoying ergonomics closer to mainstream scripting languages, and it is used notably for game scripting and as a drop-in replacement for embedded Lua runtimes.
