## Summary
The mIRC scripting language (mSL) is the event-driven, interpreted scripting language built into mIRC, a popular Windows IRC client first released by Khaled Mardam-Bey in 1995. It is an imperative, dynamically and weakly typed language whose values are essentially untyped strings, with identifiers (e.g. $len, $mid) and a rich set of commands manipulated through aliases, custom variables, and event handlers that fire on IRC activity such as messages, joins, and timers. Tightly coupled to the client's GUI and IRC protocol, it is used mainly to automate chat interactions, build bots, add custom dialogs and menus, and extend mIRC's behavior rather than as a general-purpose programming language.
