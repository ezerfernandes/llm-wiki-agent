## Summary
Dao is a lightweight, multi-paradigm scripting language created by Limin Fu around 2006, designed for embedding in and extending C/C++ applications much like Lua. It blends imperative, object-oriented, and functional styles, and is notable for its optional static typing with type inference: variables can be left dynamically typed or annotated for compile-time checking, giving a gradual-typing discipline atop a bytecode virtual machine. The language emphasizes concurrency through built-in lightweight tasklets and asynchronous functions, and is typically used for application scripting, glue code, and prototyping where tight C interoperability and an optional type system are both desirable.
