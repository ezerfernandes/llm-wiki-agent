## Summary
Groovy is a dynamic, object-oriented programming language for the Java Virtual Machine, first released in 2003 by James Strachan and later stewarded by the Apache Software Foundation. It is multi-paradigm, supporting object-oriented, imperative, and functional styles, and offers both optional dynamic typing and an optional static-compilation mode, giving it a Java-compatible syntax augmented with concise idioms such as closures, builders, and native support for lists, maps, and regular expressions. Its tight integration with Java libraries and bytecode makes it interoperable with existing JVM code while reducing boilerplate. Groovy is widely used for scripting, build automation (Gradle), testing (Spock), and domain-specific languages, as well as rapid application development on the Java platform.
