## Summary
EasyLang is a small, beginner-oriented imperative and procedural programming language created in the late 2010s by Hartmut Wedekind, designed to make programming approachable for newcomers and to teach fundamental coding concepts. It uses a simple, indentation-light syntax with statically typed but minimal type declarations (numbers and strings, with arrays), and includes built-in primitives for graphics, drawing, and interactive input so learners can produce visual and game-like programs quickly. EasyLang runs directly in the browser through an online editor that compiles to JavaScript/WebAssembly, and is most commonly used for educational purposes, programming exercises, and small interactive or graphical demos.
