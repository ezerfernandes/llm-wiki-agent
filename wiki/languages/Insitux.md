## Summary
Insitux is a Lisp-dialect scripting language with S-expression syntax, created by Patrick Bowen and first released around 2022. It is dynamically typed and functional in flavor, emphasizing immutable persistent data structures and first-class functions, and it runs on a small portable virtual machine implemented in TypeScript. Designed to be embedded into host applications, it is typically used as a configuration and extension language where a compact, sandboxed scripting runtime is needed, such as inside games and other JavaScript or TypeScript environments.
