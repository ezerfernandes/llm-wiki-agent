## Summary
TorqueScript is the embedded, interpreted scripting language of the Torque Game Engine, originating in the early 2000s from GarageGames' commercial engine (which grew out of the code behind the 2001 game Tribes 2). It is a dynamically and weakly typed, imperative language with C-like syntax, where all values are fundamentally strings that are coerced to numbers or other types as needed, and it supports object-oriented constructs through datablocks and namespaced objects tied to the engine's simulation tree. Variables are prefixed to denote scope (% for locals, $ for globals), and the language exposes console functions that bind directly to the engine's C++ subsystems. It is used almost exclusively for game logic, UI, and gameplay prototyping within Torque-based titles rather than as a general-purpose language.
