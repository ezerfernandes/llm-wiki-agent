## Summary
Wortel is an esoteric, prefix-notation functional programming language that transpiles to JavaScript, created around the mid-2010s and primarily exercised through code-golf and Rosetta Code challenges. It is dynamically typed and emphasizes terse, expression-oriented syntax, with operators and quoted symbols standing in for common operations to minimize character count. Programs are typically written as compact one-liners that compile down to runnable JavaScript, making it suited to puzzle solving and brevity competitions rather than general-purpose application development.
