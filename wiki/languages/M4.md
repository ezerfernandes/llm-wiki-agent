## Summary
M4 is a general-purpose macro processor and Turing-complete macro-expansion language developed by Brian Kernighan and Dennis Ritchie at Bell Labs in 1977, derived from the earlier M3 and ratfor preprocessors and later standardized as part of POSIX. Its computational model is purely textual: input is scanned token by token, defined macros are recursively expanded with positional argument substitution ($1, $2, ...), and there is no static type system since every value is an untyped string manipulated through built-in primitives like define, ifelse, eval, and dnl. As a paradigm it is best described as a string-rewriting/macro-substitution language rather than a conventional imperative or functional one, leaning heavily on recursion and quoting (backtick/quote delimiters) to control evaluation order. In practice M4 is used to generate configuration and source files, most famously as the engine behind GNU Autoconf/Automake and sendmail configuration, and more generally wherever templated text or boilerplate code needs programmatic expansion.
