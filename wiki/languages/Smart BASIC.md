## Summary
Smart BASIC is a commercial dialect of the BASIC programming language created by Kibernetik for Apple iOS devices, first released in the early 2010s. It is an imperative, procedural language with dynamic, weak typing in the BASIC tradition, distinguishing string variables by a trailing dollar sign while treating numeric values flexibly. Beyond classic BASIC constructs it adds modern conveniences such as graphics, audio, sensor access, and networking, letting users write and run programs directly on an iPhone or iPad. It is primarily used for hobbyist programming, learning, prototyping, and small standalone mobile apps developed entirely on-device.
