## Summary
Swift is a general-purpose, multi-paradigm language introduced by Apple in 2014 as a modern replacement for Objective-C, blending object-oriented, protocol-oriented, and functional programming styles. It is statically and strongly typed with powerful type inference, and emphasizes safety through optionals, value semantics, automatic reference counting, and exhaustive error handling, while compiling to native code via LLVM for high performance. Swift is the primary language for building iOS, iPadOS, macOS, watchOS, and tvOS applications, and since becoming open source it has also gained traction for server-side development, systems programming, and cross-platform tooling.
