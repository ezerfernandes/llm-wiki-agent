## Summary
Scratch is a visual, block-based programming language and online community developed by the MIT Media Lab's Lifelong Kindergarten Group, first released in 2007. Programs are built by dragging and snapping together graphical command blocks rather than typing text, and execution is driven by an event-based, concurrent model in which scripts run in parallel on sprites; it is dynamically typed with a small set of value kinds (numbers, strings, booleans) and loosely coerces between them. Designed primarily as an educational tool for teaching children and beginners the fundamentals of programming, it emphasizes interactive media such as animations, games, and stories. Scratch popularized the block-coding paradigm now widely used in introductory computer science education and inspired many derivative and embedded environments.
