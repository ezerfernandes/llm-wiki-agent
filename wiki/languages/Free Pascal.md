## Summary
Free Pascal is a mature, open-source compiler for the Object Pascal language family, first released in the late 1990s as a free, cross-platform alternative to Borland's Turbo Pascal and Delphi. It is a statically and strongly typed, primarily imperative and structured language with rich support for object-oriented programming (classes, interfaces, generics) and even some functional constructs, compiling natively to machine code across many architectures and operating systems. Its compiler offers multiple compatibility modes (Turbo Pascal, Delphi, ISO, and its own ObjFPC dialect), making it highly source-compatible with existing Pascal and Delphi codebases. Free Pascal is widely used for desktop applications (especially via the Lazarus IDE and LCL framework), system and command-line utilities, embedded and game development, and education.
