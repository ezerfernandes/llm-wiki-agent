## Summary
DWScript (Delphi Web Script) is an object-oriented scripting language derived from Object Pascal, developed by Eric Grange and first released around 2009 as an open-source successor to the older DelphiWebScript engine. It is statically typed with strong type checking and compiles to bytecode for execution on a stack-based virtual machine hosted within Delphi applications. The language supports classes, interfaces, generics, operator overloading, lambdas, and contracts, blending imperative, object-oriented, and some functional styles. It is most commonly used for embedding scriptable logic into Delphi/Object Pascal programs and as the compilation engine behind the Smart Mobile Studio Pascal-to-JavaScript toolchain.
