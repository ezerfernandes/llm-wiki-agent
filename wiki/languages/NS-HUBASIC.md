## Summary
NS-HUBASIC is a dialect of the BASIC programming language for the Hitachi MB-6890 ("Basic Master Level 3") and related Japanese home computers of the early-to-mid 1980s, with "NS" denoting the National/Hitachi-derived ROM BASIC variant. Like other 8-bit microcomputer BASICs, it is an imperative, procedural language that is typically interpreted line-by-line, uses dynamic and weak typing with a small set of numeric and string types, relies on line numbers with GOTO/GOSUB control flow, and addresses the host machine directly through PEEK/POKE and hardware-specific graphics and sound commands. It was used chiefly for interactive programming, simple games, and educational and hobbyist software on the home computers of its era.
