## Summary
OmniMark is a domain-specific, rule-based programming language created by Stilo (originally OmniMark Technologies) in the late 1980s and 1990s for streaming text processing, with particular strength in SGML, XML, and markup transformation. It is a statically typed language whose programming model centers on event-driven, declarative rules — element, pattern, and find rules that fire as a document is streamed — combined with imperative procedural code, making it well suited to high-volume, low-memory document conversion and publishing pipelines. Its signature feature is treating data flows (streams) and scanners as first-class constructs, so large documents can be transformed in a single pass without loading them entirely into memory. OmniMark is typically used in enterprise content management, technical publishing, and ETL-style transformation of structured and semi-structured text.
