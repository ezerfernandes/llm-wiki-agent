## Summary
Ursa is a small, dynamically typed, general-purpose scripting language created in the 2010s and implemented in Java, drawing on imperative and object-oriented paradigms with a clean, readable C/JavaScript-flavored syntax. It runs on the Java Virtual Machine, which lets Ursa programs reuse the Java standard library and interoperate with Java classes directly. The language is interpreted and aimed at lightweight scripting, embedding, teaching, and rapid prototyping rather than large-scale production systems, which is reflected in its broad but recreational coverage of Rosetta Code tasks.
