## Summary
Red is a multi-paradigm programming language created by Nenad Rakočević in 2011, heavily inspired by REBOL and designed to span the full stack from low-level systems code to high-level application and scripting work. It is homoiconic and dynamically typed, supporting functional, imperative, and reflective styles, and is notable for its compact toolchain that produces small native executables with no external dependencies. The language ships with a lower-level dialect called Red/System for systems programming, plus built-in domain-specific dialects (such as Parse for grammar-based parsing and a reactive GUI dialect) that make metaprogramming and embedded DSLs a core part of everyday use. Red is typically applied to cross-platform GUI tools, scripting, prototyping, and increasingly blockchain and decentralized-application development.
