## Summary
NetRexx is a general-purpose programming language created by Mike Cowlishaw at IBM in the mid-1990s as a dialect of Rexx designed to run on the Java Virtual Machine, interoperating fully with Java classes and libraries. It is multi-paradigm, supporting both procedural and object-oriented styles, and offers optional typing: variables can be dynamically typed strings (in the Rexx tradition) or explicitly declared with static Java types, blending scripting ease with Java's type system. NetRexx compiles to Java bytecode (or interprets source directly) and emphasizes a clean, low-syntax style with powerful decimal arithmetic inherited from Rexx. It is typically used for JVM application development, scripting Java environments, and as a more concise alternative to Java for tasks that benefit from Rexx's string-handling strengths.
