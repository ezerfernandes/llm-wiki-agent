## Summary
Microsoft Small Basic is an imperative, procedural programming language released by Microsoft in 2008, derived from the BASIC family and intended as a deliberately simplified first language for beginners and young learners. It is dynamically typed with a minimal vocabulary of roughly fourteen keywords, no functions with parameters or return values (only subroutines and global variables), and a curated set of built-in objects such as TextWindow, GraphicsWindow, and Turtle that make text, graphics, and animation immediately accessible. Programs run on the .NET-based Small Basic runtime, and the IDE offers context-aware "intellisense" guidance; finished projects can be "graduated" into full Visual Basic. Its typical use is educational—teaching core programming concepts before students move on to more capable languages.
