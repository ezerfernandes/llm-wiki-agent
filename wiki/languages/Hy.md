## Summary
Hy is a Lisp dialect, created by Paul Tagliamonte in 2013, that compiles to Python's abstract syntax tree and runs seamlessly on top of CPython, giving it full interoperability with the Python ecosystem and its libraries. It is multi-paradigm, blending the functional and macro-driven style of Lisp with Python's object-oriented and imperative features, and it inherits Python's dynamic, strong, duck-typed discipline. Code is written in s-expression syntax with Lisp-style macros, enabling powerful metaprogramming while compiling down to ordinary Python bytecode. It is typically used for embedding Lisp-flavored scripting and DSLs within Python projects, exploratory programming, and by developers who want Lisp semantics without leaving the Python runtime.
