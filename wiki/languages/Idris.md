## Summary
Idris is a purely functional programming language with dependent types, created by Edwin Brady and first released around 2009, with a major redesign (Idris 2, built on the Quantitative Type Theory of linear/dependent types) appearing in 2020. Heavily influenced by Haskell and the proof assistants Agda and Coq, it features strong static typing in which types are first-class values that can be computed and manipulated, enabling programmers to encode precise invariants and carry machine-checked proofs alongside ordinary code. It supports type-driven and interactive editor-assisted development, eager evaluation by default, and totality checking to guarantee functions terminate. Idris is primarily used for research, teaching, and experimentation in dependently typed programming and verified software rather than large-scale production systems.
