## Summary
XQuery is a declarative, functional query and transformation language for XML data, developed by the W3C with its first edition standardized as a Recommendation in 2007 (XQuery 3.1 followed in 2017). Built on XPath expressions and centered on the FLWOR construct (for, let, where, order by, return), it is strongly and statically typed against the XQuery and XPath Data Model, drawing its type system from XML Schema. As a side-effect-free language emphasizing immutability and higher-order functions, it is used chiefly to query and reshape XML documents and native XML databases, and it also extends to JSON and general data integration through implementations such as BaseX, eXist-db, MarkLogic, and Saxon.
