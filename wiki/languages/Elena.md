## Summary
Elena is a general-purpose, pure object-oriented programming language created by Alexei Rakov, first appearing in the early 2010s. It emphasizes message dispatching and a uniform object model where everything—including primitives, classes, and even code blocks—is treated as an object, and it supports mixins, multiple dispatch, and a dynamic prototype-based extension mechanism alongside more conventional class hierarchies. The language is dynamically and structurally typed with optional static type qualification, and it runs on its own virtual machine targeting Windows and Linux. In practice Elena is an experimental and educational language used mainly to explore advanced object-oriented and message-based programming idioms rather than for large-scale production deployment.
