## Summary
PicoLisp is a minimalist Lisp dialect created by Alexander Burger in the late 1980s, designed around a single internal data type (the cell) and a deliberately tiny interpreter and virtual machine. It is dynamically typed and multi-paradigm, blending functional and symbolic programming with imperative style, and notably uses Fexprs and first-class symbols rather than traditional macros, evaluating arguments lazily under explicit control. The language ships with its own object-oriented database engine and Prolog-style logic programming (Pilog), making it especially suited to rapid development of database-backed and web applications where the data model and code share the same uniform list representation. Its emphasis on simplicity, a small memory footprint, and direct symbolic manipulation makes it a compact, self-contained environment for both scripting and full application stacks.
