## Summary
Fe is a tiny, embeddable Lisp-like scripting language created by rxi around 2020 and implemented in roughly 800 lines of portable ANSI C. It is dynamically typed and functional in style, built on a minimal core of cons pairs, symbols, numbers, strings, lambdas, and macros, with a fixed-size region of memory and mark-and-sweep garbage collection so it can run without dynamic allocation. Its primary use is as an extension or configuration language to be embedded inside C and C++ host programs, where a very small footprint and easy interoperability matter more than a large standard library.
