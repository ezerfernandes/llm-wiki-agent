## Summary
Clean is a purely functional, lazy programming language developed at Radboud University Nijmegen in the Netherlands, with origins in the late 1980s and a first public release in 1987. It features a strong, statically inferred Hindley-Milner type system extended with uniqueness typing, a distinctive mechanism that tracks single-reference values to allow safe in-place updates and controlled side effects without sacrificing referential transparency. Syntactically and conceptually it closely resembles Haskell, supporting algebraic data types, pattern matching, higher-order functions, and generic programming, while compiling to efficient native code. It is used mainly in academic research and teaching on functional programming, type systems, and high-performance functional compilation.
