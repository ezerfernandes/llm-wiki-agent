## Summary
Déjà Vu is a dynamically typed, stack-based programming language created around 2013 by Tijl "Zatherz" Houtbeke, drawing inspiration from Forth, Python, and Factor. It is concatenative and primarily postfix in nature, but a lightweight reader transformation lets it accept a more conventional infix-like syntax, while values are manipulated on an explicit data stack. The language is implemented as a compact bytecode interpreter (vu) and supports first-class functions, closures, and dynamic data structures such as lists and dictionaries. It is chiefly a hobbyist and experimental language used for scripting, teaching stack-oriented concepts, and recreational programming such as the Rosetta Code tasks.
