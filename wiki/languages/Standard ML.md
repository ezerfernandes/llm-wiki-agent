## Summary
Standard ML (SML) is a functional programming language with imperative features, formally specified in 1990 and revised in 1997 as the descendant of the ML language originally developed for the LCF theorem prover at the University of Edinburgh. It is statically typed with a sound, polymorphic Hindley-Milner type system that supports near-complete type inference, algebraic data types, pattern matching, and a powerful module system based on structures, signatures, and functors. The language is strictly (eagerly) evaluated and is notable for being one of the few programming languages with a complete formal definition. It is used primarily in academia, programming-language research, compiler construction, and theorem proving, with widely used implementations including Standard ML of New Jersey (SML/NJ), MLton, and Poly/ML.
