## Summary
OPL (Organiser Programming Language) is a procedural, structured programming language created by Psion in 1984 for its handheld Organiser devices and later adopted as the native programming environment of the EPOC and Symbian OS platforms. It is statically typed in a lightweight way, using single-character type suffixes on variable and procedure names (for example `%` for integers, `&` for long integers, `$` for strings, and `()` for arrays) rather than separate type declarations. Programs are organized into procedures that can be compiled to a tokenized bytecode and run on-device, giving it a BASIC-like syntax tuned for the constrained memory and screen of early personal digital assistants. It was used primarily to build productivity applications, utilities, and games directly on Psion Organisers, Series 3/5 palmtops, and Symbian phones.
