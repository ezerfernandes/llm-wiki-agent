## Summary
In the Rosetta Code sense, "Excel" refers to programming with the formula language of Microsoft Excel, the spreadsheet application first released in 1985. Excel formulas form a declarative, functional dataflow language: rather than executing imperative statements, each cell holds an expression that is automatically recalculated when the cells it references change, so computation is expressed as a dependency graph of pure functions over cell ranges. Typing is dynamic and value-oriented, with a small set of types (numbers, text, booleans, dates, and error values) coerced implicitly, and modern versions add dynamic arrays and LET/LAMBDA constructs that allow recursion and reusable named functions. It is used overwhelmingly for end-user financial modeling, data analysis, and reporting, where its grid-based, instantly-recalculating model lets non-programmers build computations without writing traditional code.
